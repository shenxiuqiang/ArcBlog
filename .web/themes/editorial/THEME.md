# editorial

Print-editorial pairing -- DM Serif Display headings, Sora body, deep green accent -- a tokens-only overlay with no component or layout changes.

## Design DNA

- **Typography**: DM Serif Display headings + Sora body (mono: JetBrains Mono)
- **Signature**: #2a6e00 primary accent on #fafaf8 background (light), #c4f04d on #0a0a0f (dark)
- **Effects**: None -- pure color + font token swap
- **Cards**: Inherits default card layout and structure with these color/font tokens

This theme has no component overrides. It functions as a tokens-only overlay that swaps color and font design tokens for both light and dark mode. All component structure and layout inherit directly from the default base theme.
