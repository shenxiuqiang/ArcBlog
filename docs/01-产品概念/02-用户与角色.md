## 1. 角色集

| 代号 | 角色 | 一句话 |
| :-: | --- | --- |
| **C** | **创作者** | 写内容、拥有节点、希望被看见而不依赖平台 |
| **R** | **读者** | 想少花时间读到值得读的东西，且不想交出身份 |
| **O** | **节点运营者** | 部署并运行一个节点，希望**被发现**；**质押进链上注册表即可被发现** |
| **A** | **agent 接入方** | 开一个 agent 去发现、汇总、与你对话、生成并发布 |
| **G** | **平台方治理者** | 维护平台能力边界与公共规范 |

网络里**没有**统一的聚合角色：聚合由 A（用户自己的 agent）承担，发现由链上注册表承担（见 §5）。

## 2. 每类角色：要什么 / 今天卡在哪 / 成功标准

### C · 创作者
| 项 | 内容 |
| --- | --- |
| 要什么 | 内容与读者关系带得走；被汇总时**署名指向自己的节点**；发布路径短 |
| 今天卡在哪 | ① **页面写入的署名不可信**（运行时**只在文本节点**解析整串 `$session.*`）——**【平台边界】**（2026-10-12 同步：探针 `U6` = **判定 B**，结论层 = [`docs/05-开发文档/02`](../05-开发文档/02-平台能力与边界.md) `B18`；**降级（已实现）** = CLI `publish --sign-key` 写署名）；② **发布只能落在应用之外**（应用无运行时依赖）——**【平台边界】** |
| 成功标准 | 发布一篇并出现在公开页 + 只读出口 —— **可判定**；"被 N 个 agent 汇总"——**数值【决策待定】** |

### R · 读者
| 项 | 内容 |
| --- | --- |
| 要什么 | 少花时间、看得准；匿名只读（不登录、不交 Key） |
| 今天卡在哪 | **信息过载**本身没有产品解：读者要的"被汇总过的列表"**有前提**——**必须先持有/获得自己的 agent**（今天 **【已实现】**：CLI 命令面 `arcblog-summarize.mjs build\|show\|ask`，`?page=agents` 给**可复制命令**；运行时 `/mcp` 只声明）；但**仍没有"结果开箱即用"的聚合面**——结果要先有**活节点**（当前注册表投影 **0 节点**） |
| 成功标准 | 从"进入公开面"到"读到目标内容"的步数与**是否无需登录** —— **可判定**；"看得准"——**数值【决策待定】** |

### O · 节点运营者
| 项 | 内容 |
| --- | --- |
| 要什么 | 一个能跑的软件 + **被发现的途径**（不申请、不审核） |
| 今天卡在哪 | ① 买/质押 studio NFT 的脚本 **【已实现】**（`node scripts/arcblog-node-nft.mjs acquire\|stake`）；② **枚举【已实现】**（2026-10-12 同步）：两适配器 `listStakes`（`ENG-02`/`ENG-03`），`P-1` mock 全过 + `P-2` beta 真链只读 `code: OK, total: 1`，消费面 `registry refresh\|show` + `?page=registry` ⇒ "被 agent 发现"**今天已接通** |
| 成功标准 | 质押成功 + 该节点出现在**链上质押列表**中（判定式：返回条数 = 质押数；**已过**：`P-1` mock 全过 + `P-2` beta 真链只读 `code: OK, total: 1`，2026-10-12 同步）—— **可判定**；"被多少 agent 发现"——**数值【决策待定】** |

### A · agent 接入方（**主干**）
| 项 | 内容 |
| --- | --- |
| 要什么 | ① 可读的公开面；② 明确的授权面；③ 能写（生成草稿/发布）但不越权 |
| 今天卡在哪 | ① 工具面 **12 个**【已实现】（含 `create_draft`/`update_draft`/`publish_post`，见 `scripts/lib/agents.mjs`，2026-10-12 实测：read 8 / write 3 / closed 1）；② **发现工具已接线**【已实现】（`list_studios`/`get_studio` 读链上注册表投影，`PRD-AGT-12`）；③ **聚合层【已实现】**（`PRD-AGT-07` 确定性汇总 **30/30** + `AGT-08` 确定性 `ask`，`cited[]` 可回溯；**对话面 =【平台边界】**）；④ **记忆先本地【已实现】**（`PRD-AGT-11`，**2/2**），DID Space 备份 **【平台边界】** + `U10` 未验证 |
| 成功标准 | 一次完整链路（发现 → 汇总 → chat → 生成 → 发布）**逐步可判定**（见 `03 §J4` 覆盖矩阵）；质量指标（汇总命中率等）——**数值【决策待定】** |

### G · 平台方治理者
| 项 | 内容 |
| --- | --- |
| 要什么 | 能力边界可维护、规范可执行、下游不越界 |
| 今天卡在哪 | 平台能力与降级**已有唯一出处**（[`docs/05-开发文档/02-平台能力与边界.md`](../05-开发文档/02-平台能力与边界.md) 的 `B1`–`B18`+[`02a`](../05-开发文档/02a-平台禁止与降级模式.md)）；**本项目适配器缺口（枚举、转让）均已落到探针结论**（2026-10-12 同步：`ENG-02`/`ENG-03`/`ENG-05`/`ENG-06` 已接线；`P-1`/`P-2`/`P-4` 已过；**真链写入端（自描述/转让）待人类批准**） |
| 成功标准（**产品结果口径**） | ① **能力边界有唯一可引用出处**且与实测一致（不出现"两种说法"）；② **每个未验证项都有验证方法与阻塞对象**，下游可据此排期 —— **可判定** |

## 4. 角色关系（文字 + 表）

```text
        C 创作者 ──写──▶ 自己的节点（AFS）
             ▲                     │  质押 studio NFT 到 factory 地址
             │署名指向自己的节点       ▼
        A agent ◀──链上注册表（质押列表）── O 节点运营者
             │  发现 → 汇总 → chat → 生成
             ▼
        R 读者 ◀── 汇总列表 / 公开面 / 只读出口
             ▲
             └──（订阅的三种含义）
```

| 关系 | 内容 | 状态 |
| --- | --- | --- |
| C ↔ O | 同一人可同时是两者（自己写、自己运营） | — |
| O ↔ A | O 的节点因**质押**进入链上注册表；A **查表**发现它 | **均【已实现】**（2026-10-12 同步：机制 + 本项目适配器与消费面都已在册） |
| A ↔ C | A 读 C 的公开面并汇总；C 的署名随内容走 | 【已实现】（只读面）/ 页面署名 **【平台边界】**（`U6` 判定 B；降级 = CLI `--sign-key`） |
| A ↔ R | **订阅的三种含义**：① 浏览器书签（本地）② 只读出口（`/p/llms.txt`【已实现】；`/p/rss.xml`**【已实现】**——部署管线步骤 3b，`DEF-28`）③ **交给自己 agent 盯**（入口 = `?page=agents` 的**可复制命令** `arcblog-agent.mjs authorize\|run` + `arcblog-summarize.mjs build\|show\|ask`；运行时 `/mcp` 只声明） | ①②③**【已实现】**（2026-10-12 同步） |
| R ↔ C | 读者关系**不被平台持有**：不登录也能读 | 【已实现】 |

## 5. 网络职能的归属（谁负责什么）

| 职能 | 归属 | 说明 |
| --- | --- | --- |
| **聚合**（采集 → 预筛 → 评分 → 组合） | **A（用户自己的 agent）** | 同一份公开面，各人可跑各人的规则（`01 §5`） |
| **发现**（有哪些节点在运行） | **链上注册表** | 质押列表即目录：同一 factory 地址 ⇒ 全部节点 |
| **推荐位 / 排名** | **不做**（产品选择） | "谁被看见"不由任何中心决定（`01 §6`）；见 `01 §7` |
