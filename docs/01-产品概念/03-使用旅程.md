**设计要点（形态设计，**推断非原话**）**：① 先定**一份公开投影**（`/p/`），聚合侧只写一套适配器；② 用 **snapshot + changes（带游标）**，避免把撤回当新内容；③ 必须携带**来源节点的 `discoveredAt`**，不能只带发布时间；④ **匿名只读 + 条件请求 + 降级阶梯**；⑤ **可解释排序 + 保守合并门槛**，热度阈值按自己的节点频率**重新标定**。

**卡点（2026-10-12 同步）**：① ~~**发现工具仍 `unavailable`**~~ **已接线**【已实现】（`list_studios`/`get_studio` 均 `available`，读 `node/registry.json` 投影）；② **智能层**：**确定性聚合 / `ask` / 生成草稿 / 本地记忆【已实现】**，**LLM 写作与对话编排【平台边界】**（平台无 LLM 原语，`--llm` 未接）；③ **agent 的 DID 与授权面**需在实现层确认；④ 外部框架（如 AIGNE）的许可为 **Elastic-2.0**（非 OSI 开源，限制"作为托管服务对外提供"）⇒ **概念层不绑定框架**。
