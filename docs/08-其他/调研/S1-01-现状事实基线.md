## 1. 一句话定义（两条口径分开写）

**现状口径（今天实际是）**【已实现】
> ArcBlog 是一个 **DID 原生、Markdown 优先的发布型 Blocklet**（`README.md:6`），用 AUP DSL（`.aup/**`）+ 一组 Node CLI（`scripts/**`）编写，无 bundler、无 dev server、AUP 应用本身零运行时依赖；内容托管在 blocklet 的 AFS 实例空间（`/instance/app/arcblog/**`），通过 `arc` CLI 与 AUP 运行时的 `/.actions/write` 读写（`CLAUDE.md:16`、`CLAUDE.md:143`）。它不是本仓库里的通用站点，而是**一个早期博客阶段子集**：`CLAUDE.md:16` 原文 —— “the current codebase implements the early blog-phase subset of it”。

**V2.0 目标口径（要做成什么）**【规划中】（`spec §153:5249-5269`、`spec §147:4849`、`spec §1:29-55`）
> ArcBlog 不是一个博客网站，而是一套 **Open Source + Self Hosted + Identity Native + Content Native + Agent Native + Economy Native + Decentralized 的内容基础设施**：以 ARC 为运行基础、DID 为身份、AFS 为资源层、Web Device 为发布层、AUP 为交互层、Studio 为创作者节点、Hub 为发现节点、NFT + Stake 为网络角色激活机制、支付与分成为经济基础、Agent Access 为 AI 接口的**开放内容网络**。
> 它的**基本单位是一个 ArcBlog Instance**；同一份代码、同一个 Blocklet Package，按链上角色成为 **Basic / Studio / Hub / Studio + Hub** 四种运行状态（`spec §1:31-55`、`spec §7:271-376`）。最终目标原文（`spec §153:5316`）：任何人都可以运行自己的 Studio 与 Hub，创作者拥有身份与内容，Hub 通过发现和分发获得网络收益，读者直接与创作者发生经济关系。

**6.2 页面渲染方式**
- 后台 = **AUP DSL 应用**：`app.aup` 仅 14 行 manifest；页面是**外部文件**，按目录 glob 注册，每文件恰好一个根节点，header 为 `page <name> {`（加标题会校验失败）；i18n 键扁平点号、按页作用域（`CLAUDE.md:143`）。
- 控制台 = **一节一页一 `?page=<name>`**（21 节），侧栏由 `scripts/console-nav.mjs` 单一真源生成并投影进每页，`--check` 防漂移；`#hash` 路由与 `console-bridge` 已删除（`CLAUDE.md:145`、`scripts/console-nav.mjs:100-116`）。
- 公共站点 = **SSR**：`pages/**`（`hero-carousel`、`theme-bridge`）由 `.route/web` 挂在 `/p`；文章页走 `blocklet.yaml sites[].bindings` 的漂亮 URL + `propBind={post:"…/$params.slug.json"}` 两通道取值（`developer-guide.md:110-131`）。
- 渲染能力边界：`visible` 表达式只支持 `! && ||` + `$session.*/$state.*`，**无比较符、无 capability 求值** → 菜单无法按角色隐显（`checklist:131`）。

**6.3 写入路径（两条）**
```text
① 页面直写： AUP 页面 --exec "/.actions/write"--> replicated collection（minRole: admin；copy: none 单文件）
② 意图队列： 页面 --> config/<x>-intents/<id>.json --> 本机 worker（arcblog-*.mjs apply|watch）--> AFS 记录
             状态词表 pending|running|applied|rejected|noop（scripts/lib/intents.mjs:34-46）
③ 链上动作： 页面 --> config/chain-intents --> scripts/arcblog-chain-worker.mjs 节点侧签名 --> node/factories.json
```
`CLAUDE.md` 内容模型节 + `checklist:111-112,118-119,124,129`；「页面绝不直接发交易、私钥不下发浏览器」是既定纪律（`checklist:236`）。

**6.4 身份**
DID 是唯一身份：页面授权用 `$session.authenticated` + 登录卡（`blocklet.yaml` 顶层与 bindings 无角色字段）；Node DID 由 `scripts/arcblog-node.mjs` 建立（`authMethod ∈ developer|provider|blocklet|did-connect`，`_docs/persistence.md:16`）；作者身份 = DID（`spec §107:3905-3919`：不用 username 作最终身份）；内容签名用本地 Ed25519 私钥（0600，永不入 AFS）；链上角色用节点钱包（助记词在 env / 已 gitignore 的 `.env.local`）。
