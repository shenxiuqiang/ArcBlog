# S3-02 平台 UI 能力边界（设计视角）

> **用途**：给「产品设计文档」提供**平台可实现性边界** —— 页面能画什么、不能画什么、画不了时设计必须怎么退让。
> **与 S1-03 的分工**：S1-03 是**产品能力**矩阵（数据/链/权限/端点）与 20 条禁止清单；本文**不重复**它，只做**设计落地**约束（布局 / 组件 / 样式 / 交互 / 响应式）。
> **证据口径**：`§N` = `_docs/arc-contracts.md` 节号（实测）；`skill:<文件>:<行>` = `.agents/skills/aup-dsl/references/*.md`；`.aup/...:行` = 仓库真实写法；`设计标准 §N` = `_docs/ArcBlog-admin-ui-design.md`。
> **标签**：✅ 能用 ｜ ⚠️ 有前置条件/会静默失败 ｜ ❌ 不能用 ｜ 【未验证】= 无实测，附验证方法。
> **一条元规则**：`arc dsl validate` 绿 **不等于**节点能渲染 —— schema 对任何 prop 都 `additionalProperties: true`，`role`/`aria`/`position` 等键在 schema 里**根本不存在**（`arc dsl schema --json` 全文 0 命中），所以「能过校验 + 渲染无效果」是常态（§25.5、skill:runtime-gotchas.md:85-87）。

## 1. 布局与容器

### 1.1 可用原语与契约

| 原语 | 契约（渲染器真读的 prop） | 设计含义 |
| --- | --- | --- |
| `view` | `layout` / `mode` / `gap` / `padding` / `size` / `style` / `intent` / `visible` / `href` / `target` / `role` / `modalRoute`；落成 `.aup-view[data-layout]`（skill:primitives.md:41-53） | 唯一的通用容器；下文所有「行/列/卡片」都由它表达 |
| `row` / `grid` / `stack` | **别名**，服务端展开成 `view` + `data-layout`；没有 `aup-row` 类（skill:primitives.md:134） | 可以放心写，但别指望 DOM 里能按 `row` 选到节点 |
| `col` | ❌ **不存在**：`arc dsl schema --json` 的 `primitiveAliases` = badge/button/card/grid/h1/h2/h3/p/repeat/row/stack/tab，无 `col`；仓库 0 处使用 | 竖直排列一律用 `view`（默认 direction 即纵向） |
| `card` / `badge` / `button` / `tab` / `repeat` | 编译期糖，**展开结果未逐一验证**（§21.9 只证实 `card` → `.aup-view[data-mode="card"]`）；`tab` 别名在本版本**被拒**（`action node missing required content`，§21.13） | 折叠用 `view mode=tabs`；卡片面板**不要**用 `card`（见 §3） |
| `view mode=tabs` | ✅ 每个直接子 `view` 是一个面板，标题取 `label`（§21.13） | **三级内容折叠的唯一合法机制**（设计标准 §2.7.3 ①） |
| `frame` | `src/bridge/overlay/loading/size/fallback/autoHeight/aspectRatio/allow/sandbox/transparent/title/variant`；**没有 `style`**（§14） | 嵌入 Web Device 组件；尺寸只能用 `aspectRatio`/`size`，不能写 CSS |
| `auto-surface` | ⚠️ 平台外壳：内层 padding 20px、内层 h2 21.6px、自带投影，**不读页面内联 style**（设计标准 §3.3 免责、§8） | 外观页（`?page=appearance`）天然是「平台外观」，**不要为它画像素稿**、不要要求 14px/17px 对齐 |
| `overlay` `surface` `deck` `terminal` `wm` `calendar` `map` `canvas` `webgl-hero` `agent` `chat` `share-panel` `editor` `post-editor` `afs-stat` `afs-preview` `entity-overview` `table` `tooltip` `searchable-dropdown` `photo-story` | 运行时**已实现**（§25 的 54 个）但**本仓 0 处使用** ⇒ 契约未验 | 【未验证】设计可以选，但必须先单页探针（验证方法见 §5.2 U4） |
| 9 个禁用原语 | `blocklet-embed` `camera-preview` `connection-gate` `explorer` `globe` `provider-card` `rtc` `skills` `wm-surface` —— bundle 里不存在（§25、skill:primitives.md:11-14） | 写了就是「发明 API」；渲染期炸，`validate` 不报 |

### 1.2 高度与滚动规则（全仓唯一配方）

```text
wrapper 顶栏    app-header 48px，在 .aup/wrapper.aup 的 `view mode=shell` 内、`slot content` 之外（.aup/wrapper.aup:41-46）
页面根          view style={height: "calc(100vh - 48px)", overflow: visible}            （.aup/pages/admin/posts.aup:56）
骨架行          row style={width:"100vw", marginLeft:"calc(50% - 50vw)",
                            height:"calc(100vh - 48px)", marginBottom:"-52px"}          （.aup/pages/admin/posts.aup:65）
唯一滚动容器    内容列 view size={flex: 1} style={overflowY: auto}                       （.aup/pages/admin/posts.aup:169）
```

* ⚠️ **`overflow` 必须是 `visible`**：`hidden` 会把全出血（`100vw`）的顶栏与侧栏裁掉（§24 实测）。页面根**保留在 1200px 居中列里**是正常的，只要不裁剪。
* ⚠️ **`--aup-content-max`（fallback 写 1280px，实测 1200px）cap 的是「页面根的直接子元素」**，且 `margin-left/right: auto !important` —— 内联 `style` **覆盖不掉**（§24）。⇒ 全出血必须发生在**更深一层**。
* ⚠️ **没有「剩余高度」原语**：`calc(100vh - 48px)` 里的 `48px` 是实测顶栏高度，**顶栏高度一改必须全量复测**（§21.2、设计标准 §8）。
* ⚠️ `gap` 属性是**离散 token**：`gap=sm`→10px、`gap=md`→20px（= 默认值，写了等于没改）；要 `0` 只能写 `style={gap:"0"}`（§21.3、§21.5）。
* ⚠️ 滚动区**直接子项必须 `flexShrink: 0`**（否则卡片被压扁、文字被裁而不是产生滚动）；含滚动区的外层必须 `style={height:"100%", minHeight: 0}`（否则 `flex:1` 解析不出高度，滚动落到外层 → 双滚动条）（§21.2）。
* ⚠️ 触底要靠**负下边距**（`marginBottom: -52px`）：运行时 scroller 在内容下方固定留 `gap 20px + padding-bottom 32px`（§21.4）。
* ⚠️ `afs-list` 挂载后**自动聚焦**：页面底部有空列表时浏览器会把最近的滚动容器滚到底（实测 `scrollTop=1898/1898`）（§21.3、§28.2）⇒ **空列表不要放在首屏之下**。
* ❌ **`position: sticky` / `fixed`【未验证】**：`§29.8` 的 67 键白名单里**没有** `position`，`zIndex`/`transition` 同样未列；仓库 0 处使用。设计标准**附录 A.1** 的 `.page-head{position:sticky}` 是「与框架无关的 CSS 骨架」，**不是 AUP 可实现项**（附录 A.1 自己声明 AUP 落地的是**结构**而不是那段 CSS）。
* ❌ **嵌套滚动 / 双滚动条** = 布局缺陷（设计标准 §2.5）；**窄屏例外（侧栏折叠后恢复整页滚动）在仓库里没有任何实现**（见 §5.2 U1）。
* ✅ 常驻页头的正确做法不是 sticky，而是把页头放在**滚动容器之外**（`.aup/pages/ops/media.aup:137-141`：页头 `view gap=xs { h2 :title … }` 是 `overflowY:auto` 的内容列**之前**的兄弟节点）。

### 1.3 布局**不可表达**的东西（设计必须换画法）

| 想画 | 平台事实 | 设计退让 |
| --- | --- | --- |
| 吸附页头 / 吸附底栏 / 悬浮保存条 | 白名单无 `position`（§29.8）；`transform` 被清洗（§21.9）；设计标准 §2.5 明文**禁止**页头脱离内容区悬浮 | 页头/动作条放在滚动容器**之外**（§21.2），滚动手感一样 |
| 窄屏自动堆叠 / 两列变一列 | `flexWrap` **不在白名单**（`.aup/pages/economy/policy.aup:224` 注释 + §29.8 清单未列）；AUP 没有媒体查询入口 | 要么一开始就是单列，要么由 Web Device 组件（唯一能写 CSS 的地方）承担 |
| 侧栏固定 + 右栏局部替换（节点级 patch） | `action -> set <id> src/props` 本实例**不可达**（服务端回 `{"error":"AUP node not found: probe-swap"}`，§21.12） | 「一事一页 + `-> page`」（整页子树重建、无文档重载）或订阅区域（§21.11） |
| 行拖拽排序 | 平台无 drag 原语；事件只有 click/select/nav-click/user-menu-item；`reorder` 是**会话 patch 词汇**不是作者 API（§21.12） | 用 `content.sort` 数字 + 表单/CLI 改值 |
| 任意层级嵌套滚动 | 只有「一个区域」粒度（§21.11） | 单滚动容器 + `view mode=tabs` 折叠 |

| 17 | `view mode=tabs` | ✅ 唯一折叠机制 | §21.13：切换**零 WS 帧**、侧栏与面板 DOM 复用、**隐藏面板里的订阅仍在刷新**；`tab` 别名被拒 | 三级技术细节折叠一律用它（设计标准 §2.7.3）；不要用手写 `set state {open}`（历史页合法、新页禁止） |
| 18 | `afs-dropzone` | ⚠️ 无 prop + format 陷阱 | `.aup/pages/ops/media.aup:137` 注释「平台未暴露其 prop 元数据 —— 禁止臆造 prop」；§45：`arc dsl format` 会把「裸 `afs-dropzone` + 紧随兄弟」合并成一个 `content=` prop，且 `--check` **不再报错** | 只能**裸用**；放进自己的 `view {}` 层并置于该层**末尾**（media / compose / compose-edit 三页范式） |

### 3.2 token 体系

```text
颜色   var(--color-surface) 卡片/侧栏底   var(--color-border) 全部边线   var(--color-dim) 次要文字
       var(--color-primary) 主按钮/当前项/链接   var(--color-error) 语义红（--color-danger 只是别名，改写无效）
       var(--card-bg) / var(--card-border)  卡片专用
排版   var(--type-heading) 21.6px（平台 h2 默认） var(--type-subheading) 17px var(--type-body) 15px
       var(--type-small)  var(--type-caption) 13px（配 intent=muted → var(--color-dim)）
圆角   var(--radius-lg, 10px) 卡片   var(--radius-md, 8px) 按钮
间距   --space-block 20px（运行时 view 默认 gap 与卡片默认 padding）
```

* **一个页面最多一个语义色焦点**；状态用「色点 + 文字」双编码，**不得只靠颜色**（设计标准 §3.1/§4.1）。
* **平台消费的是 `--color-error`**：`variant=destructive` 的文字 + 描边 + 图标全都取它 ⇒ 叠在 12% 淡底上实测 **3.99:1（静息）/ 3.64:1（hover）**，**两态皆破 WCAG AA**。修法在**主题层**（`.web/components/theme-bridge/script.js` 的 `CHROME_CSS`，三条覆写：静息文字 `--color-text`、hover 文字 `--color-surface`、红只留 1px 描边 + 图标）（设计标准 §3.1 / §4.3，引 UI-009 / UI-010）。
* ⚠️ **`.web/themes/*/tokens.json` 不参与控制台** —— 控制台只加载 Google Fonts + `aup-core.css` + `aup-app.css`。⇒ 控制台的视觉覆盖**只有一条路**：`theme-bridge` 的 `CHROME_CSS`（先例：destructive 对比度、按钮圆角统一、命中区 24×24、footer 布局）。

### 3.3 主题 bridge 与闪烁

* 机制：`data-tone` / `data-palette` / `data-mode` 写在宿主 `<html>` 上，由 wrapper 里**不可见的 overlay iframe**（`frame theme-bridge-frame src="/p/en/theme-bridge/" bridge=true overlay=true loading=eager`，`.aup/wrapper.aup:45`）运行期读取 settings、用 MutationObserver 反复回写（§17）。
* ⚠️ **`mode` 只接受 `light` / `dark`**（不接受 `system`），而运行期**每次导航都会重置 `data-mode`** ⇒ 编译值（`.aup/app.aup`）必须等于站点实际外观，否则**必有一半访客每次导航闪 ~300ms**（§17）。桥接侧把解析结果缓存进 `localStorage['arcblog:theme:v1']` 并在启动时同步回放，是当前唯一的缓解。
* ⚠️ `$t(wrapper.*)` 在 **prop** 里会被 daemon 解析并随 locale 变化（§31(1)）⇒ **i18n 是唯一「一处改、多处生效」的机制**（也是唯一能让共享外壳文案随语言切换的机制）。
* ❌ **页面上没有时间原语**：`${generate.*}`（year/date/timeiso/uuid）在 prop 与文本节点里**一律原样输出**（8 种写法全败，bundle 里 `timeiso` 0 命中，§31(2)）⇒ 动态年份、当前时间、倒计时都**不可画**。

### 3.4 无法表达的效果（不要画进设计稿）

渐变 · 多层背景（只能用 `background` 简写描述一个）· 自定义阴影与 hover 位移（`transform` 被清洗 + `card` 的 lift 关不掉）· 自定义动画/过渡（`transition` 未在白名单）· 吸附与浮层（`position` 未在白名单）· 强制换行策略（`whiteSpace`/`wordBreak`/`textOverflow` 被丢）。

## 4. 交互与状态的可表达性

### 4.1 条件渲染 / 表达式 / 脚本

* ✅ **只有同步 `$session.*` 可靠**：`visible=$session.authenticated` 与 `visible="!$session.authenticated"` 是仓库在用的登录门写法（`.aup/pages/admin/posts.aup:59,66`）。
* ❌ **异步数据上的闸门语义是坏的**：`visible="$entry.content.count"` **恒真**、`!${…}` **恒隐藏**、`$state.*` 上的条件渲染不可靠；同一份构建双向实测（§28.1、§56）。`visible` 的表达式形式 `$state.x` 只求值一次且永不恢复；插值形式 `${state.x}` 能显示但**取反不互斥**（§28.1、§56）。
* ❌ **表达式只有 `!` `&&` `||`**：无比较、无算术、**无 `length`、无聚合、无集合运算**（skill:language.md:143-144；设计标准 §2.7.1 P2）。
* ❌ **页面里没有客户端脚本**：AUP 页面不能写 JS；Web Device 组件能写 JS（`.web/`）但**服务端与客户端都拿不到 AFS**（S1-03 §3.2/§3.3）。
* ❌ **无 capability 求值**：`$session` 只有 `authenticated/did/displayName/role/authMethod/isAdmin/isOwner`，63 个原语里没有 capability/role 求值 ⇒ **按能力运行期隐藏菜单/按钮 = 不可表达**（§54）。

### 4.2 事件类型（仓库实证）

| 事件 | 状态 | 证据 |
| --- | --- | --- |
| `click` | ✅ 主力（52 处），接 `exec` / `afterSuccess` / 链式 exec | `.aup/pages/admin/posts.aup:196-219` |
| `select`（`afs-list` 行） | ⚠️ **只能 `set` 到别的节点，不能导航** | `events={select:[{target: qa-title, set:{state:{value:$args.item.title}}}]}`（`.aup/pages/site/heroes.aup:184`）；`navigate` 目标被 entry 覆盖 args 后**失效**（skill:runtime-gotchas.md:36-39） |
| `nav-click` / `user-menu-item` | ✅（`app-header` 专用） | `.aup/wrapper.aup:42`；品牌 `src` 无 handler 会每次点击报 `Node '<id>' has no 'nav-click' event`（§14b） |
| `tab-change` / `chip:dismiss` / `onChange`（`pagination`） | 平台会发，但**设计不可依赖**（`pagination.onChange` 实测无可观察效果，§38(4)） | §21.13、§38(4) |

### 4.3 导航与写入

* `-> page <name>`：同标签页内**整页子树重建**（框架不动、无文档重载）（§21.12）。
* `view href` / `action href` + `target=_blank`：运行时自动补 `rel="noopener noreferrer"`（§21.10）；`-> navigate "url"` **不支持 target**（同 §21.10）。
* `exec "/.actions/write"`：授权来自 `blocklet.yaml` 的 `replicated` 集合；**新建路径确定可用**，写**已存在**记录可能被拒（优先最小写入面 `tree-merge`，§29.2）；`content` 必须是 JSON 字符串（§28.4）；`${entry.*}` 在 `args` 里**不求值**（必须走行内隐藏 input，§29.1）。
* 局部刷新**只有区域级**：`afs-list subscribe=true`（WS + 45s 轮询兜底）（§21.11）。

### 4.4 三条硬规矩（写设计文档时不得违背）

1. **徽标 / 指标数字不得由页面自算。** 没有 `length`/聚合原语 ⇒ 页内任何计数都是编造。唯一合法来源是**平台自己给的** `afs-list` 分页器 `Total: M records`（设计标准 §2.7.1 P2 裁定、§4.8）。⇒ 设计稿里的 KPI 数字要么删，要么改成「平台数字」。
2. **不得用 `disabled` 冒充「按能力隐藏」。** 平台无 capability 求值（§54）；`disabled` 不在任何已验证的 prop 清单里（仓库 0 处使用、schema 的 `props` 是 `additionalProperties: true` 且无该键）。设计标准 §6 的口径是「**隐藏而不是禁用**」。⇒ 权限只分「登录 / 管理员」两档（同一页内两个互斥 `visible`），其余一律**如实标注「需 CLI / 本机 worker」**并把命令渲染成可复制行。
3. **不得用条件闸门做空态。** 互斥 `visible` 在异步数据上不成立（BUG-001：有 27 条标签**同时**渲染空态卡，§28.1），页级元素也**无法探测列表长度**（§4.8）。⇒ 空态一律写成**恒定成立**的常驻说明 + 平台破折号 `—`；文案不得断言「队列为空」。

## 5. 响应式与可访问性

### 5.1 平台侧已知结论

* **视口 / 断点**：桌面优先；现有全部实测口径只有 **1803×908** 与 **1512×765**（设计标准 §2.6 / §9 断言前提）。**AUP 面（`.aup/`）0 处媒体查询**（`grep -rc '@media' .aup/ --include=*.aup` 全 0）—— `@media` 只存在于 `.web/`（Web Device 组件与主题层，例：`.web/components/theme-bridge/script.js:73` 的 `≤640px` footer 回退、`hero-carousel/style.css:301`）。
* **布局宽度**：侧栏 `clamp(200px, 15vw, 280px)` + `flexShrink: 0`（`.aup/pages/admin/posts.aup:66`）⇒ 窄屏时侧栏仍占 200px；`flexWrap` 不可用 ⇒ **不能承诺「窄屏自动堆叠/换行/内容区不横向滚动」**。
* **命中区（WCAG 2.5.8）**：`≥24×24` 只能靠 `padding` 或平台 `size` 档（`minHeight` 被静默丢弃，§29.6）。平台原生 `copy`/`QR` 按钮实测 **18×18**、footer 链接 **17px** —— 已由主题层 `CHROME_CSS` 提到 `24×24` / `28.8px`（`.web/components/theme-bridge/script.js:104,108`）。
* **对比度（WCAG 2.1 AA）**：`variant=destructive` 平台静息 **3.99:1** / hover **3.64:1**（均破 4.5:1）⇒ 主题层三行覆写后 10 个 palette/mode 组合复算静息 10/10、hover 10/10 均 ≥4.5（设计标准 §3.1/§4.3）。
* **字号度量**：同一按钮档位实测 **en 36px / zh(CJK) 38px**、`size=sm` 29px（§21.6）⇒ 设计稿**不得写死高度或宽度**，要容忍中英文 2 倍长度差（设计标准 §7）。
* **`aria-*` 由谁负责**：**平台**。页面能碰到的语义入口只有两个 —— `action ariaLabel=`（`.aup/wrapper.aup:42` 主题切换按钮）与 `view role=`（`role` 连 `arc dsl schema` 里都没有，靠约定；`afs-list` 行模板的 `role=item` 是**必需**的，§28.3）。平台负责的：`active=true` → `data-active="true"` + `aria-current="page"`（§23）；`breadcrumb` 末项 `aria-current="page"`（skill:primitives.md:80）；`target=_blank` 自动补 `rel`（§21.10）。⇒ **设计不能要求页面上有 `<h1>` 语义层级、`aria-live`、表单 `label→input` 显式关联或焦点管理**（页面上不可表达）。

## 摘要（给主笔，10 条以内）

1. **布局只有一套配方，没有第二套。** 48px wrapper 顶栏 + 页面根 `height: calc(100vh - 48px); overflow: visible` + 全出血 `row`（`100vw` + 负 margin）+ **唯一**滚动容器 `view size={flex:1} style={overflowY:auto}`。`--aup-content-max`（实测 1200px）cap 页面根直接子元素且 `!important` 不可覆盖 ⇒ 全出血必须发生在更深一层（§24、§21.2/§21.4、`posts.aup:56,65,169`）。
2. **吸附、悬浮、嵌套滚动、拖拽、窄屏堆叠都不可表达**（`position` 不在 67 键白名单、`transform` 被清洗、无 drag 原语、`flexWrap` 被丢、无媒体查询入口）。设计稿里画这五类，实现阶段必然静默降级。
3. **组件契约里最容易踩的三条**：`action` 的 `style` 走**更窄**通道（`minHeight`/`alignSelf`/`width` 静默丢弃 ⇒ 命中区只能靠 `padding`）；`afs-list` 的行子元素被强制 `flex:1 1 0%`（固定尺寸元素必须 `flexGrow:0` + `flexBasis:"auto"`）；`emptyText` **完全不生效**且会变成「活着的死键」（§29.6/§29.8、§20/§28.6）。
4. **列表能力被目录边界钉死**：`filter`/`serverFilters` 只覆盖 ≤ ~1.8 KB 内联记录且编辑后索引 stale ⇒ **不做筛选 UI**，分页只用 `afs-list pagination=manual pageSize=N`（`pagination` 原语 `total` 必须静态 ⇒ 本仓 0 使用）；`total<=pageSize` 时平台不渲染控件 ⇒ 不得伪造入口，并必须带 BUG-063 常驻恢复说明（§15.1、§44.2、§38）。
5. **条件渲染只有「同步 `$session.*`」可靠**，异步数据上的 `visible` 闸门语义是坏的 ⇒ 权限只分「登录 / 管理员」两档，空态只能写成**恒定成立**的常驻说明 + 平台破折号（§28.1、§56、§54）。
6. **三条硬规矩**：① 徽标/指标数字不得页面自算（唯一合法源 = 平台分页器 `Total`）；② 不得用 `disabled` 冒充按能力隐藏（无 capability 求值 ⇒ 只分两档或如实标注「需 CLI」）；③ 不得用条件闸门做空态。
7. **交互事件只有 click / select / nav-click / user-menu-item 可用**，其中 `select`（行点击）**只能 `set` 到别的节点、不能导航** ⇒ 「点击行跳转」必须改画成行内链接（skill:runtime-gotchas.md:36-39、`heroes.aup:184`）。
8. **视觉可达性靠主题层兜底，不靠页面**：`backgroundImage`/`transform`/`wordBreak`/`flexWrap` 被丢；`card` 的 hover lift 关不掉（面板改普通 `view`）；destructive 对比度 3.99:1 与平台 18×18 按钮命中区都由 `.web/components/theme-bridge/script.js` 的 `CHROME_CSS` 修（`.web/themes/*/tokens.json` **不参与控制台**）。
9. **主题闪烁是硬边界**：`mode` 只接受 `light|dark`，运行期每次导航重置 `data-mode` ⇒ 编译值必须等于站点实际外观，否则一半访客每次导航闪 ~300ms（§17）。
10. **本文的诚实边界 = §5.2 的 8 条未验证项**（最要紧的是 **U1「窄屏侧栏是否折叠」在仓库里没有实现证据**、**U2 sticky 未验证**、**U4 那批「已实现但本仓零使用」的原语契约未验**）。设计文档若要用这三类，先按表里的方法探针，再落笔。
