## 3. 唯一出处原则（本目录的写作纪律）

| 规则 | 出处 |
| --- | --- |
| **同一事实只在一处定义**，其它地方**引用**（不抄第二份） | [总纲 §3.2](../README.md) |
| **数据字段**（状态/阻塞/计数）**只能引用唯一出处的编号或取值**，**不得重判**（`P17`） | [`07/05 §3`](../07-团队与开发规范/05-文档与代码规范.md) |
| **原始证据不是规则来源**：`docs/05-开发文档/附件/`、`docs/08-其他/附件/` 的逐字转录只作**证据**；引用须**全路径** + 注明**它是原始证据转录、不是现行结论** | [总纲 §3.3/§5](../README.md) |
| **数字**一律"**实测 + 口径 + 可复算命令**"；"共 N 条"必须能给命令 | [`07/05 §2`](../07-团队与开发规范/05-文档与代码规范.md)（`P5`/`P10`/`P16`） |
| **计数不写预期**；项目已有权威计数器就先用它（如 `bash docs/02-产品需求/_count.sh`） | [总纲 §3.2](../README.md) |

> 本目录两篇**派生型**文件（`00` 地图 / `05` 错误码索引）**最容易违反 `P17`**——它们**只能引用** `docs/01`–`docs/07` 的编号与取值，**不得"按同样规则重判一遍"**。

## 4. 本目录的机检门

```bash
bash docs/08-其他/_gate.sh     # 0 = PASS ｜ 1 = FAIL ｜ 2 = 环境异常
```

| 判据 | 内容 |
| :-: | --- |
| **A0 必需文件齐（名字精确）** | `_提纲.md`、`00-索引与阅读路径.md`、`01-决策记录.md`、`04-常见任务导航.md`、`05-错误码索引.md`、`README.md` **六件齐** ⇒ **缺一即 FAIL**（`P13`：缺失不得静默跳过） |
| **A1 索引完整** | `00` 必须提到 `docs/01`–`docs/08` **八个区域** |
| **A4 错误码可核** | `05` 列出的码**必须能在仓库里指到**（`scripts/**`，至少 3 个命中），且**给出口径命令** |
| **A5 形态 + 链接** | `_提纲` ≤200 行、其余 ≤400 行；单行 ≤800 **字符**；死链 = 0 |

> **门的唯一源 = `_gate.sh`**（不要在本文件另抄一份判据：**两处维护必然漂移**，`P17`）。
> **判据要能红**（`P1`/`P11`）：本门 A0–A5 每条都有 FAIL 分支；**变异自证**由审查者/Lead 执行。
