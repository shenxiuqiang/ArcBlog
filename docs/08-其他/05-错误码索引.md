## 1. 这些码从哪来（唯一实现来源）

错误码的词表**集中在两个地方**，其余脚本只**使用**：

| 角色 | 位置 | 说明 |
| --- | --- | --- |
| 通用抛错器 | [`scripts/lib/arc.mjs:101-109`](../../scripts/lib/arc.mjs) | `fail(code, message)` + `ensure(condition, message, code = 'VALIDATION')`；注释自述"`code` matches docs/error-codes.md"（**归档路径**——现行对照见本篇） |
| 生命周期脚本 | [`scripts/arcblog-lifecycle.mjs:258`](../../scripts/arcblog-lifecycle.mjs) | 自带 `fail()`；`validate` / `publish` / `draft` 等子命令的码从这里出 |

**成功形态**（与归档 `_docs/error-codes.md:45-49` 一致，实测来源）：

```bash
$ grep -n "ok: true" scripts/arcblog-lifecycle.mjs | head -3
361:  console.log(JSON.stringify({ ok: true, action: 'validate', slug, category, tags, coverImage, ogImage }, null, 2));
385:    console.log(JSON.stringify({ ok: true, action: 'publish', path: publicPath(slug), slug, status: next.status }, null, 2));
453:  console.log(JSON.stringify({ ok: true, action: 'publish', path, slug, status: next.status }, null, 2));
```

> **判据纪律（沿用 [`02-需求 00 §9`](../02-产品需求/00-需求地图与规范.md) 第 12 条）**：**平台 `arc` 子命令出错时退出码仍可为 0** ⇒ 判据必须**解析 JSON 的 `success`/`code`**；**自建 CLI** 失败时 exit 1，可用退出码但**仍建议解析 JSON**。**本篇不复述该规则**，只引用。

## 2. 索引表：**当前实现实际返回的 7 个码**（【已实现】，证据 = `scripts/**:行`）

> 「实现来源」列给**定义点**（非 `*.test.mjs`）的**首个/最强**证据；一个码可能有多个抛出点，**以源码为准**。

| 码 | 语义（对照归档 `_docs/error-codes.md`） | 实现来源（`scripts/**:行`） |
| --- | --- | --- |
| `VALIDATION` | 缺必填字段（`title`/`slug`/`author-did`）、markdown 安全守卫、参数非法 | [`scripts/lib/arc.mjs:108`](../../scripts/lib/arc.mjs)（`ensure` 默认码）、[`scripts/arcblog-lifecycle.mjs:185`](../../scripts/arcblog-lifecycle.mjs)、[`scripts/lib/agents.mjs:314`](../../scripts/lib/agents.mjs) |
| `CONFLICT` | slug / 记录已存在，未给 `--update`；被引用而拒绝删除 | [`scripts/arcblog-lifecycle.mjs:410`](../../scripts/arcblog-lifecycle.mjs)、[`scripts/arcblog-category.mjs:93`](../../scripts/arcblog-category.mjs) |
| `NOT_FOUND` | 状态转换目标不存在 | [`scripts/arcblog-lifecycle.mjs:211`](../../scripts/arcblog-lifecycle.mjs)、[`scripts/lib/categories.mjs:123`](../../scripts/lib/categories.mjs)、[`scripts/lib/chain.mjs:457`](../../scripts/lib/chain.mjs) |
| `INVALID_TRANSITION` | 非法生命周期转换（例：`draft -> archived`）；**订单未 `paid` 时拒绝结算** | [`scripts/arcblog-lifecycle.mjs:379`](../../scripts/arcblog-lifecycle.mjs)、[`scripts/lib/economy.mjs:227`](../../scripts/lib/economy.mjs) |
| `FORBIDDEN` | Agent 工具对 agent **关闭**（买家隐私 / §130 默认关闭）或**无未过期 grant**；`authorize` 拒绝 `agent.admin` | [`scripts/arcblog-agent.mjs:208`](../../scripts/arcblog-agent.mjs)、[`scripts/arcblog-agent.mjs:239`](../../scripts/arcblog-agent.mjs) |
