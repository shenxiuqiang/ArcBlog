## 引用纪律（**唯一出处原则的例外面**）

1. **必须写全路径**，并注明「**原始证据**」——**不得**当成现行契约、**不得**只引它而绕过结论层。
2. **引用必须读完整节**，并**同时检查邻近的反证行**（只引"有利的那一半"，曾把【规划中】写成【已实现】）。
3. **`§N` 编号会变**：它是**转录件的内部编号**，**不得**当稳定标识——要引**事实句**。
4. **现行结论**永远以 `docs/01`–`docs/08` 的正文为准；本目录**不产生规则**。

> **性质**：本目录三份文件均为**逐字转录**（当时实测到的原文），**内容未被改写**；它们**不是现行契约**，引用时按上面的四条纪律处理。
