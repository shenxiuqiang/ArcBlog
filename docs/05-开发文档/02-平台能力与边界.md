### B20 细节（2026-10-12 实测与根因）

**根因**：面由 manifest 的 `collections.<名>.faces`（`web`/`sitemap`/`llms`/`mcp`）**显式开启且 fail-closed**（省略 `faces` 即关闭全部面）；其 `indexable` 是**仓库/包内文件 glob**（如 `content/places/**/content.md`），`scope: /packages`。本仓用 `replicated:` 声明 AFS 记录、内容在**运行时**写入实例（`/instance/app/arcblog/posts/*.json`）⇒ **没有任何集合能声明该面**，所以指针里没有集合小节、分片一律 404。

**官方出处（2026-10-12 读全文）**：`https://www.arcblock.io/zh/docs/agent-access/llms-txt/` 与 `https://www.arcblock.io/zh/docs/agent-access/declare-what-agents-see/` —— 两处 URL 里的 `agent-access` 只是**平台文档路径**，**不再是**本仓经济族词汇（门的 A3 词表在此为**已知假红**，见该门注释）。

**第一方证据**：`~/.arc/versions/2.0.0-beta.50/assets/blocklets/places-notebook/blocklet.yaml` 的 `collections:` 块 —— 含 `type`/`scope`/`indexable`/`readRole`/`defaultLocale`/`fields`/`summary`/`faces` 等键（逐字形态以该文件为准）；其 `faces` 用的是 `{web: true, sitemap: true, index: {}}`，与官方文档写的 `{llms: true, mcp: [search, list, get]}` 同族 ⇒ **以官方文档为面名口径，以本机示例为语法证据**。

**为什么现在不算缺陷**：`PRD-SITE-05` 的判据是"只读出口可用"，而指针本身可用（540 B 真实内容，并主动点名 `/mcp` 与 `/api/afs/rpc` 两条更强的面）；agent 读取内容的设计路径是 MCP/AFS RPC + 本仓工具，不依赖文本面。

**可选未来能力（未实施，方案留档）**：构建时把 AFS 文章导出为 `content/posts/<slug>/content.md`（新增导出步骤，**必须排在 `npm run build` 之前**），并新增 `collections.posts`（`indexable: ["content/posts/**/content.md"]`、`readRole: guest`、`faces: {web: false, sitemap: true, llms: true}`）⇒ 打开 `/p/llms-posts.txt` 分片与 sitemap。代价：导出步骤与 AFS 写入耦合（每次发布后需重新导出+构建），且与"内容在 AFS、页面在 AUP"的现有模型并行存在两套内容视图 ⇒ **需要产品裁决**后再做。

### B21 细节（2026-10-12 实测）

**服务端行为**：AUP 路由（`/posts/<slug>`、`/?page=<名>`）返回的是平台默认壳 —— `<html lang="en" data-tone="clean" data-palette="neutral" data-mode="dark">`、`<title>AFS</title>`、4866 B、标签仅 `div/link/script/span/meta/title`，**没有 `<h1>`、没有正文、没有 meta**（`__AUP_BOOT__` 也不在此路由的 HTML 里）。

#### B17 补：`/p/llms.txt` 的内容与指针（2026-10-12 实测）

- 正文**只有一句 `(no content yet)`** ⇒ 对 agent 而言这个"读取契约"**没有列任何内容**（`PRD-SITE-05` 只承诺"可用"，未承诺内容完整；但驱动它与 sitemap 的是同一个静态生成器，因此同因）。
- 它**指向根级 URL**：`Full-text version … https://arcblog.localhost/llms-full.txt` —— 实测该 URL 是 **200 `text/html`**（应用壳），真身在 **`/p/llms-full.txt`**（`text/plain`）⇒ **平台自己生成的文本指向平台自己吞掉的路径**（与 B17 主体同一类）。
- 同一文本里的另三个指针**是对的**：`/.well-known/mcp.json`（200 JSON）、`/api/afs/rpc`（POST 200 JSON）、`/mcp`（405 JSON，POST 可用）。
