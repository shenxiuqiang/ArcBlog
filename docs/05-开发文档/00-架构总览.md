## 1. 五层分层图

```text
① AUP 面        .aup/**（pages/ wrapper/ app.aup/ locales/）—— 声明式 DSL，无运行时依赖
② AFS 记录面    /instance/app/arcblog/**（post/node/economy/hub/config/…）—— 唯一持久层
③ 工具与队列消费面 scripts/*.mjs（32 CLI：**1 个独立 worker 文件** + **7 个 CLI 的 `apply|watch` 子命令**）—— Node 脚本，操作 ②
④ 链适配器面    scripts/lib/chain.mjs（mock | ocap）—— 环境变量选链，fail-closed
⑤ 构建产物面    app.json / pages/*.json / wrapper.json / locales / dist/ —— 由 ① 生成与打包
```

| 层 | 谁能写 | 证据 |
| :--: | --- | --- |
| ① | `arc dsl generate --write`（从 `.aup`）；**手改生成物没有自动门**——`arc dsl generate --check` **不在**快层（`grep` 命中 0，见 [`05 §7`](05-测试分层与质量门.md) G4，补门登记为 Stage 6 功能点） | `S5-01 §1`；`05 §7` 实测 |
| ② | 页面 `exec /.actions/write`（经 `blocklet.yaml` replicated 授权）**或** ② 的 CLI / 队列消费方 | `S5-01 §3`（写入路径矩阵） |
| ③ | 人（CLI）或队列消费方自身（由人/页面意图触发） | `S5-01 §3/§4`；[`01 §5`](01-数据模型与存储.md) |
| ④ | **只有** CLI / 队列消费方；**页面与 DSL 不得携带链地址或代币符号** | `CLAUDE.md` 链环境节、`S5-02` |
| ⑤ | `npm run build`（唯一安全入口） | `S5-03 §1`、BUG-067 事故 |

## 2. 两条写入通道（**不要混用**）

| 通道 | 形态 | 授权 | 失败可见性 | 适用 |
| --- | --- | --- | --- | --- |
| **页面写入** | `exec "/.actions/write"` + `${args.*}` 模板 | `blocklet.yaml` 的 `replicated.<collection>`（`minRole: admin`，`copy: none`） | `onErrorToast`（**当前 9/14 页缺**，见 Stage 4 `07 §2`） | 表单类、队列意图 |
| **CLI / 队列消费方写入** | `node scripts/*.mjs …` | 本机执行（无页面会话） | 退出码 + JSON（**自建 CLI 失败 exit 1，可用作判据**） | 生命周期、链动作、批量、清理 |

**共同铁律（沿用 Stage 2 `00 §9` 第 12 条）**：**平台 `arc` 命令出错时 `$?` 可能仍为 0** ⇒ 判据必须解析 JSON `success`/错误码；**自建 CLI 脚本**的退出码可用。
**队列范式**：任何"页面写入 + 异步生效"的场景走**意图队列**（8 条，唯一定义见 `01 §3`），页面只显 `pending｜running｜applied｜rejected｜noop`。

| `categories/` | guest | 分类taxonomy | CLI/页面（队列） |

| `node/{profile,identity,discovery,health}.json` | guest | 节点身份与网络只读面 | CLI |
| **`node/factories.json`** | guest | **节点 NFT 公开投影**（适配器/链/工厂/各角色生命周期） | 链 CLI 每步后写 |
| `config/roles.json` | **admin** | 角色/NFT 配置（**可能被 live 测试复位**） | CLI |

| `economy/{orders,settlements,ledger,access-grants,refunds,attributions}/` | **admin** | 订单/结算/账本/凭据/退款/归因 | **仅 CLI**（页面只读） |
| `hub/{registrations,index}/` | **admin** | Studio→Hub 注册与派生索引 | 页面/CLI |

**链上事实的唯一权威 = `node/factories.json#nodes.<role>`**（Stage 2 `05-ID §1.1` 裁决；`factories.<role>` 是注册表投影、`config/roles.json` 与 `roles status` 是**本机视角**，**不得互相做一致性比对**）。

## 4. 运行时与构建产物

```text
.aup/**  --arc dsl generate --write-->  app.json / pages/*.json / wrapper.json / .aup/locales/*.json
        --npm run build (= arc blocklet build + scrub:dist-secrets)-->  dist/（部署产物）
/p/     SSR Web Device 处理器（theme-bridge、hero-carousel 等组件页）
/        AUP handler（页面路由；`/.well-known/*` 与 `/api/*` 在本平台不可达）
```

- **页面分组**（实测 2026-09-30，`find .aup/pages -name '*.aup' | wc -l` = **30**，与 `.aup/app.json` 的 `pages` 键数一致）：`pages/admin`（**8**）｜`pages/site`（5）｜`pages/ops`（**5**）｜`pages/economy`（**4**）｜顶层公开面（8）——共 **30 个 `.aup` 页面文件**；控制台可见 **21 行 = 21 页** + 子页 `compose-edit`（`hasSidebar=false`）。
- **写接线页数 = 14**（`S5-01` 实测，**非 22**）；**队列消费方 = 8 条队列**（**非 4**），真实形态 = **1 个独立 worker 文件**（`arcblog-chain-worker.mjs`）+ **7 个 CLI 的 `apply\|watch` 子命令**（逐条命令见 [`01 §5`](01-数据模型与存储.md)；`ls scripts/ | grep -i worker` 只有前者）。
- **`dist/` 的生成与门**：由 `npm run build` 生成、随源码同步；**提交前必须重跑**且 `arcblog-dist-secrets --check` ok。**裸 `arc blocklet build` 会把 `node.key`/`.env.local` 复制进 `dist/` 并写进 `dist/.afs/manifest.json`**（BUG-067，平台无 ignore 开关）——**只用 `npm run build`**。
