## 1. 架构总图（三段）

```text
① 链（发现层）        所有节点把 studio NFT 质押到同一 factory 地址
                      ⇒ 查该地址的质押列表 = 全部在运行节点（链上注册表）
② 节点（存储层）      每个节点自有 AFS 空间（内容）+ NFT data（可达信息）
                      节点之间不互相登记、不经平台中继
③ 用户侧（聚合层）    agent 在应用之外运行：发现 → 汇总 → chat → 生成 → 发布
```

| 段 | 要点 |
| --- | --- |
| ① 发现 | **链上注册表**（`listStakes(receiver=factory)`）；**没有 AFS 登记关系** |
| ② 节点 | 内容存 AFS；**可达信息（`endpoint`/`region`/`appName`）存 NFT `data.value`** |
| ③ 聚合 | **agent 主干**，跑在应用之外；AUP 应用**无运行时依赖** |

## 3. 目录与页面（**实测 + 口径**）

| 事实 | 实测 | 口径 / 复算命令 |
| --- | :-: | --- |
| 页面文件 | **25** | `ls .aup/pages/*/*.aup .aup/pages/*.aup \| wc -l` |
| 控制台侧栏行 | **17** | `node -e "import('./scripts/console-nav.mjs').then(m=>console.log(m.CONSOLE_SECTIONS.length))"` |
| AFS schema 文件 | **12** | `ls world/*.yaml \| wc -l`（分组见 [`01 §2`](01-数据模型与存储.md)） |

**分目录实测（2026-10-12，命令同下）**：`ls .aup/pages/admin/*.aup` = **8**、`site/` = **5**、`ops/` = **5**、顶层 `pages/*.aup` = **7**（合计 **25** = 上表"页面文件"）；其中**控制台导航节** = **17**（`CONSOLE_SECTIONS.length`）——差额 = `pages/admin/compose-edit.aup`（从 studio 草稿列表进入的**编辑页**，不是导航节）。

**口径说明**：上表**只写实测值**；两套界面集合（控制台行 / 公开面页）的唯一真源 = `scripts/console-nav.mjs` 与 `.aup/pages/**`。
**增删页面的连带后果**：增删行 ⇒ 必须重跑 `node scripts/arcblog-console-nav.mjs`；`ui-budget` 棘轮基线随之调整（**取测试实际输出**）；**`runtime-ids` 不在其列**（详见 [`docs/04-UI设计规范/00 §4`](../04-UI设计规范/00-总则与形态纪律.md) 与 [`05-测试分层与质量门`](05-测试分层与质量门.md) §3）。
