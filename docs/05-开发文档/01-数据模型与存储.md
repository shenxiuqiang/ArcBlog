## 3. 目录边界（**draft 边界靠目录，不靠字段**）

| 事实 | 说明 |
| --- | --- |
| 表达语言限制 | AUP 表达式只支持 `$session.*`/`$state.*` 上的 `\|\|`/`&&`/`!`，**无比较** ⇒ 无法按 `status` 做可见性门 |
| 因此 | **`posts/` 只放已发布**（访客可读）；**`drafts/` 放草稿/归档/软删**（admin-only） |
| 生命周期 | `draft → published → archived → published`，外加 `draft\|archived → deleted`（软删） |
| **索引陈旧** | `afs-list` 的 `filter`/`serverFilters` 走**索引**；**编辑记录会让索引项变旧** ⇒ 该记录会从过滤列表**静默消失**（规避 = 目录边界 / `propBind` 单记录读；见 [`docs/03-产品设计/02 §2`](../03-产品设计/02-公开面.md)、[`docs/04-UI设计规范/03 BD-05`](../04-UI设计规范/03-状态与降级.md)） |

> **【未验证】**：真链上 `listStakes` 的**分页/延迟/上限**未知（生产用法为 `size=10` + cursor）；类型声明曾把四个 filter 字段标为必填，而方法实际收 `PartialDeep<>` ⇒ **形状未验证**。验证方法 = [`07`](07-未决技术问题与探针计划.md) 的 **`P-1`**（mock：返回条数 = 质押数）与 **`P-2`**（真链只读）；判定式 = 未质押者不出现。

## 4. 公开投影（`node/factories.json`）

| 项 | 内容 |
| --- | --- |
| 写者 | 链 CLI 在每次生命周期动作后写（**地址与 tx 哈希**，**绝不含密钥**） |
| 读者 | 任意登录会话的控制台页（`?page=factory`） |
| 为什么需要 | 权威记录在 `config/`（admin-only）⇒ **需要一个公开投影**让控制台可用 |
| 与"注册表"的区别 | `factories.json` 是**本节点自己的**链事实；**全网节点列表**来自**链上注册表**（不是在 AFS 里登记） |

## 5. **节点自描述不在 AFS**

| 项 | 位置 | 状态 |
| --- | --- | --- |
| `endpoint` / `region` / `appName` | **链上 NFT 的 `data.value`**（CBOR/JSON，`updateAsset` 写） | 接口 SDK 有；**本项目适配器未接** ⇒ **【规划中】** |
| 谁能读 | 任意 agent / 第三方只读工具（**不依赖本仓库代码**） | 【已实现】（机制）/ 本项目消费 **【规划中】** |
| 撤销时 | **清"质押时写入的字段"**（`endpoint`/`region`/`appName`）；**mint 时字段（`owner`/`pk`）不动** | 语义**已定**；接口【规划中】 |
| 下线判定 | **以 stake 记录为准**（链上事实），不靠"data 解析失败" | 已定 |
| 转让 | `TransferTx{to,value,assets[],data}` 经 `signTransferTx → sendTransferTx`（**beta + TBA 测试币**） | **【规划中】**（**未跑过**，不得写成已能买卖） |
| 署名 | 内容签名（`--sign-key`）**保留且在用**：署名可信是与 agent 协作的前提 | 【已实现】 |
