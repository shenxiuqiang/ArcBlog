## 2. 写入路径矩阵（**每集合的每条写入路径**）

| 集合 | 页面路径 | CLI / worker 路径 | 幂等性 |
| --- | --- | --- | --- |
| `posts`/`drafts` | `exec /.actions/write`（`compose`/`compose-edit`/`preview`） | `arcblog-lifecycle publish/archive/delete` | 同 slug 覆盖；**编辑不改 id** |
| `pages` | 队列 `pages/intents` → worker | `arcblog-pages` | 上下线幂等 |
| `heroes` | 页面写 + 队列 | CLI | 由 `sort` 排序，重复写不产生第二份 |
| `media` | **无**（页面仅索引/清理意图） | `arcblog-media add/remove --force` | `remove` 有引用冲突即拒 |
| `categories`/`tags` | 队列 `config/*-intents`、`tags/intents` | `arcblog-category`、`arcblog-tags` | 合并/重命名幂等（**worker 未运行不得改库**） |
| `node/*` | 无 | `arcblog-node`、`arcblog-network` | 覆盖写 |
| **`node/factories.json`** | 无（页面只读） | 链 worker 每步后写 | 全量重算（**含 SVG**） |
| `config/roles.json` | 无（页面只读） | `arcblog-roles state set` | **fail-closed**；`revoking` 会 Tombstone Hub 关系 |
| `config/agent-grants` | `agents` 页 | `arcblog-agent authorize` | 同 `didHash` 覆盖；**TTL 到期即拒** |
| `economy/orders` | 队列 `order-intents` → worker `order apply` | `arcblog-economy order …` | 以 **AFS 记录数 +1** 为准（**toast 不算证据**） |
| `economy/ledger` | 无 | `order pay`/`refund`/结算 | **append-only**，id = `<orderId>:<type>` |
| `economy/access-grants` | 无 | `order pay` 后 | 每 order 一份 |
| `hub/registrations` | 页面（队列） | `arcblog-network hub list/refresh/index rebuild` | 注册幂等；`tombstone` 只增 |

**14 页有写接线**（`S5-01` 实测）；**8 个 worker**（见 §5）。**页面写接线 = `exec "/.actions/write"` 或 `/.actions/delete`**（无此二者的页**不得**声称"页面可写"）。

## 4. 投影与只读面

| 投影 | 生成者 | 权威关系 |
| --- | --- | --- |
| **`node/factories.json`** | 链 CI/worker | **链上事实唯一权威 = `nodes.<role>`**；`factories.<role>` 是**注册表投影**（`adapter:"unknown"`、`simulationUnknown:true`），**不得**用来判"已上链" |
| `node/discovery.json` | `arcblog-network hub refresh` | 只读派生；**不得**写"已同步" |
| `economy/policies`、`economy/products` | 页面/CLI | **价格唯一真源 = `economy/products`**（spec §45：价格在 Product 上、永不在 post 上）；`posts` 只带 `productId` 引用 |
| `.aup/locales/*.json` | `arc dsl generate` | 生成物；`wrapper.*` 为**手工维护**唯一例外 |

**三条不得混淆的记录**（Stage 2 F2 裁决）：`node/factories.json#nodes.<role>`（链上权威）／`config/roles.json`（本机配置，**可能被 live 测试复位**）／`roles status`（CLI 本机视角）。**二者与权威之间不得做一致性比对**。

## 5. 八个 worker

| # | worker | 消费 | 触发 | 失败残留 |
| :-: | --- | --- | --- | --- |
| 1 | `arcblog-lifecycle-worker` | 文章生命周期意图 | 定时/手动 | 意图保留 `pending` |
| 2 | `arcblog-media-worker` | `media-intents` | 手动 | 同上 |
| 3 | `arcblog-tags-worker` | `tags/intents`、`tag-intents` | 手动 | 同上 |
| 4 | `arcblog-pages-worker` | `page-intents` | 手动 | 同上 |
| 5 | `arcblog-roles-worker` | `role-intents` | 手动 | fail-closed |
| 6 | `arcblog-economy order apply` | `order-intents` | 手动 | order 留 `pending` |
| 7 | `arcblog-chain-worker watch/run` | `chain-intents` | watch/手动 | 意图保留；链失败不改投影 |
| 8 | `arcblog-economy … access/settlement` worker | 结算/凭据 | 手动 | 幂等重跑 |

**共同纪律**：worker **幂等**（重复跑不得产生第二份）；**失败必须留痕**（意图不静默丢弃）；**链动作必须有 `chainVerification` 之外的独立证据**（`node/factories.json` + 链上 tx hash）。

## 6. 数据完整性与读取口径

- **必填**：`title`/`slug`/`author-did`；分类白名单从 `categories/` 读（空则回退 `technology|design|life`）；tags = 小写下划线、≤10；`coverImage`/`ogImage` 必须 http(s)。
- **索引陈旧（C1 相关）**：`afs-list` 的 `filter`/`serverFilters` 走索引，**编辑后索引条目 stale** ⇒ 影响列表的写入必须**同时刷新索引**（见 `06-运维场景手册`）。
- **分页口径**：**唯一定义 = [`04-流程 §2.1`](../03-产品设计/04-流程与跨页契约.md)（C1）**；本篇不复述。
- **`content.` 前缀探针（Stage 5 必查，见 `07 §4`）**：`store.aup:21` 现用 `filter={field:"content.visibility"}`。契约 §44.1 记载 **`content.status`/`content.category` 一律 0 命中（静默）** ⇒ 需**只读对比**（同集合用带前缀 / 不带前缀两种 `where` 比较命中数）。**在实测出结论前，本文不得断言"商店目录恒空"**。
- **append-only**：`economy/ledger` 只增不删；`deterministic id` 使按 order 读取 O(1)，全量读取须分页。
