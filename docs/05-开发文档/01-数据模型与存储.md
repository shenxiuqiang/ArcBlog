## 3. 目录边界（**draft 边界靠目录，不靠字段**）

| 事实 | 说明 |
| --- | --- |
| 表达语言限制 | AUP 表达式只支持 `$session.*`/`$state.*` 上的 `\|\|`/`&&`/`!`，**无比较** ⇒ 无法按 `status` 做可见性门 |
| 因此 | **`posts/` 只放已发布**（访客可读）；**`drafts/` 放草稿/归档/软删**（admin-only） |
| 生命周期 | `draft → published → archived → published`，外加 `draft\|archived → deleted`（软删） |
| **索引陈旧** | `afs-list` 的 `filter`/`serverFilters` 走**索引**；**编辑记录会让索引项变旧** ⇒ 该记录会从过滤列表**静默消失**（规避 = 目录边界 / `propBind` 单记录读；见 [`docs/03-产品设计/02 §2`](../03-产品设计/02-公开面.md)、[`docs/04-UI设计规范/03 BD-05`](../04-UI设计规范/03-状态与降级.md)） |

> **已验证（2026-10-01）**：`P-1`（mock：返回条数 = 质押数、未质押不出现、游标可续）与 `P-2`（真链只读：`{addressFilter:{receiver}, paging}` 最小形状被接受、`code: OK`、cursor 分页可续、延迟 ~1–2.3 s）均已通过——原样输出见 [`07`](07-未决技术问题与探针计划.md) 行内。

## 4. 公开投影（`node/factories.json`）

| 项 | 内容 |
| --- | --- |
| 写者 | 链 CLI 在每次生命周期动作后写（**地址与 tx 哈希**，**绝不含密钥**） |
| 读者 | 任意登录会话的控制台页（`?page=factory`） |
| 为什么需要 | 权威记录在 `config/`（admin-only）⇒ **需要一个公开投影**让控制台可用 |
| 与"注册表"的区别 | `factories.json` 是**本节点自己的**链事实；**全网节点列表**来自**链上注册表**（不是在 AFS 里登记） |
