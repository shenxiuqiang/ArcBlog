## 1. 构建（**只用 `npm run build`**）

| 项 | 内容 |
| --- | --- |
| 唯一安全入口 | **`npm run build`** = `arc blocklet build` + **`npm run scrub:dist-secrets`** |
| 为什么 | **引 `B11`（见 [`02 §2`](02-平台能力与边界.md)）：平台无 ignore 开关 ⇒ 只能用 `npm run build`（含 `scrub:dist-secrets`）；BUG-067 的边界定义以 `02` 为准** |
| 何时跑 | 改了 `.aup/**`、`blocklet.yaml`、`world/**` 时必须跑；纯文档改动**不需要** |
| 复算命令 | `node -e "const d=require('./package.json');console.log(d.scripts.build, '|', d.scripts['scrub:dist-secrets'])"` |

| **发布面（新增，2026-10-12）** | `dist/` **只发布运行所需**：`docs/`、`_research/`、`scripts/` 属**源码材料**，运行期**只被当作展示文本**（可复制命令/空态提示；`exec`/`action`/`src=`/`url=` 一律不引用，已 grep 证）⇒ scrub 连同**manifest 条目**一起删除。实测：**498 → 236 文件**（5.0 → 2.1 MB），manifest **496 → 234** 条。政策常量 = `NON_PRODUCT_DIRS`（`scripts/arcblog-dist-secrets.mjs`）；`--check` **只报不红**（`nonProductFiles`），因为"多发了源码"是浪费、不是泄漏 |
| 复算 | `node scripts/arcblog-dist-secrets.mjs --check` 看 `nonProductFiles`（期望 **0**）；`python3 -c "import json;m=json.load(open('dist/.afs/manifest.json'));print(len(m['files']))"`（期望 **234**，且无 `docs/`/`_research/`/`scripts/` 前缀）|

**纪律**：**禁止**把裸 `arc blocklet build` 写进任何流程；**禁止**删除 `node.key` / `.env.local`（它们必须留在仓库根且**不进 `dist/`**）。

## 2. 链环境（**由环境选择，不由代码选择**）

| 项 | 内容 |
| --- | --- |
| 预设开关 | `ARCBLOG_CHAIN_ENV=beta\|main` ⇒ 只**填默认**（GraphQL host / network / chain id / mint token / decimals），常量 = `CHAIN_PRESETS`（`scripts/lib/chain.mjs`） |
| **beta** | host = **`https://beta.abtnetwork.io/api`**；**原生代币 = TBA** |
| main | 原生代币 = **ABT** |
| 显式覆盖 | `ARCBLOG_CHAIN_HOST` / `NETWORK` / `CHAIN_ID` / `TOKEN_ID` / `TOKEN_DECIMALS` / `MNEMONIC` **始终优先** |
| 记录级回退 | `config/roles.json` 是**唯一**的记录级回退；其 `network` 与所选预设**不一致即 fail-closed**（**不静默混环境**） |
| `--adapter ocap` | 写链**之前**就要求 **`network` + `chainHost` + `tokenId` 三件套**；之后**仍需助记词**，否则回 **`CHAIN_UNAVAILABLE`** |
| 证据 | `scripts/lib/chain.mjs:150-156` 注释区（beta host + TBA + decimals 18，注明"**页面读记录、从不读这些常量**"） |
| 复算命令 | `grep -n 'beta.abtnetwork.io\|native token on beta' scripts/lib/chain.mjs` |

> **引用限定范围**：`chain.mjs` 该注释区的范围是"**预设默认值**" —— 它**不**代表真链可用性，也**不**代表本项目已跑通链流程（见 [`01 §5`](01-数据模型与存储.md) 与 [`02 §3`](02-平台能力与边界.md) 的三处缺口）。

## 3. 部署与运行形状

| 项 | 内容 |
| --- | --- |
| 实例 | AUP 应用部署为 Blocklet（`scope: app`），内容在实例空间 `/instance/app/arcblog/**` |
| 路由 | `.route/` 两个挂载：`/` → AUP app handler；`/p` → SSR（Web Device）处理器 |
| **`.route/web` 的服务根** | 服务的是**仓库根**，**不是 `dist/`** |
| 因此 | **`/p/rss.xml` 必须生成到仓库根 `.web-cache/rss.xml`**（平台**不会**自动生成 RSS） |
| 生成命令 | `node scripts/arcblog-rss.mjs --feed-link "$BASE" > .web-cache/rss.xml`（`$BASE` = 节点公开基址） |
| 只读出口状态 | `/p/llms.txt`【已实现】；**`/p/rss.xml`【已实现】**：由**部署管线步骤 3b** 生成 + 部署后存活校验（裸 `arc blocklet build` 会重建 `.web-cache/` 抹掉它 ⇒ 用 `node scripts/arcblog-deploy.mjs`，见 `DEF-28`） |
| 页面写入 | 页面只写**意图**（`exec /.actions/write` / 意图队列）；生效在**运营侧**（CLI / worker） |
| 发布 | **必须在应用之外**：`node scripts/arcblog-lifecycle.mjs publish … [--sign-key node.key]` |

**复算命令**：`test -f .web-cache/rss.xml && echo 已生成 || echo "未生成（【规划中】）"`；`ls .route/`。

## 4. 密钥与地址纪律

| 条 | 内容 |
| :-: | --- |
| **K1** | `node.key` / `.env.local` **只在仓库根**（gitignored）；**绝不进 `dist/`**（构建走 `npm run build` 的 scrub 步骤） |
| **K2** | **任何页面 / DSL 文件不得携带链地址或代币符号**；控制台只读**公开投影** `node/factories.json` |
| **K3** | 助记词只经**环境变量 / `.env.local`**；缺失即 `CHAIN_UNAVAILABLE`（**fail-closed**） |
| **K4** | 公开投影只写**地址与 tx 哈希**，**不含密钥材料**（见 [`01 §4`](01-数据模型与存储.md)） |

**复算命令**：`grep -rIl 'z[0-9a-zA-Z]\{30,\}' .aup/ | wc -l` → 期望 **0**（无硬编码链地址）；`ls dist/.afs/manifest.json >/dev/null 2>&1 && grep -c 'node.key\|.env.local' dist/.afs/manifest.json || echo "dist 未构建"`。

## 5. 运行期自检与常见故障（**只列本项目能指的**）

| 症状 | 首查 | 依据 |
| --- | --- | --- |
| 构建后 `dist/` 出现密钥 | 是不是跑了**裸** `arc blocklet build` | **`B11`**（见 [`02 §2`](02-平台能力与边界.md)） |
| 阅读器拿不到 feed | `.web-cache/rss.xml` 是否生成（位置 = **仓库根**） | §3 |
| 链命令报 `CHAIN_UNAVAILABLE` | 三件套 + 助记词 | §2 |
| 环境混用 | `ARCBLOG_CHAIN_ENV` 与 `config/roles.json` 的 `network` 是否一致 | §2（fail-closed） |
| 页面过滤列表缺记录 | 索引陈旧（编辑后索引变旧） | [`01 §3`](01-数据模型与存储.md) |
