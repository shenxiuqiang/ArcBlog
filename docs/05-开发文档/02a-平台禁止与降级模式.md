## 2. 降级模式库（6 个）

## 3. 降级模式库

> 六条模式与 `S1-03 §3` 的 P1–P6 **同源、编号一致**；这里只补「适用于哪些 PRD + 本轮新增的验收证据」。

### P1 · 意图队列 + 本机 worker
- **适用场景**：需要写链、需要私钥 / 大计算、耗时超过一次交互（上链、索引重建、分类/媒体迁移、策略变更、授权签发）。→ `PRD-CNT-01/05`、`PRD-ECO-01/02`、`PRD-NET-02/05`、`PRD-AGT-03`、`PRD-OPS-05`。
- **实现要点**：页面只写 `<id>.json` 意图（`${args.*}` 走**隐藏 input**，**不得**直接写 `entry.*`/`$session.*`，§29.1/§34(2)）；队列目录全树 admin-only；worker 认领写 `running`；**终态必须带非空 `message`**；状态词表只有 `pending|running|applied|rejected|noop`（§33(1)）；`<id>.json` 之外的条目显式落诊断（§33(2)）；耗时写**真实** `elapsedMs`（§36(1)）。
- **验收判据**：AFS 记录本身变化（**不是 toast**，§29.4）；`afs-list subscribe=true` 能实时看到状态；终态带原因；只读对账四分类计数自洽（§36(2)）；页面与记录的 `elapsedMs` 逐字一致。
- **已知反例**：`config/chain-intents` 仍用旧词表 `pending|running|done|failed`，**改名会触发真实链写**，故未随 D36 改名（§33(1) 范围外残留，BUG-051）。

### P2 · 诚实降级（平台破折号 + 常驻说明）
- **适用场景**：首屏可能为空、动态值无法本地化、状态无法条件渲染、平台确实不提供该信息。→ `PRD-NET-04` A2/B2、`PRD-ECO-01` B7、`PRD-ECO-06` B2、`PRD-ECO-07` B2、`PRD-ECO-08` B2、`PRD-OPS-01`、`PRD-SET-03`。
- **实现要点**：空值渲染 `—`，同卡片内一句**恒定成立**的说明（把「—」读作「尚未绑定 / 暂不可用 / 未上链」）；不做「有数据才显示」的空态卡（§37(3)、§28.8、§36(2)）；常驻说明用 `scale=caption intent=muted`（`S3-03` 摘要 4）。
- **验收判据**：说明与数据状态**不矛盾**；**不同真实状态不得被同一句话断言成同一件事**（§28.8）；报告里不出现「链上已验证」除非真的 `verified`（§36(2)）；**不得**渲染成 `0` / `Online` / 绿灯 / 自造「尚无数据」字面。
- **已知反例**：BUG-001 用互斥 `visible` 做空态 ⇒ 27 条标签**同时**渲染空态卡；BUG-005 动态 `$t()` 三次探针全败；BUG-052/056/072（无条件空态断言）。

### P3 · CLI 折叠为高级 + 可复制命令
- **适用场景**：平台能力缺位（哈希、签名、迁移、媒体引用复核、内容运维、权限自证）。→ `PRD-OPS-02`、`PRD-ECO-08` A2、`PRD-AGT-03`。
- **实现要点**：页面**不假装能点**，渲染一条可复制的完整命令；命令走中央 flag 注册表（`--k v` ≡ `--k=v`，未知 flag fail-closed，§37(1)）；危险操作要求显式确认与**到期时间**（`arcblog-agent.mjs authorize` 强制 TTL）。
- **验收判据**：命令**原样可跑**且今天真能跑通（不是「将来会」）；`--help` 存在（已知缺口：`chain-worker` 无 help 面；`rss`/`query-posts`/`daily-report` 的 `--help` 不生效，§37(1)）。
- **已知反例**：`ops/agents.aup:16` 的授权签发即此模式（页面自认「AUP DSL 没有哈希原语，请用运营者 CLI」）。

### P4 · 角色 / 能力 fail-closed
- **适用场景**：任何「未验证就绝不能生效」的授权（节点角色、Agent 能力、付费全文、链上查询）。→ `PRD-ID-03/04/05`、`PRD-AGT-01/02`、`PRD-ECO-01`。
- **实现要点**：角色未验证 ⇒ **不授予任何能力**（`scripts/lib/roles.mjs`）；链适配器归属**逐节点**三态 `mock|ocap|unknown` + `simulated: true|false|null`，**禁止**把未归属写成 `simulated: false`（§33(3)）；链上查询只在「节点归属与 worker 适配器都为 `ocap`」时才发起，否则跳过并写**显式诊断**（§33(4)）。
- **验收判据**：拒绝路径有**显式原因**且零副作用；`mock`/`manual` **永远不得**声称「链上已验证」（§32(7)）。
- **已知反例**：`node/factories.json` 曾文件头 `adapter: 'ocap'` 而 `nodes.hub` 是 mock 残留 ⇒ 按文件头判定的消费者会把模拟事实当链上事实（§32(9)、BUG-043）。

### P5 · 生成器投影（取代 `include`）
- **适用场景**：跨页共享的导航、门禁卡、页头、空态。→ `PRD-SET-04`、`PRD-ID-07`（构建期多份侧栏）。
- **实现要点**：单源模型（`scripts/console-nav.mjs`）+ 生成器（`scripts/arcblog-console-nav.mjs`）+ `--check` 门禁；当前项用平台自己的 `active=true`（语法上必须写在 `-> page <name>` **之后**，§23）；生成器**不输出 id**，靠自身产出的稳定标记定位（§25.3）。
- **验收判据**：`--check` 在缺项/漂移/多个或零个 `active` 时**点名失败**（§23）；`arc dsl format` 与 `--check` 不互相打架（§23 语法位置坑）。
- **已知反例**：`arc dsl lint --fix` 会删掉运行时寻址的 id（`site-header`/`hero-carousel-frame`/`theme-bridge-frame`），必须靠 `scripts/arcblog-runtime-ids.test.mjs` 拦住（§25.4，C9）。

### P6 · 用目录边界取代条件筛选
- **适用场景**：需要按「状态」隔离可见性，但表达式不支持比较。→ `PRD-CNT-03`（草稿/发布隔离）、`PRD-SITE-06`（主题继续逛）。
- **实现要点**：把语义放进**路径**：`posts/`（guest，只放已发布）、`drafts/`（admin，草稿+归档+软删）；`replicated` 与 `networkRead` **同时**声明，未声明 = 拒绝（§13、`blocklet.yaml:160-259`）；公开子树必须在**另一个顶层前缀**（§13、§49）。
- **验收判据**：`scripts/arcblog-permissions.test.mjs` 以**无 cookie 访客**身份断言矩阵；拒绝断言必须匹配 `below readRole`，避免「未声明路径」伪装成「已正确授权」（§13）。
- **已知反例**：分类 chips 因下推查询漏记录被**移除** —— 宁可没有筛选，也不要静默少文章（§15.1 末）。
