## 2. 五个 npm 包：**只服务链脚本**（`--adapter ocap` / 只读对账）

| 包（`package.json:16-22`） | 唯一引用点 | 用途 | `mock` 路径是否需要 |
| --- | --- | --- | --- |
| `@ocap/client` | `scripts/lib/chain.mjs:628`；`scripts/arcblog-economy.mjs:998` | GraphQL 链客户端（`getQueries()` / `sendTx`） | ❌ 不需要 |
| `@ocap/wallet` | `scripts/lib/chain.mjs:629` | 助记词 → 钱包（签名主体） | ❌ |
| `@arcblock/did-ext` | `scripts/lib/chain.mjs:630` | `fromAppDid`（应用 DID 派生） | ❌ |
| `@arcblock/did-util` | `scripts/lib/chain.mjs:653`（**子路径** `@arcblock/did-util/cbor`） | `toStakeAddress(owner, factory, nonce)` —— SDK 从 `@ocap/client/lib/extension.js` 走这里派生 stake 地址；缺失会让 revoke/claim 回落到陈旧地址并报 `Invalid itx: "address"` | ❌ |
| `bip39` | `scripts/lib/chain.mjs:631,661` | `mnemonicToSeedSync(config.mnemonic)` | ❌ |

**加载方式**：全部走 `const load = async (name) => { try { return await import(name) } catch { missing.push(name); return null } }`（`chain.mjs:620-627`）——**惰性 + 缺件可报告**，而不是顶层 `import`。这是"零依赖 checkout 仍能跑非链功能"的机制本身。

**fail-closed 形态**（`chain.mjs:632-643`）：缺包或缺 `chainHost`/`mnemonic` ⇒ 抛 `CHAIN_UNAVAILABLE`，消息列明 `missing packages: …` / `missing ARCBLOG_CHAIN_HOST` / `missing ARCBLOG_CHAIN_MNEMONIC`，并给出"装包或改 `--adapter mock`"两条出路。**不写任何记录、不发任何交易。**

**链环境的唯一定义点**：`CHAIN_PRESETS`（`chain.mjs:162-177`，预设键 `beta` / `main`）+ `REAL_CHAIN_REQUIRED = ['network','chainHost','tokenId']`（`:186`）。优先级 `flag ＞ 显式 ARCBLOG_CHAIN_* ＞ config/roles.json ＞ ARCBLOG_CHAIN_ENV 预设 ＞ mock 默认`（`:212-216`）；预设与 `config/roles.json` 不一致时 **fail-closed**（`:254-267`）。
> **示例纪律**：本篇与 [`06`](06-运维场景手册.md) 的任何示例**只写占位符**（`<chain-host>` / `<token-id>` / `<mnemonic>`），**绝不落真实链地址或代币符号**。

## 3. AUP DSL 定位：为什么是 DSL，而不是"引入一个前端框架"

**选它的三个理由（都可证伪）**

1. **它是唯一能读 AFS 的页面通道**：Web Device（`.web/` + `pages/`）在服务端与客户端**都没有 AFS 通道**（`02` 能力 #50）⇒ 用 React/Vue 重写公开面，等于放弃动态内容。
2. **它不需要构建链**：没有 bundler、没有 dev server、没有客户端依赖（§1.1①②）⇒ 交付面 = `dist/` 整树拷贝，密钥面由一个后置擦除点兜住（[`04 §1`](04-构建·部署·运行.md)）。
3. **它的边界是**已知**的**：语言原语清单、prop 契约、渲染坑都在 `02` 成表落地，可以写进验收判据（`02` 能力 #47/#61/#64）。

**代价（必须一起接受）**

| 代价 | 证据 | 应对（不在此重定义） |
| --- | --- | --- |
| 表达式只有 `!` `&&` `\|\|`，无比较/算术/聚合 | `02` 能力 #60 | 目录边界（`02a` P6）；计数取平台分页器 |
| 无哈希 / 时间 / 签名原语 | `02` 能力 #46 | 全部由 CLI/worker 算好写 AFS |
| `include`/`partial` 运行期不可用 | `02` 能力 #62（`02a` F14） | 生成器投影 + `--check` 门（`02a` P5） |
| 组件不能跨页；`:id` 会被 `lint --fix` 剥掉 | `02` 能力 #61/#64 | 生成器逐页烘焙；`runtime-ids` 快层守卫 |
| `.aup` 改动**不热更新** | `02` 能力 #70 | `restart` + 复挂（[`04 §2`](04-构建·部署·运行.md)） |
| safe-style 白名单 67 键（`action` 更窄） | `02` 能力 #27 | 遵守白名单；真 CSS 落 `.web/` |

> **写需求时的自检**：任何"页面里能不能做 X"的问题，先查 [`02 §2`](02-平台能力与边界.md) 的能力矩阵；矩阵说 ❌/⚠️ 的，**不允许**用"引入一个库"绕过——本平台不允许应用自带运行期依赖。

## 4. 外部组件与 SSR：两条"必须依赖生成物/宿主"的线

| 组件 | 形态 | 为什么这样 | 生成/门禁 |
| --- | --- | --- | --- |
| `hero-carousel` | `.web/components/hero-carousel/{component.dsl,render.js,style.css,script.js}` | 首页轮播是 **Web Device**（不是 `afs-list`）：直接 DOM 操作 + 真 CSS | `script.js` 是**生成物**（文件头 `// GENERATED FILE — do not edit by hand.`），= `vendor/photo-story.js` + `init.js`；`node scripts/arcblog-hero-carousel.mjs` 重生成，`--check` 在**快层**（`arcblog-hero-carousel`） |
| `theme-bridge` | `.web/components/theme-bridge/` + `pages/theme-bridge/layout.aup` | 整页主题（`data-tone`/`data-palette`/`data-mode`）由**不可见 overlay iframe** 驱动；它是 Web Device **唯一**能摸 AFS 的例外（经 `parent.window.afs`） | `02` 能力 #40/#41；`arcblog-theme` 快层守卫 |

**SSR 边界（`/p` 面）**：`.route/web` 声明 `path: /p` + `handler: web` + `access: public`；组件 `script.js`/`style.css` **被内联进 SSR 页面**，因此**根相对资源 URL 不可用**（会被 AUP handler 吞掉，`_docs/arc-contracts.md` §14）——这也是"为什么 vendor 而不是引 CDN"的实测原因（`script.js:9-12` 原文）。
**静态文件面**：`/p/` 下的静态产物是**部署期快照**，rebuild 会清掉（`02` 能力 #51）⇒ 生成顺序写进 [`04 §1`](04-构建·部署·运行.md)。

## 5. 明确"不引入"清单（写进验收标准即错的选型）

| # | 不引入 | 为什么 | 若要引入，先满足 |
| :-: | --- | --- | --- |
| N1 | 前端框架（React/Vue/Svelte）与客户端状态库 | 应用面是 AUP DSL；Web Device 无 AFS 通道（`02` #50） | 平台先给 Web Device 开 AFS 通道（今天不存在） |
| N2 | 打包器（webpack/vite/esbuild/rollup） | 无打包步骤；构建 = 整树拷贝（`arc blocklet build --help` 只有 `--output/--dry-run/--clean`） | 平台构建支持 plugin/ignore（今天**无** exclude 开关，`02` #69） |
| N3 | dev server / HMR | 平台无 watch；`.aup` 改动必须 `restart` + 复挂（`02` #70） | 平台提供 reload 路径（今天 `arc blocklet run` **不是** reload） |
| N4 | 运行期 npm 依赖（`import` 进 `.aup`/`.web`/`pages`） | 实测 0 处（§1.1①）；应用面没有模块加载器 | 平台定义应用侧模块解析（今天无） |
| N5 | 数据库 / ORM / 缓存层 | 持久层 = AFS 单文件 JSON；可见性靠目录边界（`01 §1`） | 平台提供事务/索引原语（今天查询层只对 ≤~1.8 KB 内联记录可靠，`02` #20） |
| N6 | HTTP 服务端框架（Express/Koa/Fastify） | 根级自定义端点（`/.well-known`、`/api/*`）全被 AUP 壳吞掉（`02` #49） | 平台放开根路由（今天不可达；网络层只能以 AFS 资源发布） |
| N7 | 调度库（node-cron / Agenda 等） | 平台原生调度在 `arc` 命令面不存在（`02` #54）；"周期"= 长驻 `watch` | 平台给出可用调度面；否则按 [`06 §3`](06-运维场景手册.md) 的长驻 worker 纪律 |
| N8 | 云构建 / CI 产物忽略规则（`.blockletignore` 等） | 平台不认 ignore（`arc-contracts.md` §39(1)）；密钥擦除只能后置 | 平台支持排除；今天唯一防线 = `npm run build` 的第二步 + `verify:artifacts` |
| N9 | 另一套内容真源（静态 SEO 烘焙 / CMS） | CMS 静态烘焙在 CLI/AFS 面**不可达**（`02` #51） | 平台开放 content space（今天闭网数据面） |

> **一条元规则**：本表任何一项被"绕过"（例如往 `.aup` 里塞 `import`），`arc dsl validate` 与快层**都不会替你拦**——DSL schema 对 prop 是 `additionalProperties: true`（`02 §1` 引用块元规则 1）。所以不引入清单是**评审项**（G1/G3），不是自动门。
