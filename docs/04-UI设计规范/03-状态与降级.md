## 1. 条款清单（S01–S08）

| ID | 条款（祈使句） | 类型 |
| :-: | --- | --- |
| **S01** | **不自造空值字面**（禁「尚无数据 / 暂无数据 / No data」）；无数据只用平台破折号 `—` | 可机检 |
| **S02** | **不得**用 `emptyText` 承载空态或"下一步"指引（平台四种写法全无效） | 可机检（弱式）+ 人工审查 |
| **S03** | **不得**用异步条件闸门做空态（`visible="!${state.…}"`） | 可机检 |
| **S04** | 单记录**未绑定 ≠ 记录不存在**（禁 `visible="!$state.…"`） | 可机检 |
| **S05** | 每个 `propBind` 卡带**两段式取数常驻说明**（"空白 ≠ 不存在"） | 可机检（覆盖计数）+ 人工审查 |
| **S06** | 异步取数必须有**加载态**（页面级文案或骨架）；**禁倒计时**（平台无时间原语） | 可机检（计数）+ 人工审查 |
| **S07** | 有写接线的页必须给**失败反馈**（`onErrorToast` 或等价） | 可机检 |
| **S08** | 意图队列**图例词集 ⊆ `INTENT_STATUSES`**，不自造 `done/failed/success` | **人工审查**（裸 grep 有假阳性，N-4 落地后转机检） |

## 3. 反例（`S4-03 §6` 中属于本篇的部分）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| 空态写"暂无数据 / No data" | 自造空值字面；与平台破折号口径冲突 | S01：破折号 `—` + 常驻说明 |
| 用 `emptyText` 承载"下一步" | 平台**四种写法全无效**，渲染默认英文 | S02：页级常驻说明卡（M04） |
| `visible="!${state.x}"` 做空态 | 异步互斥闸门不成立（BUG-001：27 条标签**同时**渲染空态卡） | S03：恒定成立写法 |
| `visible="!$state.x"` 判"记录不存在" | 冷启动时把"未绑定"渲染成"不存在"（5 页实测） | S04：两段式说明（S05） |
| `propBind` 卡无说明，空白即空白 | 读者无法区分"没加载完"与"真的没有" | S05：常驻说明 |
| 画"等待期倒计时实时递减" | 平台**无时间原语**，`${generate.*}` 原样输出 | S06：完成条件 + 真实耗时 |
| 只弹成功 toast、无失败分支 | 假成功（BUG-012/068） | S07：失败原因 + 恢复路径（M05） |
| 自造 `done/failed/success` 状态词 | 与队列词表真源漂移 | S08：⊆ `INTENT_STATUSES`（从模块导入） |

## 5. 本篇机检（可粘贴；真实输出见 `07 §2`）

```bash
python3 - <<'ZZ'
import re,glob
files=[f for f in glob.glob('.aup/pages/*/*.aup')+glob.glob('.aup/pages/*.aup')]
t={f:open(f,encoding='utf-8').read() for f in files}
cnt=lambda pat: sum(len(re.findall(pat,v)) for v in t.values())
print('S01 自造空值 =',cnt(r'暂无数据|尚无数据|No data'))
print('S02 emptyText=: =',cnt(r'emptyText=:'))
print('S03 visible=!${state. =',cnt(r'visible="!\$\{state\.'))
print('S04 visible=!$state. =',cnt(r'visible="!\$state\.'))
pb=[f for f,v in t.items() if 'propBind=' in v]; doc=[f for f in pb if re.search(r'render-timing|two-stage',t[f])]
print('S05 propBind 页 =',len(pb),'有说明 =',len(doc))
print('S06 页面级 loading= =',cnt(r'loading='))
print('S07 写接线页 =',len([f for f,v in t.items() if '/.actions/write' in v or '/.actions/delete' in v]),
      '缺失败反馈 =',len([f for f,v in t.items() if ('/.actions/write' in v or '/.actions/delete' in v) and 'onErrorToast' not in v]))
ZZ
```

**判据**：`S01 = 0`；`S02/S03/S04/S06/S07` 为**已登记待修**清单（数量见输出，须与 §2 现状一致）；`S05` 的"有说明/`propBind`"比值须逐步升至 1。
