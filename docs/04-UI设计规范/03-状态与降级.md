## 1. 三态定义（**唯一出处**）

| 态 | 写法 | 判据 | 禁止 |
| --- | --- | --- | --- |
| **空** | 页级**常驻说明** + 平台破折号 `—`；文案含"下一步" | 空态元素存在于页级（非 `emptyText`）；含"下一步/如何开始" | 用 `emptyText` 承载指引；断言"没有数据/队列为空" |
| **错** | **原因 + 影响 + 恢复路径**（可复制命令或目标页） | 每个写动作有失败分支 | 只弹成功；以 toast 当成功证据 |
| **降级** | 破折号 + **常驻说明** + **可复制命令** | 每个【平台边界】项有常驻说明且含命令 | 假按钮 / 假 0 / 假绿灯 / 把"已入队"当"已生效" |
| **载（补充）** | "**未加载完 ≠ 不存在**"两段式说明 | 异步取数页存在该说明 | 加载中即渲染空态 |

## 2. **BD-01 … BD-09：平台边界的界面条款**

| 条款 | 平台事实（来源） | **必须怎么说** | **不得怎么说** | 判据 |
| :-: | --- | --- | --- | --- |
| **BD-01** | 发布只能在应用之外（[`docs/03-产品设计/03 §3-B1`](../03-产品设计/03-交互模式与状态.md)） | 给**可复制运营侧命令**：`node scripts/arcblog-lifecycle.mjs publish --title … --sign-key node.key`；并说明"页面只写意图，发布在运营侧完成" | 不给"发布"按钮；不说"已在应用内发布成功" | 正例：含"发布"的句子里出现 `arcblog-lifecycle`（`grep`）；负例：无 `action … publish` 类按钮 |
| **BD-02** | `/p/rss.xml` **需先生成**（产物不在仓库） | "**未生成时**：读者/阅读器拿不到 feed" + 生成命令：`node scripts/arcblog-rss.mjs --feed-link "$BASE" > .web-cache/rss.xml` | **不得**说"RSS 已就绪"；不得用 RSS 图标暗示可用 | 正例：含 `rss` 的句子同现 `待生成｜未生成｜需先生成`；负例：无"RSS 已就绪"的**断言句**（**规则声明行豁免**：同行含 `不得/禁止/不说/无此`） |
| **BD-03** | 根级自定义端点不可用（应用壳吞掉） | 只给 `/p/` 出口：`/p/llms.txt`、`/p/rss.xml` | 不出现"自定义域名下的 feed / API"、`/.well-known/…`、`/api/…` **可用** | 负例：正文不得把 `/.well-known`、`/api/`、根级 `/rss.xml` 写成可用出口 |
| **BD-04** | 注册表枚举**本项目未接**（适配器/mock 无 `listStakes`） | **三样同现**：① **`当前未接`** ② 探针 **`P-1`** 状态 ③ **链上浏览器/通用 SDK 核对入口** | **禁止**用空列表冒充"链上没有节点"；不得把机制【已实现】写成"本项目已完成" | 正例：`?page=registry` 文案三样可 `grep`；负例：未接状态下不得出现"0 个节点"这类**确定性**空态 |
| **BD-05** | 索引陈旧（`afs-list` 过滤走索引） | 列表给**目录边界口径**（"按目录/时间读，不靠过滤"）+ 缺项时**可复现命令** | 不得把过滤列表当作"就是全部"；不得给"共 N 条"式自算数字 | 负例：页面无"共 N 条"；正例：说明含"目录边界" |
| **BD-06** | 页内上传：**原语存在、但本实例实测失败** —— `afs-dropzone` **是**平台**唯一**上传原语且**无 prop 元数据**（`arc dsl schema` 不暴露）⇒ 只能裸声明；**实测（2026-09-27，本实例）拖入失败**：`"Upload failed: targetDir must be a non-empty string"`；**且即使成功也不产生索引记录**（二进制落**用户自己的 DID space**，索引仍由 CLI 维护）。来源：[`05-开发文档 02 §2 B12`](../05-开发文档/02-平台能力与边界.md) | `?page=media` **必须**给**可复制 CLI 命令**（`arcblog-media …`）+ "页面只做索引/清理"；**若页面渲染 dropzone，必须同时给出**"**实测失败**"说明与"**索引走 CLI**" | **不得把上传呈现为可用路径**；不说"上传成功"；**不得**只用一个拖拽区暗示它可用 | 负例：把上传写成可用（缺 CLI 命令或缺失败说明）；正例：含 `arcblog-media` **且**含失败说明。⚠️ **页面可以有 dropzone**（`.aup/pages/ops/media.aup:150` **确实渲染**）⇒ **不**以"无 `type="file"`/拖拽区"作负例 |
| **BD-07** | 构建/密钥门（BUG-067） | `?page=diagnostics` 给**只读告知条**："裸 `arc blocklet build` 会把 `node.key`/`.env.local` 复制进 `dist/`；**只用 `npm run build`**" | 不提供"一键构建"按钮；不静默省略该风险 | 正例：含 `BUG-067` 或 `npm run build`；负例：无构建按钮 |
| **BD-08** | 平台无跨页片段（`include` 不可用）⇒ 外壳每页各一份（生成物） | "改导航须重跑 `node scripts/arcblog-console-nav.mjs`" | 不得说"改一处即全站生效"；不得承诺"组件化外壳" | 正例：含 `arcblog-console-nav`；负例：无"改一处全站生效"表述 |
| **BD-09** | **`?page=agents` 的未落盘能力**（发现/汇总/chat/生成编排/转让/记忆） | 每项标 **【规划中】** + **前置探针**（`P-1` 枚举 / `P-3`/`P-4` 转让与权限）；文案写"**当前未接/未跑通**"，并给**只读**说明（不给可点入口） | **不得**给可点入口、不得暗示"已可用"、不得用空列表/假 0 冒充 | 正例：`agents` 页含 `【规划中】` 且含 `P-1`/`P-3`/`P-4` 之一；负例：未落盘能力处出现 `action`/按钮 |

**通用**：九条都属**降级态**，必须同时满足 §1 的降级写法（破折号 + 常驻说明 + 命令）；**判据为负例时，条款在正本中"命中即 FAIL"**。

## 3. 防误导总则（**四条**）

| # | 禁止 | 为什么 | 正解 |
| :-: | --- | --- | --- |
| **F1** | **空列表冒充"没有"** | 链上/枚举/异步三种"空"含义完全不同 | 说清"是**未接**、**未加载**、还是**确无**" |
| **F2** | **假 0 / 假绿灯** | 数字与状态必须能指到 AFS 记录或链上事实 | 指不到 ⇒ 破折号 + 说明 |
| **F3** | **已入队当已生效** | 页面写入只写意图；生效在运营侧/链上 | 队列卡五态（`pending…applied`）如实显示 |
| **F4** | **链上类页面不给核对面** | 核对面是"可验证"的兑现方式 | 必须给链上浏览器/通用 SDK 指引 |

## 4. 可机检（能跑写命令，跑不了写前置）

```bash
# 负例（BD-02）：**规则声明行不算违规** —— 同行含 不得|禁止|不说|无此 即豁免（规则源必须能提名它禁掉的东西）
grep -rn 'RSS 已就绪' docs/01-产品概念 docs/02-产品需求 docs/03-产品设计 docs/04-UI设计规范 | grep -vE '不得|禁止|不说|无此' ; echo "BD-02 负例（真实违规）→ 有输出即 FAIL"
# 正例：BD-01 的命令同现
grep -rn 'arcblog-lifecycle' docs/03-产品设计 docs/04-UI设计规范 | wc -l | sed 's/^/BD-01 正例命中行数 = /'
# 正例：BD-04 的三样（registry 页文案；前置 = 页面创建后）
#   当前 .aup/pages/ops/registry.aup 不存在 ⇒ 本行判据待页面创建后复跑
test -f .aup/pages/ops/registry.aup && grep -c '当前未接\|P-1\|核对' .aup/pages/ops/registry.aup || echo "BD-04 前置未满足：registry 页尚未创建（【规划中】）"
```

**判据**：负例 `grep` **必须 0 命中**（**规则声明行自动豁免**——否则"定义禁令"的条款会被自己的判据判红，本项目已踩过此坑）；正例命中数 **> 0**；前置未满足的条款必须**显式打印前置**（`BD-04` 即此例），不得静默跳过。
