### 2.1 `V05` 的平台事实（**读原始证据必须读出它的"限定范围"**）

| 事实 | 范围 | 出处 |
| --- | --- | --- |
| `action` 的 `style` **只转发部分键**：`padding`/`borderRadius` **生效**，**`minHeight` 被静默丢弃** | **限定在 `action`** | `docs/05-开发文档/附件/arc-contracts.md` **§29.6**（**原始证据**） |
| 同族：`action` 的 `style` 走**更窄的转发路径**（`alignSelf` 在白名单里，写在 `action` 上同样被丢；`posts.aup` 的按钮因此被拉伸到 1440.56px） | **限定在 `action`**；解法 = **用布局包一层** | `docs/05-开发文档/附件/arc-contracts.md` §29.8 第 2 条（**原始证据**） |
| safe-style **67 键白名单**：**含** `padding`/`borderRadius`/**`minWidth`**/**`minHeight`**/`alignSelf`/`flexBasis`/`flexGrow` | **通用**（不限 `action`） | `docs/05-开发文档/附件/arc-contracts.md` §29.8（**原始证据**） |
| safe-style **不含** `wordBreak`/`overflowWrap`/`whiteSpace`/`textOverflow` ⇒ 页内 style **无法**强制断行 | **通用** | 同上 §29.8（**原始证据**）——**这条是 §4 反例与 V06 的依据** |

**⇒ 收窄后的写法**：
- **对 `action`（按钮）**：**不得**用 `style={minHeight: …}` 撑 24×24 —— 它**会被丢弃**；用 **`padding`** 或平台 **`size`** 档，或**用布局包一层**（§29.6/§29.8 的既定解法）。**这是已确立的事实。**
- **对 `view`/`row`**：`minHeight`/`minWidth` **在 67 键白名单内** ⇒ **预期生效**；「`view`/`row` 上的 `minHeight` 也会被丢弃」**原始证据未确立**，且 §29.8 的 `borderBottom` 对照（`action` 丢、`view`/`row` 有效）**反向暗示** `view`/`row` 的转发更宽。故该断言记为 **【未验证】**，见 §2.2。

**`V05` 探针（【未验证】必给：验证步骤 + 判定式）**

| 项 | 内容 |
| --- | --- |
| **未验证什么** | ~~`view`/`row` 上的 `minHeight` 是否真的渲染~~ ✅ **已由 `U18` 关闭（2026-10-12）**：Playwright 只读实测 `index.aup:11` 的 row **176px**、`reader.aup:17` 的 view **280px**，computed 与 rect 均等于写入值 ⇒ **生效**；`action` 上无实例可测（本仓一处都没写），该支**按风险不成立**登记 |

| **阻塞** | 需 CDP（Playwright/Chrome DevTools Protocol）；**本轮未执行**（文档轮不跑写/渲染探针） |
| **归口** | 结论出来后：若 A ⇒ 本条款收窄完成、`view`/`row` 用法无需改；若 B ⇒ 扩写为"`minHeight` 在页内 style 上均不可作命中区依据"并回报 |

| --- | --- |
| **可选中** | 命令文本是可选中的文本节点（**非** 图片 / 非 单字符拼贴）；`monospace: true` |
| **可复制** | 走平台 `copyable`（`key-value-list` 字段级），**不手写**复制逻辑｜实测（`.aup/pages/**/*.aup` 源文件）：`monospace: true, copyable: true` 同现 **87 次 / 28 行**；`copyable` **90 次 / 31 行**（**凡数字必带口径**） |
| **键盘可达** | ✅ **已量到输出（2026-10-12）**：Playwright 逐次 `Tab` ⇒ `?page=index` 5 个、文章页 10 个、about 9 个**非 iframe** 交互元素全部可聚焦，且聚焦环可见（`outline-style: solid`）；**0 个**无可聚焦/无聚焦环。⚠️ **边界**：平台 `frame` 标记（hero/theme-bridge iframe）自身 `outline-style: none`（焦点进入其内部文档），非本仓可控 |
| **不假装可执行** | 页面**不得**提供与命令等价的按钮（[`03 §2 BD-01/BD-06/BD-07`](03-状态与降级.md)：**给命令不给按钮**）；卡上须说明"**本页不执行**" |
| **不截断** | 长命令在窄视口**换行不溢出**（与 V06 同规） |

## 4. 反例（本域）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| 写死 `"#333"` / `rgb(...)` | 主题切换后不跟随，绕过 `--color-*` 唯一通道 | V01：`var(--color-*)` |
| 圆角写 `6px`、`12px` 等 token 外取值 | 主题体系的孤立值；改主题时不跟随 | V02：只用 3 个合法值（现 1 处非法需修） |
| 状态只放颜色点 / 只放 `title` | 色觉障碍与触屏读不到；`title` 不可发现 | V03：**色点 + 文字同排** |
| `destructive` 用平台静息值就交差 | 平台值 **3.99:1**（hover **3.64:1**），破 4.5 | V04：主题层覆写 |
| 给 **`action`** 写 `style={minHeight: …}` 撑命中区 | **`action` 的 style 只转发部分键** ⇒ `minHeight` 被静默丢弃，看着达标、实际不到 24×24（**原始证据** `docs/05-开发文档/附件/arc-contracts.md` §29.6） | V05：`padding` / 平台 `size` 档 / 用布局包一层（`view`/`row` 上 `minHeight` 在白名单内，**不在**本条禁令范围） |
| 长哈希靠 `wordBreak: "break-all"` 断行 | 该属性**在 safe-style 白名单外**，写了也不生效 | V06：结构自适应 + 可复制 |
| 注册表未接时渲染"暂无节点"空列表 | 把**未接**说成**确无**，读者以为网络是空的 | V07：三样同现；禁确定性空态 |
| 给"一键发布／上传"按钮 | 平台做不到 ⇒ **假按钮** | V08 + [`03 §2 BD-01/BD-06`](03-状态与降级.md)：给命令 |
| **固定外观**下 `theme.json` 与 `app.aup` 的 `mode` 不一致 | 门会红（**这正是该门覆盖的场景**）；每次导航先画错外观 | V09：保持二者一致（门的断言会拦） |
| 把 `theme.json` 设为 `system` 却以为门"漏测是 bug" | **按设计豁免**：自适应默认构造上无法与"某一位访客的解析结果"作静态等式（[`scripts/arcblog-theme.test.mjs:36-38`](../../scripts/arcblog-theme.test.mjs)）；闪烁成本见 `docs/05-开发文档/附件/arc-contracts.md` §17 | 读 `scripts/arcblog-theme.test.mjs:36-38` 的**理由注释**，走 `V-Q4`（是否需要能判解析结果的守卫），**不要**当缺陷上报 |
