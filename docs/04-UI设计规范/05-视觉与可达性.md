### D2 主题闪烁条款（**Lead 裁决**）
- **条款**：`.aup/app.aup` 的 `mode` **必须**与站点**实际默认外观**一致（`seed/settings/arcblog/theme.json` 的解析结果）；`mode` 是运行期**每次导航**都会被平台写入的属性 ⇒ 不一致会造成**每次点击菜单闪一次错误主题**（成本引 `_docs/arc-contracts.md` §17 既有结论）。
- **现状（**今天无人守**）**：`seed/settings/arcblog/theme.json` = `system`；`.aup/app.aup:5` = `mode light`；`scripts/arcblog-theme.test.mjs:34-45` 在 `system` 下**直接 `return`** ⇒ 守卫**失效**。
- **处置**：① 条款按本规范执行；② **修守卫测试 = Stage 6 功能点**（要求：`system` 下也要能判定"解析后的默认外观"，**不得** early-return 绕过）；③ 在 `07 §4`「不可判/待测」清单登记"**今天无人守**"。
- **验收形态**（Stage 6 实现时）：`node scripts/arcblog-theme.test.mjs` 在 `system` 下也必须给出"解析后默认外观 == `app.aup` mode"的断言结果。

## 3. 反例（`S4-03 §6` 中属于本篇的部分）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| 写死 `"#333"` / `rgb(...)` | 主题切换后不跟随；`CHROME_CSS` 唯一通道被绕过 | V01：`var(--color-*)` |
| 圆角写 `6px` 等自由值 | token 体系外的孤立值 | V02：只用 3 个合法值 |
| 状态只放颜色点或只放 `title` | 色觉障碍与触屏都读不到；`title` 不可发现 | V03：**色点 + 文字同排**，图例为常驻 `p` |
| `destructive` 用平台静息值就交差 | 平台值 **3.99:1**（破 4.5） | V04：主题层覆写三行（`S4-02 §3`） |
| 靠 `minHeight` 撑命中区 | `minHeight` 被静默丢弃 | V05：`padding` 或平台 `size` 档 |
| 长哈希靠 `wordBreak` 断行 | `wordBreak`/`overflowWrap` 全被丢 | V06：结构自适应 + 可复制 |
| 改 `theme.json` 为 `system` 但不管 `app.aup` | 每次导航闪错主题（守卫今天失效） | D2 条款 + Stage 6 修守卫 |

## 5. 本篇机检（可粘贴；判据见 `07 §2`（本篇 §5 给本篇条款的真实输出））

```bash
python3 - <<'ZZ'
import re,glob,collections
t={f:open(f,encoding='utf-8').read() for f in glob.glob('.aup/pages/*/*.aup')+glob.glob('.aup/pages/*.aup')}
hard=[(f,i) for f,v in t.items() for i,l in enumerate(v.split('\n'),1) if re.search(r'"#[0-9a-fA-F]{3,6}"',l)]
print('V01 硬编码颜色 =',len(hard),hard[:5])
rad=collections.Counter(re.findall(r'borderRadius: "([^"]*)"',''.join(t.values())))
ok={'0','var(--radius-md, 8px)','var(--radius-lg, 10px)'}
print('V02 圆角取值 =',dict(rad),'| 非法 =',[k for k in rad if k not in ok])
app=open('.aup/app.aup',encoding='utf-8').read()
mode=re.search(r'mode\s+(\w+)',app)
theme=open('seed/settings/arcblog/theme.json',encoding='utf-8').read().strip()
print('D2 app.aup mode =',mode.group(1) if mode else 'MISS','| seed theme =',theme[:40].replace(chr(10),' '))
ZZ
```
