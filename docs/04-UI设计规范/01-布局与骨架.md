## 1. 唯一骨架配方

```text
app-header（来自 wrapper，控制台页不自带）
├─ 侧栏（生成物：每页一份；`scripts/console-nav.mjs` → `node scripts/arcblog-console-nav.mjs`）
└─ 内容区 = 唯一滚动容器
   └─ 页头卡：① 标题（短式）② 一句话用途 ③ 唯一主操作
   └─ 页体：列表 / 表单 / 说明块（按页族）
```

| # | 条款 | 判据 |
| :-: | --- | --- |
| **L1** | 每页**只有**一个滚动容器（内容区）；页面根不滚动 | 页面根 `style` 不含 `overflow: auto/scroll` |
| **L2** | 页面根用**全高**布局：`height: "100vh"` + **`overflow: visible`** | `grep` 页面根：`overflow` **不得**为 `hidden`（`hidden` 会裁掉 `100vw` 全 bleed 页头与侧栏，见 [`docs/05-开发文档/附件/arc-contracts.md`](../05-开发文档/附件/arc-contracts.md) §24） |
| **L3** | 侧栏由**生成器**写入，**不得手改**；定位标记 = 侧栏的 `size={width: "clamp(200px, 15vw, 280px)"}` | `node scripts/arcblog-console-nav.mjs --check` 通过（`npm test` 已含） |
| **L4** | 三处同名：**门禁标题 = 页头标题 = 侧栏短式** | 人工比对（`07` 出清单） |
| **L5** | 页头**至多 1 个**主操作；**有**主操作时必须在页头且恰 1 个（0 个仅限只读/状态页：`?page=operations`／`registry`／`diagnostics`／`feeds`／`seo`／`agents` 的可写动作由 CLI 或平台 `auto-surface` 承担，`C3` 禁止造按钮）**2026-10-13 澄清** | 人工；`grep` 页头区 `variant=primary` ∈ {0,1}，且 0 时该页无任何可写动作 |
| **L6** | 异步取数用 `propBind` + 两段式（未加载完 ≠ 不存在） | 见 [`03 §1`](03-状态与降级.md) 载态 |
| **L7** | **概览页（`?page=dashboard`）解剖 = 三段**：① 需要处理（异常区，`PRD-OPS-01`）② 待处理草稿 ③ 最近发布；每段 = **标题 + 一句话说明 + 内容 +（可选）一个次操作**，页头仍恰 1 个主操作。同一份信息不重复落两处（数字/常驻行各有唯一点） | 人工比对（页源码 + 渲染）；内容卡 = 3（`ui-budget` 对 dashboard 的 `cards` 例外 3） |
| **L8** | **界面不承载开发说明**：平台机制解释、`BUG-` 号、`localStorage` 键名、CLI 文件名/命令、`arc-contracts` 章节号、判定原理**不得**出现在页面文案里；它们属于 `?page=diagnostics`（平台边界/FAQ）或 `docs/**`（原始证据）。页面只留「用户能做什么 + 数据原话」 | **机检（棘轮）**：`node --test scripts/arcblog-i18n.test.mjs`（含 L8 守卫）｜ 账本 = `scripts/ui-copy-baseline.json`，量具 = `node scripts/arcblog-ui-copy.mjs`（只量页面 `i18n {}` 块＝渲染文案；注释与接线不计）；`?page=diagnostics` 按本条豁免并在账本里写明理由；**变异自证**：给 `site/seo` 的 i18n 加一条 `BUG-063` ⇒ `site/seo: 6 > 4` 红，撤销后绿 |
| **L9** | **页面族解剖**（2026-10-13 定稿，全表见 [`docs/03/01 §1b`](../03-产品设计/01-控制台骨架与页面族.md)）：概览页=KPI 行+需要处理（`L7`）；列表/治理页=页头+**状态行**+列表+写入面；表单/设置页=页头+表单卡+折叠高级；只读状态页=页头+状态卡（`surface` 直读记录）+可复制命令。**三条不变量**：① 每页可见卡 **≤ 2**（例外须按 `N8` 登记）；② 页面**不自算**数字（计数只来自 CLI 投影记录 `config/console/*` 或平台分页器）；③ 状态行的成本应当只有"1 个 `surface` + 1 个子节点"（依据 `arc-contracts §63`） | `node scripts/arcblog-ui-budget.mjs`（`cards` 每页 ≤ 2，例外见 `EXEMPTIONS`）＋ 人工核对状态行指向的记录确实由 CLI 写出（`node scripts/arcblog-overview.mjs refresh` 后 `config/console/*` 存在） |

## 2. 公开面骨架（7 页）

| 页 | 骨架要点 |
| --- | --- |
| `index`（`/posts`） | Hero（`hero-carousel` 组件）+ 最新列表；Hero 无数据 ⇒ **默认卡**（不得空白） |
| `reader`（`/posts/{slug}`） | `propBind` 取记录（`$params.slug`，无花括号）+ `${state.post.*}` 客户端读；`visible` 用**插值式** |
| `page-view`（`/pages/{slug}`） | 同 `reader`，未绑定 ⇒ "**未绑定 ≠ 不存在**" |
| `preview`（`/preview/{slug}`） | 管理员门禁；访客 not-found |
| `author` | 节点档案 + 文章列表；角色未知 ⇒ 显示 `unknown` |
| `saved` | 门禁卡；登出**不可见**、不缓存 |
| `about` | 只读出口告知（→ [`03 §2 BD-02/BD-03`](03-状态与降级.md)） |

## 4. 不做什么

| 项 | 理由 |
| --- | --- |
| 不自造布局框架/栅格系统 | 平台 primitives 已足够；新增抽象会与生成物冲突 |
| 不做页内 tabs / `#hash` 路由 | 一页一事；外壳按页渲染，页内路由会与生成物冲突 |
| 不做跨页片段（`include`） | 【平台边界】：`include` 运行时不可用 ⇒ 外壳只能生成复制（见 [`03 BD-08`](03-状态与降级.md)） |
| 不做"以后再放回来"的占位行 | 占位会重新引入两套计数（侧栏生成器与 `ui-budget` 棘轮） |
