## 2. 判据与处置（逐条）

### L01 根高度公式唯一（**D3：直接采用 Stage 3 R1**）
- **配方**：`height: calc(100vh - 48px)`（48px = shell 页头高度）+ `overflow: visible`。**本规范不新造规则**；理由与取证见 [`01-骨架 §1`](../03-产品设计/01-控制台骨架与页面族.md)（R1 裁决：20/22 页在用；两处偏差**自相矛盾**——其内层侧栏行仍写 `calc(100vh - 48px)`，且控制台页均无 `app-header`）。
- **判据**：`grep -rn 'style={height: "100vh"' .aup/pages/ --include=*.aup` → **除已登记例外外为 0**。
- **现存偏差（2 页，判历史遗留）**：`admin/general.aup:100`、`admin/diagnostics.aup:29`。**处置 = 统一为实现项**（Stage 5/6 落地），**不在本规范给"例外"条款**（`00 §3` 第 1 类病根：同一事实两处定义）。
- **另记（D3 附带）**：`CLAUDE.md` 写 `100vh` 的那处是**陈旧原文**；Stage 5/7 重写 `CLAUDE.md` 时改正。本阶段只在条款注明"**以 Stage 3 R1 为准**"。
- **公开面**：8 页**不设根高度**（自然流式），**不适用** L01（见 Stage 3 `02-公开面 §1`）。

### L02 全出血行唯一且写法固定
- **写法**：`width: "100vw"` + `marginLeft: "calc(50% - 50vw)"`（每页**恰 1 处**）。
- **判据**：逐页统计 `width: "100vw"` 出现次数 == 1（**已实测：`compose-edit` 恰 1 处**；`hasSidebar=false` 只影响侧栏，不影响全出血行）。
- **现状**：达标 21/21（范式 `.aup/pages/admin/posts.aup:65`）。
- **登记（D5 邻域，Stage 6 候选）**：平台 **full-page 组合契约**可替掉本 hack（`03-模式 §5` 已登记）——**本规范在替换前以此写法为唯一合法形态**。

### L03 根 `overflow` 必须 `visible`
- **判据**：`grep -rn 'overflow: "hidden"' .aup/pages/ --include=*.aup` → **页面根**为 0。
- **现状**：全仓唯一 `overflow: hidden` 在 `index.aup:11` 的**列表行**（封面裁切，非页面根）⇒ **合法，登记为已批准的非根用法**；页面根 22 处均为 `visible`。
- **理由**：`overflow: hidden` 会被 `--aup-content-max` 裁掉 `100vw` 全出血行与侧栏（`_docs/arc-contracts.md` §24 既有结论）。

### L04 滚动容器唯一（**人工审查**）
- **条款**：滚动区直接子项 `flexShrink: 0`；外层 `height: 100%` + `minHeight: 0`；**全页只留一个滚动容器**。
- **为何人工**：无原语可探测"滚动归属"；须 CDP 量 `documentElement.scrollHeight === innerHeight` **且**内容列 `scrollHeight > clientHeight`（`S4-03 §1.1`）。
- **现状**：**未测**（R23 实测 `ledger` 内容列 26734 / 文档恒 908，说明当前实现符合预期，但**未逐页测**）。
- **替代测法**（`04-流程 §4` 条款）：CDP 两次读数（滚动前后 `scrollTop` 归属元素）+ 记录到 `07 §3` 人工清单。

### L05 禁 `position: sticky|fixed`（**平台边界**）
- **判据**：`.aup/**` 出现 `position: sticky|fixed` = **FAIL**（禁写条款——`position` 不在 safe-style 67 键白名单，"能不能吸顶"**不可判**，故只能禁写）。
- **现状**：**0 处**，达标。
- **替代形态**：页头/动作条**放在滚动容器之外**（`01-骨架 §1` 四条硬约束①）；窄屏顶部条见 `03-模式 §5`（平台 `nav-sidebar` 折叠，**不是** sticky）。

## 3. 反例（`S4-03 §6` 中属于本篇的部分）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| 根用 `height: "100vh"`（无 `-48px`） | 根比内容高 48px ⇒ 伪滚动/裁切；与全仓唯一配方冲突 | L01 配方（2 处历史遗留待统一） |
| 用两套全出血 hack（`marginLeft: "-50vw"` 等自造写法） | 只允许一种写法，否者后人改一处漏一处 | L02 固定写法 |
| 为了"禁止页面滚动"给根加 `overflow: hidden` | 会被 `--aup-content-max` 裁掉全出血行与侧栏 | L03：根 `visible`；裁切需求放**非根**元素 |
| 用 `position: sticky` 画吸附页头 | 平台丢弃该属性（白名单无 `position`）⇒ 视觉与源码不一致 | 页头放滚动容器之外 |
| 把滚动条挂在内容卡里再套一层滚动 | 双滚动容器 ⇒ 命中区与滚动归属混乱 | L04：只留一个滚动容器 |

## 5. 本篇机检（可粘贴；输出见 `07 §2`）

```bash
python3 - <<'ZZ'
import re,glob
pages=[f for f in glob.glob('.aup/pages/*/*.aup')+glob.glob('.aup/pages/*.aup')]
root100=[]; bleed=[]; ovh=[]; pos=[]; root_over={}
for f in pages:
    s=open(f,encoding='utf-8').read()
    lines=s.split('\n')
    for i,l in enumerate(lines,1):
        if 'style={height: "100vh"' in l: root100.append(f'{f}:{i}')
        if 'position: sticky' in l or 'position: fixed' in l: pos.append(f'{f}:{i}')
    if 'width: "100vw"' in s: bleed.append((f,s.count('width: "100vw"')))
    if re.search(r'^\s*view[^\n]*overflow: "hidden"',s,re.M): ovh.append(f)
print('L01 root 100vh =',len(root100),root100)
print('L02 pages with 100vw =',len(bleed),'| !=1 ->',[b for b in bleed if b[1]!=1])
print('L03 root overflow:hidden =',len(ovh),ovh)
print('L05 position sticky/fixed =',len(pos),pos)
ZZ
```

**判据**：`L01` 仅允许 2 条**已登记例外**；`L02` 各页 `100vw` 恰 1（`compose-edit` 允许 0）；`L03` 根为 0；`L05` 为 0。**真实输出见 ``07 §2``**。
