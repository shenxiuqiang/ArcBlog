## 1. 唯一骨架配方

```text
app-header（来自 wrapper，控制台页不自带）
├─ 侧栏（生成物：每页一份；`scripts/console-nav.mjs` → `node scripts/arcblog-console-nav.mjs`）
└─ 内容区 = 唯一滚动容器
   └─ 页头卡：① 标题（短式）② 一句话用途 ③ 唯一主操作
   └─ 页体：列表 / 表单 / 说明块（按页族）
```

| # | 条款 | 判据 |
| :-: | --- | --- |
| **L1** | 每页**只有**一个滚动容器（内容区）；页面根不滚动 | 页面根 `style` 不含 `overflow: auto/scroll` |
| **L2** | 页面根用**全高**布局：`height: "100vh"` + **`overflow: visible`** | `grep` 页面根：`overflow` **不得**为 `hidden`（`hidden` 会裁掉 `100vw` 全 bleed 页头与侧栏，见 [`docs/05-开发文档/附件/arc-contracts.md`](../05-开发文档/附件/arc-contracts.md) §24） |
| **L3** | 侧栏由**生成器**写入，**不得手改**；定位标记 = 侧栏的 `size={width: "clamp(200px, 15vw, 280px)"}` | `node scripts/arcblog-console-nav.mjs --check` 通过（`npm test` 已含） |
| **L4** | 三处同名：**门禁标题 = 页头标题 = 侧栏短式** | 人工比对（`07` 出清单） |
| **L5** | 页头卡**恰 1 个**主操作 | 人工；`grep` 页头区 `action` 数 = 1 |
| **L6** | 异步取数用 `propBind` + 两段式（未加载完 ≠ 不存在） | 见 [`03 §1`](03-状态与降级.md) 载态 |

## 2. 公开面骨架（7 页）

| 页 | 骨架要点 |
| --- | --- |
| `index`（`/posts`） | Hero（`hero-carousel` 组件）+ 最新列表；Hero 无数据 ⇒ **默认卡**（不得空白） |
| `reader`（`/posts/{slug}`） | `propBind` 取记录（`$params.slug`，无花括号）+ `${state.post.*}` 客户端读；`visible` 用**插值式** |
| `page-view`（`/pages/{slug}`） | 同 `reader`，未绑定 ⇒ "**未绑定 ≠ 不存在**" |
| `preview`（`/preview/{slug}`） | 管理员门禁；访客 not-found |
| `author` | 节点档案 + 文章列表；角色未知 ⇒ 显示 `unknown` |
| `saved` | 门禁卡；登出**不可见**、不缓存 |
| `about` | 只读出口告知（→ [`03 §2 BD-02/BD-03`](03-状态与降级.md)） |

## 4. 不做什么

| 项 | 理由 |
| --- | --- |
| 不自造布局框架/栅格系统 | 平台 primitives 已足够；新增抽象会与生成物冲突 |
| 不做页内 tabs / `#hash` 路由 | 一页一事；外壳按页渲染，页内路由会与生成物冲突 |
| 不做跨页片段（`include`） | 【平台边界】：`include` 运行时不可用 ⇒ 外壳只能生成复制（见 [`03 BD-08`](03-状态与降级.md)） |
| 不做"以后再放回来"的占位行 | 占位会重新引入两套计数（侧栏生成器与 `ui-budget` 棘轮） |
