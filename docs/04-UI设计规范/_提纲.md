## 7. 本阶段强约束（正文照办）

1. **"跑过 ≠ 写回"**：凡声称可机检的条款，**代码 + 命令 + 真实输出必须同处一篇**（`07 §2`）；不接受"我在 /tmp 跑过"。
2. **判据要有判别力**：新写的可机检条款必须能用"**回滚副本 → 必须 FAIL**"证明，产物 = `docs/04-UI设计规范/_sens.sh`（与 Stage 3 `_sens.sh` 同法）。
3. **不重复定义**：M01–M15 / 四态 / C1–C4 的唯一出处仍在 Stage 3，本阶段**只引用**（§5 表 + 机检）。
4. **形态纪律**：版本行 ≤80 字符、单行 ≤800 字符（**按字符**）、变更进表。
5. 每篇 ≤400 行；`_提纲` 与 `_sens.sh` 为过程/工具文件，不参与条款判据的 glob。
