## 2. 本目录三件事

1. **条款库**：8 篇条款，覆盖范围见 [`00 §2`](00-总则与形态纪律.md)；
2. **降级表达**：每个【平台边界】项都有**界面上的说法**（不是抛错）；
3. **可机检验收清单**：每条款给判定式；能跑的写命令，跑不了写**前置**。

## 3. `03-状态与降级`：**B1–B8 落点计划**

| 来源（`docs/03-产品设计/03 §3`） | 平台事实 | 本篇条款要求 |
| :-: | --- | --- |
| **B1** | 发布只能在应用之外 | 给**可复制命令**（`M07`），**不给按钮** |
| **B2** | `/p/rss.xml` 由**部署管线**产出（裸 build 会抹掉） | **不得**把 RSS 说成"运行时自动产出"；写明管线步骤 3b + `node scripts/arcblog-deploy.mjs`（2026-10-12 同步） |
| **B3** | 根级端点不可用 | 不出现"自定义域名下的 feed/API" |
| **B4** | 注册表枚举**已接线**（`P-2` 真链只读通过） | **"CLI 预计算 `stateNote`/`ownNote` + 探针 `P-1`/`P-2` 状态 + 链上浏览器/SDK 核对入口"三样同现**；**禁空列表冒充"链上没有节点"**（2026-10-12 同步） |
| **B5** | 索引陈旧 | 列表给**目录边界口径**；禁"共 N 条" |
| **B6** | 页内上传不可用 | **不得把上传写成可用路径**：可渲染 dropzone，但须给可复制 CLI 命令 + **实测失败**说明 |
| **B7** | 构建/密钥门告知面 | 只读告知条（BUG-067 + 只用 `npm run build`） |
| **B8** | 平台无跨页片段 | 外壳是**生成物** ⇒ 改导航须重跑生成器 |

**判据形态**：每条给「**必须怎么说** / **不得怎么说**」+ **可 `grep` 的正例或负例**；判据先在正本上自跑、再做**变异**。
