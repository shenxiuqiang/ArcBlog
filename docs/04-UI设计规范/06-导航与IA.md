## 1. IA 分组（四组）

| 组 | 行（`?page=`） | 说明 |
| --- | --- | --- |
| **写作** | `dashboard` `compose` `posts` `media` | 内容生产与素材 |
| **站点** | `pages` `heroes` `categories` `tags` `appearance` `seo` `feeds` | 站点结构与外观 |
| **节点与网络** | `operations` `factory` `registry` `agents` | `registry` = 节点清单；`agents` = agent 工作面**主入口** |
| **高级** | `general` `diagnostics` | 通用设置与自检 |

**计数与真源（不写预期）**：行集合的**唯一真源** = `scripts/console-nav.mjs` 的 `CONSOLE_SECTIONS`；**代码在册** `length` = **21**（复算：`node -e "import('./scripts/console-nav.mjs').then(m=>console.log(m.CONSOLE_SECTIONS.length))"`）；上表列的是**本规范覆盖**的控制台行。
**文件口径**：`ls .aup/pages/**/*.aup` = **30**（代码在册）；`compose-edit` 是无侧栏子页，公开面 7 页不带控制台侧栏。

## 2. 导航条款

| # | 条款 | 判据 |
| :-: | --- | --- |
| **N1** | **`?page=` 名禁止改名**（改名牵动生成器、测试与外部链接） | 与 `scripts/console-nav.mjs` 的 id 集逐字一致 |
| **N2** | 侧栏是**生成物**，每页一份；**不得手改** | `node scripts/arcblog-console-nav.mjs --check` 通过 |
| **N3** | **增删行 ⇒ 必须重跑 `node scripts/arcblog-console-nav.mjs`** | 否则 `scripts/arcblog-console-nav.test.mjs`（`assert.ok(path, …not found)`）**必红** |
| **N4** | 当前行**恰一行** `active=true`（平台渲染 `aria-current="page"`） | `grep -c 'active=true'` = 1 / 页 |
| **N5** | 侧栏定位标记 = `size={width: "clamp(200px, 15vw, 280px)"}`（生成器据此定位自身块） | 生成器 `--check` |
| **N6** | 侧栏文案键 = `$t(wrapper.nav-*)`，**声明一次**在 `wrapper.aup`；页面键是 `<page>.<key>` | 见 [`04-文案与i18n.md`](04-文案与i18n.md) |
| **N7** | 公开面**不出现控制台侧栏**；两套导航互不引用 | 人工比对（`07` 出清单） |
| **N8** | 增删行的**棘轮后果**：`arcblog-ui-budget` 基线随之调整（断言 `files.length == CONSOLE_SECTIONS.length + 1`），**基线取测试实际输出、不写死** | [`07 §…`](07-验收清单与机检.md) 的命令 | ⚠️ **2026-10-12 例外登记**：`dashboard` 的 `styles` 阈值由 **8 → 9**（`cards` 早为 P2 例外 3）——原因是 `PRD-OPS-01` 的**异常区**作为**独立卡片**落地（PRD 原文要求"异常区，不是两张裸列表"），第三张卡片自带 1 处 `style={}`；该例外**显式写在** `scripts/arcblog-ui-budget.mjs` 的 `EXEMPTIONS` 注释里，**不得**通过 `--write-baseline` 悄悄升阈值 |
| **N9** | ⚠️ **`arcblog-runtime-ids` 不在增删行的守卫之列**（只守 `wrapper.aup` 三个 id、不遍历页面） | **不得**把它写成"增删行会红" |

## 3. 与生成器/测试的关系（**实现侧唯一依据**）

| 物 | 关系 |
| --- | --- |
| `scripts/console-nav.mjs` | **唯一真源**（组与行序列）；`CONSOLE_SECTIONS.length` 用实测 |
| `scripts/arcblog-console-nav.mjs` | 生成器：把侧栏写进**每个控制台页**；`--check` 是漂移门 |
| `scripts/arcblog-console-nav.test.mjs` | 漂移 + **页存在性**断言 ⇒ **增删行必红** |
| `scripts/arcblog-ui-budget.test.mjs` | 棘轮 ⇒ **增删行必红**，基线随之调整 |
| `scripts/arcblog-runtime-ids.test.mjs` | **与增删行无关**（`wrapper.aup` 三 id） |

---

## 4. 不做什么

| 项 | 理由 |
| --- | --- |
| 不做 `#hash` 路由 / 标签页 | 一页一事；与侧栏生成物冲突 |
| 不做"隐藏行"代替删除 | 隐藏行仍占 `CONSOLE_SECTIONS` ⇒ 棘轮与漂移门失真 |
| 不做"以后再放回来"的占位行 | 占位会重新引入两套计数 |
