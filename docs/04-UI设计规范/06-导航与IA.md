## 3. 反例（`S4-03 §6` 中属于本篇的部分）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| 手改某页侧栏（不跑生成器） | 手工漂移；`--check` 会红，且 21 页不一致 | N02：改 `scripts/console-nav.mjs` 后重新生成 |
| 一页里给两行 `active=true` | "我在哪"歧义；`aria-current` 双标 | N01：恰一行且是本页 |
| 组名与行名同词（`Operations`/`Operations`） | 用户无法区分"分组"与"页" | N04：组名改"节点与网络" |
| 内容区放"整页替换"链接 | 与原断言一样会**空心通过**；且破坏"一页一件事" | N03：等价断言 + 显式链接 |
| 链接到记录绑定页 / 非 HTML 资源不加 `target` | 在 AUP 壳内把用户带离应用上下文 | N05：`target=_blank` |
| 控制台页自带 `app-header` | 壳重复 ⇒ 双页头、双主题切换按钮 | N06：共享壳（`wrapper.aup:42`） |
| 删掉控件却不给去向 | 功能静默消失（P1） | N05 后半：折叠 / 高级页 / CLI 三选一 + 登记 |

## 5. 本篇机检（可粘贴；判据见 `07 §2`（本篇 §5 给本篇条款的真实输出））

```bash
python3 - <<'ZZ'
import re
src=open('scripts/console-nav.mjs',encoding='utf-8').read()
rows=re.findall(r"label:\s*['\"]([^'\"]+)",src)
groups=re.findall(r"group:\s*['\"]([^'\"]+)",src) or re.findall(r"title:\s*['\"]([^'\"]+)",src)
print('rows =',len(rows),rows[:5])
print('N04 组名与行名同词 =',sorted(set(rows)&set(groups)))
pages=[f for f in __import__('glob').glob('.aup/pages/*/*.aup')]
selfhdr=[f for f in pages if 'app-header' in open(f,encoding='utf-8').read()]
print('N06 自带 app-header 的控制台页 =',selfhdr)
ZZ
node scripts/arcblog-console-nav.mjs --check
```

**判据**：`N04 = []`（当前 **1 处**：`Operations`）；`N06 = []`；`--check` 输出 `{"ok": true, "pages": 21}`。
