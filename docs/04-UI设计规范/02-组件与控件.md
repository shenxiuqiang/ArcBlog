## 2. 判据与处置

### C01–C03：`afs-list` 三契约（引用 C1）
- **唯一口径出处 = [`04-流程 §2.1`](../03-产品设计/04-流程与跨页契约.md)**（分页契约 C1）；本篇只给判据。
- **判据**：结构解析每个 `afs-list`：`id` 显式、`pagination=manual`、`pageSize=N`、`autoSelect=false`、`clickMode=` 显式；每个直接子模板含 `role=item`；`pagination=auto` 计数 = 0。
- **现状**：C01/C03 达标 **38/38**；C02 达标（0 处，R23 已把 `dashboard` 3 处改 `manual`）；**唯一登记例外** = `site/heroes.aup:184`（`clickMode=select`，快速加入暂存，已在 Stage 3 登记）。

### C04：表单初值写法
- **判据**：`grep -rn 'state={value: *"\${' .aup/pages/ --include=*.aup` → **0**（34 处 `state={value:` 全是**静态空串**，合法）。
- **现状**：达标 0 违规。**平台事实**：`state={value:"${state.x}"}` 渲染**字面量模板串**；`value="${state.x}"` 才插值且保持可编辑（契约 §19）。

### C05：禁行级 `pattern=`
- **判据**：`grep -rn 'pattern=' .aup/pages/ --include=*.aup` → **0**。
- **现状**：**不达标 7 处**（`economy/policy.aup:343,344,349,350,354,380,381`）⇒ **登记为实现项（Stage 5/6）**；替换形态 = 服务端校验 + 失败原因（M05），或受控 `select`（M11）。
- **危害**：服务端拿**未替换的模板字面量**校验 ⇒ 每次保存**静默失败却弹成功**（假成功）。

### C06：`destructive` 必确认
- **判据**：`grep -rn 'variant=destructive' .aup/pages/ --include=*.aup | grep -v 'confirm='` → **0**。
- **现状**：达标 **14/14**（全仓 36 处 `confirm=`）。**模式出处** = [`03-模式 §1`](../03-产品设计/03-交互模式与状态.md) M06。

### C07：禁用原语清单
- **判据**：`.aup/**` 出现 9 个不存在原语之一，或把 `col`/`badge`/`card` 当面板原语 → **FAIL**（面板一律普通 `view` + 卡片 token）。
- **现状**：达标 0 违规（65 个面板已改造）。

### K4：预算单一口径 + ratchet（**两条失效条款的替代**）
| 原失效条款 | 替代 |
| --- | --- |
| `S4-01 §2` 第 6 条（shell「快速目视」整文件计数） | **口径唯一 = `node scripts/arcblog-ui-budget.mjs --json`**；`_sources` 每页带 hash（可复现）；**不得**再并列"整文件计数" |
| `S4-01 §2` 第 7 条（"重录基线只允许下调"） | **ratchet 语义 = 只禁"变差"**：`regressions`/`baselineDrift` 必须 `[]`；**合法新增**走 `--write-baseline` **并在变更记录写明动因**（BUG-080 先例） |
- **指标含义（Lead 裁决 R3 邻域）**：`ctrl` = `action`+`input` 行数、`styles` = `style={...}` 处数、`i18n` = 声明键数 ⇒ **折叠不减指标**，故预算门维持 **ratchet**、**非 strict**；**不得**用 LN（行数）当预算判据。
- **新增门（D5 登记，本阶段不写脚本）**：**N-3 分级预算门（`tech ≤ 2` 单独断言）**——避免与 `ctrl/styles/i18n` 连带失败。

## 3. 反例（`S4-03 §6` 中属于本篇的部分）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| `pagination=auto` 或自造"加载更多" | 假分页：只截断 + 无限续载，**无页码入口**，读者无法跳页 | C01：`pagination=manual pageSize=N`；`total ≤ pageSize` 平台不渲染，**不得补假入口** |
| 行模板不写 `role=item` | 行会渲染成**默认文件清单**（R7 先例） | C03 |
| `input state={value:"${state.x}"}` | 渲染**字面量模板串** | C04：`value="${state.x}"` |
| 行级 `pattern=` 做校验 | 服务端拿未替换模板 ⇒ **静默失败 + 假成功** | C05：服务端校验 + 失败原因 |
| `destructive` 不弹确认 | 不可逆操作无后果说明 | C06：`confirm={title,message}` |
| 用 `badge`/`card`/`col` 当原语 | 平台无这些面板原语 | C07：普通 `view` + 卡片 token |
| 为了让数字好看手动下调基线 | 把合法工作判成回归/掩盖恶化 | K4：ratchet + `--write-baseline` + 变更记录 |

## 5. 本篇机检（可粘贴；真实输出见 `07 §2`）

```bash
python3 - <<'ZZ'
import re,glob
files=[f for f in glob.glob('.aup/pages/*/*.aup')+glob.glob('.aup/pages/*.aup')]
txt={f:open(f,encoding='utf-8').read() for f in files}
print('C02 pagination=auto =',sum(v.count('pagination=auto') for v in txt.values()))
print('C04 state={value:"${ =',sum(len(re.findall(r'state=\{value: *"\\$\{',v)) for v in txt.values()))
p=[(f,i) for f,v in txt.items() for i,l in enumerate(v.split('\n'),1) if 'pattern=' in l]
print('C05 pattern= =',len(p),p)
d=[(f,i) for f,v in txt.items() for i,l in enumerate(v.split('\n'),1) if 'variant=destructive' in l and 'confirm=' not in l]
print('C06 destructive without confirm =',len(d),d)
print('C07 forbidden primitives =',sum(len(re.findall(r'(?<![a-z-])(badge|card|col)\s*\{',v)) for v in txt.values()))
ZZ
```

**判据**：`C02/C04/C07 = 0`；`C05` 仅允许**已登记的 7 处**（待修）；`C06 = 0`。
