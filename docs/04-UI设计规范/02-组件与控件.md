## 1. 组件清单

| 组件 / primitive | 用途 | 关键纪律（**违者即缺陷**） |
| --- | --- | --- |
| `app-header` | 顶端壳 | `logo` 是图片字段；**`src` 是点击目标** ⇒ 必须声明 `events={nav-click: …}` 或用 `href`，否则每次点击报 `no 'nav-click' event` |
| `afs-list` | 列表 | 行子元素默认 `flex: 1 1 0%`；固定缩略图需 **`flexGrow: 0` + `flexBasis`**；`autoSelect=false` 防首行选中；**过滤走索引 ⇒ 编辑后记录会消失**（→ [`03 BD-05`](03-状态与降级.md)） |
| `exec "/.actions/write"` | 页面写入 | 只写**意图**；授权来自 `blocklet.yaml` 的 `replicated`（未声明路径即拒） |
| `propBind` | 单记录取数 | `$params.slug`（**无花括号**）+ `${state.post.*}`；`visible` 用**插值式**（表达式式只算一次、永不恢复） |
| `frame`（theme-bridge） | 整页主题 | overlay + `bridge=true`；**沙箱默认列表**会静默挡 `target="_parent"` ⇒ 需加 token 或 `sandbox=false`（同源） |
| `view href` | 行内跳转 | **列表 select 事件不能导航**（exec 合并 entry payload 覆盖 args）⇒ 一律用 `href` |

## 2. 控件纪律（表单 / 动作 / 列表）

| # | 条款 | 判据 |
| :-: | --- | --- |
| **C1** | 表单预填用 `value="${state.x}"`（**不是** `state={value: "${state.x}"}`，后者渲染字面量） | 代码审查 + 页面实测 |
| **C2** | 不可逆/高风险动作必须 `confirm=` 并把**后果**写进确认文案（`M06`） | `grep`：`variant=destructive` 处必有 `confirm` |
| **C3** | 平台做不到的动作 ⇒ **复制命令卡**（`M07`），**不给按钮** | 见 [`03 BD-01/06/07`](03-状态与降级.md) 的判据 |
| **C4** | 分页**口径唯一**：平台原生分页器；`total ≤ pageSize` 不渲染分页行 | `grep` 出 `pagination=manual`；页面**不得**"共 N 条" |
| **C5** | 空态用**页级常驻元素**（`emptyText` 不解析 `$t()`，且不能承载指引） | [`03 §1`](03-状态与降级.md) 空态判据 |
| **C6** | 队列卡五态（`pending/running/applied/rejected/noop`）如实显示；**已入队 ≠ 已生效** | [`03 §3 F3`](03-状态与降级.md) |
| **C7** | 禁用只靠 `visible` 的**表达式式**（异步数据会永不出现） | 一律插值式 |
| **C8** | 主题用平台 token（`active=true`/accent token），**不手写颜色** | 与 [`05`](05-视觉与可达性.md) 的可达性条款联动 |

## 3. `?page=registry` 需要的最小组件集

| 需要 | 用什么 | 说明 |
| --- | --- | --- |
| 节点列表 | `afs-list`（**或**只读命令输出卡，视枚举是否已接） | 未接时**不得**渲染确定性空列表（[`03 BD-04`](03-状态与降级.md)） |
| 时效四态 | 文本 + 破折号 `—` | 与 `PRD-NET-03` 的四态一致 |
| 核对入口 | **复制命令卡 / 外链** | 链上浏览器或通用 SDK（`PRD-NET-07`） |
| 状态位 | 常驻说明块 | 三样：`当前未接` + `P-1` + 核对入口 |

## 4. 不做什么

| 项 | 理由 |
| --- | --- |
| 不自造下拉/日期等原生控件替代 | 平台 primitives 与样式白名单有限（`backgroundImage` 等会被丢弃） |
| 不在列表 select 上做导航 | 运行期实测缺陷（见 §1） |
| 不用 toast 当成功证据 | [`03 §1`](03-状态与降级.md) 错态判据 |
