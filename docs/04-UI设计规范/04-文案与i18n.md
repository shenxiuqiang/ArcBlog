## 1. locale 生命周期（**本篇 = 唯一出处**）

| # | 事实 | 说明 | 复核方式 |
| :-: | --- | --- | --- |
| **LC1** | **键是扁平点号**，不是嵌套对象 | `.aup/locales/*.json` 存 `"wrapper.nav-console"`；写成 `{"wrapper":{"nav-console":…}}` 时 **`generate` 读不到、运行期原样渲染 `$t(wrapper.…)`** | 实测：`en`/`zh` 各 **880** 键，**嵌套对象 0**、点号键 **880**（§7 脚本） |
| **LC2** | **页面键由 `arc dsl generate` 生成**（源 = 各页 `i18n {}` 块），**合并写、从不删** | 已存在的键保留、新键追加；**没有任何"删除"语义** ⇒ 死键只能由人清 | 契约层：[`docs/05-开发文档/附件/arc-contracts.md`](../05-开发文档/附件/arc-contracts.md) §31（**原始证据**）；可观测面 = LC1 的键数与 `$t()` 引用集之比（§7 输出） |
| **LC3** | **`wrapper.*` 只能手工维护** | `generate` **不产** `wrapper.*`；`wrapper.aup` 里的 `i18n {}` 块**运行期不生效**（它就是文档性声明）⇒ **改 `wrapper.*` 必须直接改 locale JSON** | 实测：`wrapper.*` 键 **37** 个（`nav-*` **31**），均在 `.aup/locales/*.json` 里；`.aup/wrapper.aup` 仍有 1 个 `i18n {}` 块（**声明性**） |
| **LC4** | **死键由平台 `arc dsl lint` 报告** | 判据取 `arc dsl lint --json` 的 `dead_locale_keys`，**计数从命令取、不得写死** | 本篇 §3-W07 |
| **LC5** | **禁止整体 `arc dsl lint --fix`** | `--fix` 会剥掉**只有运行期寻址**的 id（如 `.aup/wrapper.aup:42` 的 `site-header`——它是 `nav-click` 事件的目标）。实测：lint 的 **89** 条 issue **全部**是 `unreferenced_explicit_id`，即"**要删的正好是不该删的那批**" | 实测 `arc dsl lint --json` → `{"unreferenced_explicit_id": 89}`；`site-header` 见 `.aup/wrapper.aup:42` |
| **LC6** | 键的生命周期**随页面走** | 键名 = `<page>.<key>`（页面作用域）；**跨页引用他人的键 = 命名空间泄漏**（W03） | 本篇 §3-W03 |
| **LC7** | 改了 `wrapper.*` 或页面 `i18n {}` ⇒ **必须重跑 `arc dsl generate`** | 否则 `.aup/locales/*.json` 与源码不一致（`arc dsl generate --check` 今天不在任何测试里，见 [`docs/05-开发文档/05`](../05-开发文档/05-测试分层与质量门.md) §8） | `arc dsl generate` 默认 **dry-run**；带 `--write` 才落盘 |

> **LC5 的教训（写入纪律）**：**"平台提供的批量修复"不等于"可以批量的修复"**——`--fix` 的目的（清未引用 id）与运行期寻址（事件目标）**在同一语法位**上，因此只能**逐条**判断。这与 [`00 §4`](00-总则与形态纪律.md) 的"看起来会红的门 ≠ 真的会红的门"是同一类错误的两面。

## 2. 条款清单（W01–W08）

| ID | 条款（祈使句） | 类型 |
| :-: | --- | --- |
| **W01** | 每个 `$t()` 引用在 `en`/`zh` **都有串** | 可机检（**已有门** `arcblog-i18n`） |
| **W02** | `$t()` 的 key 必须是**编译期常量**（禁运行期拼 key） | 可机检 |
| **W03** | 页面**不得**引用**别的页面**的 i18n 命名空间 | 可机检 |
| **W04** | 门禁标题 `gate-title` == 页头 `title`（**同一页一个名字**） | 可机检 |
| **W05** | **三处同名**：门禁 / 页头 / 侧栏短式**指代一致** | 人工审查（[`06 §2 N6`](06-导航与IA.md) 给键归属） |

| **W08-d** | **未落盘能力**（`?page=agents` 的发现/汇总/chat/生成/转让/记忆）文案**必须**标【规划中】+ 前置探针（`P-1`/`P-3`/`P-4`）；**不得**用"已可用/已开通"等措辞 | 可机检 `grep`（[`07 §1`](07-验收清单与机检.md) 收表；`BD-09` 同口径） |

## 4. W08 的三条负例（**判据 → 命令 → 真实输出**）

| # | 禁令（引 [`03 §2`](03-状态与降级.md)，不重定义） | 负例 `grep` | 规则声明行豁免 |
| :-: | --- | --- | --- |
| **W08-a** | 不得声称"RSS 已就绪"（`BD-02`） | `grep -rn 'always on' .aup/pages/ --include=*.aup` —— ⚠️ **须与"分发面 / 产物已就绪"语义同现**才算违规：实测 **2 行**中 `.aup/pages/ops/agents.aup:37` 的 *"Read tools are always on"* 是对**工具模型**的**真陈述**，**不属**本禁令（排除登记见 [`docs/06-功能列表 03 §6 E3`](../06-功能开发列表/03-缺陷与待修.md)） | 同行含 `不得\|禁止\|不说\|无此` 即豁免（**规则源必须能提名它禁掉的东西**） |
| **W08-b** | 不得出现"自定义域名下的 feed / API"（`BD-03`） | `grep -rnE '自定义域名\|custom domain.*(feed\|api)' .aup/pages/ --include=*.aup` | 同上；⚠️ **`/.well-known/service/login` 不是本禁令对象**（它是**平台登录流**，实测 23 个文件在用且可用）⇒ 见下方**豁免** |
| **W08-c** | 注册表未接时不得用空列表冒充"链上没有节点"（`BD-04`） | `grep -rn '0 个节点\|no nodes' .aup/pages/ --include=*.aup` | **前置未满足**：`.aup/pages/ops/registry.aup` **尚不存在**（见下） |

**W08-b 的豁免（避免假红，M5）**：`.well-known/service/login` 是 **DID 登录跳转**（平台能力），不是"对外导出的 feed/API 出口"。判据**必须**把它排除，否则会误伤 23 个正当用法。
**W08-c 的前置**：`registry` 页待创建 ⇒ 该行**当前不可判**，必须**显式打印前置**，**不得静默跳过**（与 [`03 §4`](03-状态与降级.md) 同一处理）。

**本轮真实输出**
```text
$ grep -rn 'always on' .aup/pages/ --include=*.aup
.aup/pages/site/feeds.aup:5:    feeds-desc { en "These surfaces are always on and generated from published content — nothing to configure." ... }
.aup/pages/ops/agents.aup:37:  tools-desc { en "Every tool the agent surface declares, … Read tools are always on; write tools need a time-boxed grant; closed tools never run." ... }
# ↑ 共 2 行 / 2 次；**其中只有第 1 行是违规**（第 2 行是对工具模型的真陈述，见下方语义限定）

$ grep -rl '/p/rss.xml' .aup/ | wc -l          → 35        # 其中 .aup/pages/ 下 *.aup = 28
$ grep -ro '/p/rss.xml' .aup/ | wc -l          → 38
$ test -e .web-cache/rss.xml && echo EXISTS || echo ABSENT   → ABSENT
$ grep -rlo '/.well-known/service/login' .aup/pages/ | wc -l → 23   # 豁免对象（登录流）
$ grep -rn '0 个节点\|no nodes' .aup/pages/ --include=*.aup → （无输出）
$ test -f .aup/pages/ops/registry.aup → BD-04 前置未满足（registry 页尚未创建）
```

> **结论（诚实）**：`W08-a` **当前不达标**（`feeds.aup:5` 的 `always on` + 28 个页面链 `/p/rss.xml`，而产物不存在）；`W08-b` **当前 0 命中**（无自定义域名出口的断言；`/.well-known/service/login` 已排除）；`W08-c` **前置未满足**，登记待页面创建后复跑。

## 5. 反例（本域）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| `$t(other-page.key)` 借别页命名空间 | 命名空间泄漏（**实测 4 页**）；键的归属与生命周期错乱 | W03：声明在本页 `i18n {}` 并用本页键 |
| 只改页头、不管门禁/侧栏 | 同一页两个名字，用户以为进了两个页面 | W04/W05：**三处同批**改 |
| 留 `label="SEO Title"` 英文字面 | 中文环境出现英文，且**绕过 i18n 门** | W06：`label="$t(<page>.f-…)"` |
| 运行期拼 key（`$t(${state.x})`） | **原样渲染且不报错** ⇒ 静默坏 | W02：编译期常量 |
| 死键留着"以后可能用" | `dead_locale_keys` 是平台门，留着即隐性坏 | W07：删键或在**本页** `i18n {}` 显式声明 |
| 改 `wrapper.*` 去改 `wrapper.aup` 的 `i18n {}` | **运行时不用那个块** ⇒ 改了不生效 | LC3：直接改 `.aup/locales/*.json` |
| 整体跑 `arc dsl lint --fix` | 会剥掉运行期寻址 id（`site-header` 等 **89** 条全是这类） | LC5：只读 `--json`，`--fix` 禁用 |
| 写 "RSS／订阅已就绪，无需配置" | **假绿灯**：产物不存在，读者拿不到 feed | W08-a：降级写法（未生成 + 生成命令） |
| 未接状态下写"链上有 0 个节点" | 把"**未接**"说成"**确无**"（[`03 §3 F1`](03-状态与降级.md)） | W08-c：三样同现（未接 + 探针 `P-1` + 核对入口） |

## 7. 本篇机检（代码 + 命令 + **真实输出**同处一篇）

```bash
python3 - <<'ZZ'
import re,glob,json
# LC1：扁平点号键
for l in ('en','zh'):
    d=json.load(open(f'.aup/locales/{l}.json',encoding='utf-8'))
    print(f'LC1 {l}: keys={len(d)} 嵌套={sum(1 for v in d.values() if isinstance(v,dict))} 点号键={sum(1 for k in d if "." in k)}')
print('LC3 wrapper.* 键 =',sum(1 for k in json.load(open('.aup/locales/en.json',encoding='utf-8')) if k.startswith('wrapper.')))
files=glob.glob('.aup/pages/admin/*.aup')+glob.glob('.aup/pages/site/*.aup')+glob.glob('.aup/pages/ops/*.aup')+glob.glob('.aup/pages/*.aup')
def blk(s):
    m=re.search(r'\bi18n\s*\{',s)
    if not m: return ''
    i=m.end(); d=1
    while i<len(s) and d:
        d += 1 if s[i]=='{' else (-1 if s[i]=='}' else 0); i+=1
    return s[m.end():i-1]
t3=[];t4=[];t2=t6=0
for f in files:
```
