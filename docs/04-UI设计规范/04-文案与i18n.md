## 3. 反例（`S4-03 §6` 中属于本篇的部分）

| 反例写法 | 为什么错 | 正确写法 |
| --- | --- | --- |
| `$t(other-page.key)` 借别页命名空间 | 命名空间泄漏（**6 处实测**）；键的生命周期与归属错乱 | T03：声明在本页 `i18n {}` 并用本页键 |
| 只改页头不管门禁/侧栏 | 同一页两个名字，用户看到"两个页面" | T04/T05：**三处同批**改 |
| 留 `label="SEO Title"` 英文字面 | 中文环境出现英文；且绕过 i18n 门 | T06：`label="$t(<page>.f-...)"` |
| 运行期拼 key（`$t(${state.x})`） | 原样渲染且**不报错** ⇒ 静默坏 | T02：编译期常量 |
| 死键留着"以后可能用" | `dead_locale_keys` 是平台门；留着即隐性坏 | T07：删键或在本页 `i18n {}` 显式声明 |
| `arc dsl lint --fix` 整体跑一遍清死键 | 会剥掉**运行时 id**（`site-header`/hero frame） | 只跑 `arc dsl lint --json` 读 `dead_locale_keys`；`--fix` 禁用 |

## 5. 本篇机检（可粘贴；判据见 `07 §2`（本篇 §5 给本篇条款的真实输出））

```bash
python3 - <<'ZZ'
import re,glob
t={f:open(f,encoding='utf-8').read() for f in glob.glob('.aup/pages/*/*.aup')+glob.glob('.aup/pages/*.aup')}
print('T02 运行期拼 key =',sum(len(re.findall(r'\$t\([a-zA-Z0-9_-]+\.\$\{',v)) for v in t.values()))
print('T06 英文字面字段 =',sum(len(re.findall(r'label="(SEO Title|OG )',v)) for v in t.values()))
bad=[]
for f,v in t.items():
    pid=re.search(r'page\s+([a-z0-9-]+)',v)
    ns=set(re.findall(r'\$t\(([a-z0-9-]+)\.',v))-{'wrapper'}
    if pid and ns-{pid.group(1)}: bad.append((f.split('/')[-1],sorted(ns-{pid.group(1)})))
print('T03 命名空间泄漏页 =',len(bad),bad)
t4=[]
for f,v in t.items():
    g=re.search(r'gate-title[^)]*\{[^}]*?en\s+"([^"]+)"',v) or re.search(r'gate-title[^}]*?en\s+"([^"]+)"',v)
    h=re.search(r'title\s*\{[^}]*?en\s+"([^"]+)"',v)
    if g and h and g.group(1)!=h.group(1): t4.append((f.split('/')[-1],g.group(1),h.group(1)))
print('T04 gate-title != title =',len(t4),t4)
ZZ
```

**判据**：`T02 = 0`；`T06` 逐步降至 0（现 8）；`T03` 现 6 页、目标 0；`T04` 现 2、目标 **0（D6）**。
