## 7. 机检（本篇）

```bash
# 形态纪律 M1/M2/M4（按字符）
python3 - <<'ZZ'
import glob
for f in sorted(glob.glob('docs/04-UI设计规范/*.md')):
    ls=open(f,encoding='utf-8').read().split('\n')
    v=[l for l in ls[:10] if l.startswith('| 版本 |')]
    over=[i for i,l in enumerate(ls,1) if len(l)>800]
    print(f'{f.split("/")[-1]}: lines={len(ls)} ver_len={len(v[0]) if v else "MISS"} over800={over}')
ZZ
```

**判据**：每篇 `ver_len ≤ 80`、`over800 = []`、`lines ≤ 400`。
**唯一出处机检**：见 `07 §6`（与 Stage 3 `00-原则 §8` 第 7 条同法）。
