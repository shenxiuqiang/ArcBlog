## 同步规则（重要）

**两个文档必须同步修改：**

1. **修改产品文档 → 同步本清单**：规格中新增功能 → 本清单新增一行（状态 ⬜）；规格中修改功能定义 → 更新对应行的"规格章节"与备注；规格中删除功能 → 删除对应行。
2. **功能实现完成 → 更新本清单**：将状态从 ⬜ / 🟡 改为 ✅，并在"实现位置"列填写代码入口。
3. **以规格为准**：任何不一致时，产品文档是权威来源（spec §150 原则同样适用于文档本身）。
4. 每行必须带**规格章节号**（如 §8.3），保证双向可定位。
