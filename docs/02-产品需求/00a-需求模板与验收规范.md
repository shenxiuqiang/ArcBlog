## 3. 验收标准规范

### 3.1 验收四件套（每条需求必备）

```text
PRD-XXX-NN  <一行需求>
├─ 上游      : 01 §n（节标题前 4 字） / 03 §n J<n>-<m> / 00 §12.x 第 N 条 / 04 §x
├─ 验收      : <一条可执行命令 或 一条可观察行为>   ← 禁止"体验更好""更完善"
├─ 证据形态  : <AFS 前后对比 / 命令 + `success`/错误码 + 原始输出摘要 / 可观察态>
└─ 负例      : <必须失败的路径 + 期望错误码或行为>   ← 缺负例视为未完成
```

### 3.2 三段分组（采纳 S2-02 §1.3）

`A 组` 功能断言 ｜ `B 组` 负例与 fail-closed ｜ `C 组` 零回归与质量门。每组每条带编号（`A1…`、`B1…`、`C1…`），便于轮末逐条回填。

### 3.3 五条硬规则

① 平台做不到的必须引 `R3 §4-N` 并给降级路径，**不得承诺**（门 G5）；② 资金/上链类必须写**前置批准点**（人类批准）；③ 页面写入类必须写"入队 ≠ 生效"（意图队列）；④ 每条需求必须能被判**通过 / 不通过 / 受限【未验证】**三值之一；⑤ 证据基线写 commit sha。

### 3.4 "好 / 坏"对照

**不复制**：[`S2-02 §2`](../08-其他/调研/S2-02-需求规范与验收标准.md) 已给 10 对（含归档原文与改写版），全部采纳。**本目录新增的三条自用判据**（源自 Stage 1 事实审查的教训）：

| # | 场景 | 判据写法 |
| :-: | --- | --- |
| N1 | 引用上游节号 | 必须写 `§n（节标题前 4 字）`；机检：`grep -cE '§[0-9]+（' ` 与 `§` 总数一致 |
| N2 | 断言"页面可观察" | 不得用 `body.innerText` 打状态断言（会被常驻文案命中，见 S2-02 §2 第 2 行）；只取**行文本**且正文断言与常驻文案断言分列 |
| N3 | 平台不可能成立的语义 | 写判据前先问"平台是否渲染该控件/该状态是否可达"；不可达就改写为替代口径（如 `total ≤ pageSize` 时平台**不渲染**分页器） |

### 5.2 逐条目结构判据（**"出现即通过"不算判据**）

> **动因（Lead 抽检）**：`01-CNT` 的 `PRD-CNT-01` 曾把两节写成 `**§7 结果记录**` 与 `**§7 写范围 / §8 开放问题**`（编号错位 + 两节合并），而当时自检只查"文件里是否出现过 `§6 写范围`" ⇒ **报 0 残留却漏掉该条**。**判据必须逐条目核对 8 节齐全与顺序**。

**判据（可粘贴；只读）**：把每个 `### 3.x …PRD-…` 切一块，核对块内 8 节**齐全且顺序正确**。节标签 = `**§N <名称>**`，名称须以该 N 的规定名开头（§1 背景 / §2 范围 / §3 验收 / §4 平台边界 / §5 依赖 / **§6 写范围** / **§7 结果记录** / §8 开放问题）；名称受限可排除 `（**§4 未收录 ⇒ 不臆造编号**）` 这类行内引用；标签允许在行内（本目录约定 §5–§8 常合并一行）。

```bash
python3 - <<'PY'
import re, glob
EXP=[('§1','背景'),('§2','范围'),('§3','验收'),('§4','平台边界'),('§5','依赖'),('§6','写范围'),('§7','结果记录'),('§8','开放问题')]
NAME=dict(EXP); bad=0; checked=0
for f in sorted(glob.glob('docs/02-产品需求/0[1-8]-*.md')):
    lines=open(f,encoding='utf-8').read().split('\n'); blocks=[]; cur=None
    for i,l in enumerate(lines,1):
        if re.match(r'^#{1,3} ',l):
            if cur: blocks.append(cur); cur=None
            if re.match(r'^### 3\.\d+ .*PRD-',l): cur=[l.strip(),i,[]]
        elif cur is not None: cur[2].append((i,l))
    if cur: blocks.append(cur)
    for title,start,body in blocks:
        checked+=1; labels=[]
        for i,l in body:
            for m in re.finditer(r'\*\*(§[0-9]+) ([^*]+?)\*\*',l):
                n,name=m.group(1),m.group(2).strip()
                if n in NAME and name.startswith(NAME[n]): labels.append((n,i))
        if [x[0] for x in labels]!=[x[0] for x in EXP]:
            bad+=1; print('FAIL',f.split('/')[-1],'::',title[:46],[f'{a}@{b}' for a,b in labels])
print(f'entries checked = {checked}, failures = {bad}')
PY
```

**判据（本轮基线）**：`entries checked = 50, failures = 0`（50 = 需求总数，与 `00 §9` 第 9/10 条一致）。
**敏感性要求**：判据必须**抓得住**"编号错位/两节合并"——把任一 `<PRD-…>` 块的 `**§6 写范围**` 改成 `**§7 写范围 / §8 开放问题**` 后必须报 FAIL（本轮已用回滚副本验证：**副本 1 FAIL、正本 0 FAIL**）。**改判据后必须重跑这两个用例**。

### 5.3 锚点与缩写引用判据（`§5.1` #10 / #11 的脚本）

> **动因**：产品审查 A 指出 `PRD-SITE-02` 的来源追溯不属四类锚点（该能力未登记在 `00 §12.1`）；pm 复审 B 指出 **`PRD-SITE-07`（已撤销）的缩写形态**（`PRD-SITE-03/07`）漏网——全文 `grep` 抓不到。两条判据合成一个脚本：

```bash
python3 - <<'PY'
import re,glob
SEC=r'§\d+(?:\.\d+)*'
files=sorted(glob.glob('docs/02-产品需求/0[1-8]-*.md')); built=set(); rows=[]
for f in files:
    for i,l in enumerate(open(f,encoding='utf-8').read().split('\n'),1):
        m=re.match(r'^\| \*{0,2}(PRD-[A-Z]+-\d{2})\*{0,2} \|',l)
        if m:
            built.add(m.group(1)); c=[x.strip() for x in l.split('|')]
            rows.append((f,i,m.group(1),re.sub(r'\[([^\]]+)\]\([^)]*\)',r'\1',c[4] if len(c)>4 else '')))
C=[re.compile(r'`01 '+SEC+r'（[^）]+）`'),
   re.compile(r'`03 '+SEC+r'（[^）]*J\d+(?:-\d+)?[^）]*）`|`03 '+SEC+r'（[^）]+）`.*J\d+'),
   re.compile(r'00 §12\.\d（上游断链接收）`?\s*第\s*\d+\s*条.*R[14]'),
   re.compile(r'`04 '+SEC+r'（[^）]+）`')]
bad=0
for f,i,rid,src in rows:
    if not any(c.search(src) for c in C): bad+=1; print('ANCHOR-FAIL',f,i,rid,src[:90])
print(f'anchor rows = {len(rows)}, failures = {bad}')
bad2=0
for f in sorted(glob.glob('docs/02-产品需求/0*.md')):
    for i,l in enumerate(open(f,encoding='utf-8').read().split('\n'),1):
        if '撤销' in l: continue
        for m in re.finditer(r'(PRD-[A-Z]+)-(\d{2})((?:/\d{2})+)',l):
            for n in re.findall(r'\d{2}',m.group(3)):
                if f'{m.group(1)}-{n}' not in built: bad2+=1; print('ABBREV-FAIL',f,i,f'{m.group(1)}-{n}')
print(f'abbrev-ref failures = {bad2}')
PY
```

**判据（本轮基线）**：`anchor rows = 50, failures = 0` 且 `abbrev-ref failures = 0`。
