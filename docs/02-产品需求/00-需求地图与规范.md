## 2. 领域图（**7 个**）

| 领域码 | 名称 | 一句话范围 | 与相邻领域的分界 |
| :-: | --- | --- | --- |
| **CNT** | 内容创作 | 写作、草稿/发布/归档/软删、分类与标签、静态页、媒体资产、**agent 生成草稿的人审与署名** | 不定义"怎么发到公开面"（→ `SITE`）；不定义"谁能写"（→ `ID`） |
| **SITE** | 发布与站点 | 公开页与稳定 URL、首页推荐位、站点级分发元数据、**只读出口作为被 agent 读取的契约** | 不定义"发现"（→ `NET`）；不定义"agent 怎么汇总"（→ `AGT`） |
| **NET** | 发现与网络 | **链上注册表**（质押即目录）、节点自描述（`endpoint`/`region`）、可达性与时效、**被 agent 发现的数据面** | 不定义"agent 读到后做什么"（→ `AGT`）；不定义"角色资格"（→ `ID`） |
| **ID** | 身份与角色 | DID 身份、**studio 单一角色**与能力派生（fail closed）、**链上节点生命周期**（购买/质押/撤销/清空/转让）、私域数据隔离 | 不定义"运维可见性"（→ `OPS`）；不定义"发现"（→ `NET`） |
| **AGT** | Agent（**主干**） | agent 的公开读取面、能力档与授权、**发现→汇总→chat→生成→发布**的编排、**记忆（先本地）** | 不定义注册表本身（→ `NET`）；不定义"页面上怎么写"（→ Stage 3） |
| **OPS** | 治理与运维 | 节点巡检与排障可见性、自检项、清理（dry-run）、构建/密钥门**告知面**、退出搬迁的**可见步骤**、平台方治理的合规面 | **不拥有链上生命周期**（→ `ID`）；不定义"平台能不能"（→ Stage 5） |
| **SET** | 设置与外观 | 实例设置（身份/语言时区/开关）、外观与主题、设置项的权限边界、实例外壳一致性 | 不定义"本地化文案内容"（→ Stage 4）；不定义"权限模型"（→ `ID`） |

**领域边界的两条落定**（详见 §5）：链上节点生命周期归 `ID`；注册表与节点自描述归 `NET`，"读到之后做什么"归 `AGT`。

## 3. 实现状态**不在本目录**（唯一出处 = `docs/06-功能开发列表/`）

> **本目录不定义、也不填写"六态"**（`未开工｜开发中｜已实现待验｜已验证｜平台边界｜已废弃`）。
> **实现状态（六态 + 正交阻塞 `无｜待决策｜待批准｜待平台能力`）的唯一定义点 = `docs/06-功能开发列表/`**（Stage 6 落盘）。
> **本目录只用五类"现状事实标签"**（【已实现】【规划中】【平台边界】【决策待定】【未验证】，**门槛 = [`docs/README.md`](../README.md) §3.1**）。它断言的是"**今天的代码/实测**长什么样"，**不是**"这条需求做到哪了"。

### 3.1 给 Stage 6 的输入要求（**必须执行**）

| # | 要求 | 判据 |
| :-: | --- | --- |
| 1 | **`已验证` 只能由独立方给出**；自证最高到 `已实现待验` | 台账条目有**独立验证者**署名（验证人 ≠ 实现人） |
| 2 | **"机制在平台上存在" ≠ "本项目已接"** | **判据 = 仓库里能指到调用点/产物**。**反例（本项目踩过）**：链上枚举 `listStakes` 曾"SDK 有、本项目适配器与 mock 都没有"（当时 `grep` = 0）⇒ 当时只能写 `未开工`/`开发中`；**2026-10-12 同步**：`ENG-02`/`ENG-03` 已接线（`grep -c listStakes scripts/lib/chain.mjs` = **3**；`P-1` mock 全过 + `P-2` beta 真链只读 `code: OK, total: 1`）⇒ 今天写 `已实现待验`。**规则不变，例随事实更新** |
| 3 | **通道可用 ≠ 产物就绪** | **反例（本项目踩过）**：`/p/rss.xml` 通道【已实现】而仓库根 `.web-cache/rss.xml` 曾不存在（需手跑 `arcblog-rss.mjs`）⇒ 当时写 `开发中`。**2026-10-12 同步**：RSS 生成已并入**部署管线步骤 3b**（`build → deploy → rss → verify`，`node scripts/arcblog-deploy.mjs`），部署后存活校验含 `/p/rss.xml`（`DEF-28`；实测 **200 `application/xml`**）⇒ 今天写 `已实现待验`；⚠️ **裸 `arc blocklet build` 会重建 `.web-cache/` 把它抹掉** ⇒ 必须走 deploy |
| 4 | **概念追溯是台账的前置** | 台账每条 `FP-` 必须能回到一条本目录 `PRD-`，且该 `PRD-` 有概念条款（`00a §3-A1`） |

## 5. 本阶段要裁的两处（**本篇落定**）

| # | 问题 | **落定** | 理由 |
| :-: | --- | --- | --- |
| **S2-A** | 链上节点生命周期归哪 | **归 `ID`**：购买 → 质押 → 撤销 → **清空**（清质押字段、留 mint 字段；`updateAsset` **已接线**，`ENG-05`）→ **转让**（**接线【已实现】**，`ENG-06`；真链执行**待人类批准**）；**`OPS` 只管运维可见性**（"我是否在注册表里"、"只读出口自检"、"残留清理"） | 生命周期改的是**资格与所有权**（身份域），运维只读它；避免两域各写一套状态机（同一事实两处定义是已发生过的形态病） |
| **S2-B** | "被 agent 发现"怎么拆 | **注册表与节点自描述归 `NET`**（"有哪些节点、可达信息是什么"）；**"agent 能读到/怎么汇总"归 `AGT`**；两域**交叉引用、不重复定义**（`AGT` 引用 `NET` 的需求号，反之亦然） | 概念层已按此拆分（`04 §1` 的「链上注册表」vs「agent 聚合」）；一处定义、一处消费 |

## 8. 机检（可粘贴；**真实输出见本节**）

````bash
python3 - <<'ZZ'
import re,glob,collections,sys
BT=chr(96)                       # 反引号（不在本文里写字面三反引号，避免截断代码块）
codes={'CNT','SITE','NET','ID','AGT','OPS','SET'}
bad=[];rows=0;per=collections.Counter()
for f in sorted(glob.glob('docs/02-产品需求/0[1-9]-*.md')):
    sec=''
    for l in open(f,encoding='utf-8'):
        if l.startswith('## '): sec=l.strip()
        for m in re.finditer(BT+r'PRD-([A-Z]+)-\d{2}'+BT,l):
            if m.group(1) not in codes: bad.append(f'{f}: {m.group(0)} 领域码非法')
        if re.match(r'^\|\s*'+BT+r'PRD-',l) and '需求总表' in sec:
            m=re.search(BT+r'(PRD-([A-Z]+)-\d{2})'+BT,l)
            if m: rows+=1; per[m.group(1)]+=1
dups=sorted(k for k,v in per.items() if v>1)
ok = not bad and not dups and rows==56
print('领域码检查:', sorted(set(bad)) or 'PASS')
print('口径A 需求总表行数 =',rows,'｜ 唯一编号 =',len(per),'｜ 重复编号 =',dups or '无')
print('VERDICT','PASS' if ok else 'FAIL')
sys.exit(0 if ok else 1)         # FAIL 必须非 0 退出
ZZ
````

**真实输出（本机实跑 2026-10-01）**
```text
领域码检查: PASS
口径A 需求总表行数 = 56 ｜ 唯一编号 = 56 ｜ 重复编号 = 无
VERDICT PASS
rc = 0
```

**判据**：领域码合法、无重复编号、口径A = **56**（与 `_count.sh` 一致）；链接 0 MISS；每篇 `wc -l` ≤400、单行 `len(str)` ≤800。
