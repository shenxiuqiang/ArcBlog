## 1. 能力组

| # | 能力组 | 一句话 |

| S1 | 公开页与 URL | 每篇内容有稳定 URL，可分页/绑定路由 |

| S3 | 分发元数据 | 站点级 SEO/OG 与文章级分享卡 |

| S6 | 匿名只读 | 无需登录、零泄漏；**读者关系不被平台持有** |

## 4. 不做什么（本域）

| 项 | 理由 |
| --- | --- |
| 不做根级自定义 HTTP 端点 | 【平台边界】（应用壳吞掉）；替代 = `/p/` 与 AFS |
| 不做平台侧推荐位/排名 | 违背 `01 §6` 不可替代性 |
| 不做"我的订阅"这类平台侧读者关系存储 | `01 §2 P1`：读者关系不被平台持有（订阅留在读者/其 agent 侧） |
