## 3. 需求条目

### 3.1 PRD-SITE-01 · 公开站点页

**§1 背景**：`03 §2（J2 读者）` J2-1/2；现状【已实现】——`/posts/{slug}` 走 `propBind` 取记录、静态页走 `/pages/{slug}`、作者面 `/author`。
**§2 范围**：做——两条公开路由在 guest 会话下都返回 200 且正文完整；不做——不改绑定结构（`blocklet.yaml` `sites[].bindings`）。
**§3 验收标准**
- **A1** guest 访问 `/posts/{slug}` → 200，正文与 `AFS:posts/<slug>.json` 的 `body` 一致（逐字比对首选段落）。
- **A2** guest 访问 `/pages/{slug}` → 200；`/about`、`/author` 可达。
- **A3** 不存在的 slug → not-found 页面（**不得**返回其他文章内容）。
- **B1（负例）** guest 直读 `drafts/<slug>.json` 必须被拒（草稿不得从公开面泄漏）。
- **B2（负例）** 付费文章的**正文**不得出现在公开记录里（`visibility: paid` 的公开副本 `body` 必须为空，`previewOnly: true`）。
- **C1** `scripts/arcblog-permissions.test.mjs` 通过；`npm test` 快层通过。
**§4 平台边界**：无。**§5 依赖**：无。**§6 写范围**：`.aup/pages/reader.aup`、`.aup/pages/page-view.aup`、`blocklet.yaml` 的 bindings（仅当必须时）。**§7 结果记录**：未开工。**§8 开放问题**：无。

### 3.4 PRD-SITE-04 · 文章级分享卡片（OG）（**只读探针已跑：非 JS 抓取零文章级 meta**）

**§1 背景**：`01 §7.2（明确不做）` B1 已记"逐条静态 HTML + 完整 SEO 元数据烘焙"为**平台强制不做**；`R2 §1.3` V-p2 记阅读页未输出 `ogImage/ogTitle`。
**§2 范围**：做——**在 AUP 动态面**输出文章级 OG meta（从记录字段投影）；**不做**——不承诺逐条静态 HTML、不承诺 root 级 `sitemap.xml`/`rss.xml`（平台不可达）。
**§3 验收标准**
- **A1（2026-09-30 更正为双视角）** **JS 视角**：`document.head` 中出现 `og:title` / `og:image`，值与记录字段一致（**可观察**：浏览器内 DOM 断言）。**纯 HTML 抓取视角**：**允许缺失**（实测已证不可达，见 §4）——**不得**再写"页面源字符串断言"。
- **A2** 缺 `ogImage` 时按站点级默认继承；两者皆无时**不输出**空标签（而非输出空值）。**仅适用于 JS 视角**。
- **B1（负例）** 不得声称"根路径 `sitemap.xml` 是真实文件"——根路径返回的是 AUP 壳（`R3 §1`），真文件只在 `/p/` 下；页面/文档均不得写成可得。
- **B2（负例）** **不得把"纯 HTML 抓取能读到文章级 meta"写成已实现或可承诺**——2026-09-30 只读探针**已证伪**（见 §4）；允许的唯一表述是"JS 视角输出 + 非 JS 视角降级"。与 `PRD-CNT-01` **同一纪律、同一写法**（不另立第二套口径）。
- **C1** `npm test` 快层通过。
**§4 平台边界与实测结论（2026-09-30 只读探针；Lead 与 qa 双复核）**：文章级 OG 依赖**逐条静态 HTML**，而公开面是 AUP SPA（`R3 §2.6`；**§4 未收录 ⇒ 不臆造编号**）。**实测**：`curl http://arcblog.localhost:4939/posts/hello-arcblog` → **HTTP 200 / 4944 B**，`og:` **0 命中**、`twitter:` **0 命中**、`<title>AFS</title>`、正文未服务端渲染 ⇒ **纯 HTML 抓取（含绝大多数社交爬虫）拿到的是 SPA 壳、零文章级 meta**；且当前连**站点级** `og:*` 也未输出。

| 结论 | 内容 | 依据 |
| :-: | --- | --- |
| **已定 · 降级 1** | **站点级 meta** 为最低承诺（属 `PRD-SITE-03`），文章级**不向爬虫承诺** | 实测：SPA 壳无任何 `og:*` |
| **已定 · 降级 2** | 阅读页输出**分享卡指引**（可复制文案 / 图 URL，人工分享） | 平台无逐条静态 HTML |
| **仍待验（已缩窄）** | ① 真实分享器预览（Facebook / X 调试器）② **执行 JS 的爬虫**是否读到 `og:*` | 需外部预览器或爬虫 UA，本机不可判 |
| **本条状态** | **【平台边界】**（非 JS 视角）+ **【规划中】**（JS 视角的 `og:*` 输出） | 上表 |
**§5 依赖**：**探针已执行**（2026-09-30 只读；结论见 §4）。**§6 写范围**：`.aup/pages/reader.aup`、`.aup/pages/page-view.aup`。**§7 结果记录**：未开工（**纯 HTML 抓取路径已证不可达；实现只做 JS 视角 meta + 分享卡指引**；不得写成"OG 可用"）。**§8 开放问题**：见 §5.1（O-SITE-3 已裁 = A：先确认再承诺；**2026-09-30 已确认**）。

### 3.5 PRD-SITE-05 · RSS 与分发面

**§1 背景**：`03 §6（J6 访客）` J6-2；现状【已实现】——`scripts/arcblog-rss.mjs` 生成 `/p/rss.xml`；`?page=feeds` 只读总览（`write=0`）。
**§2 范围**：做——RSS 与 `?page=feeds` 的一致、开关生效；不做——不新增分发协议（不做 Atom 之外的自定义协议）。
**§3 验收标准**
- **A1** `node scripts/arcblog-rss.mjs --feed-link <url>` 输出可解析的 XML（项数 = 已发布数，按时间倒序）。
- **A2** `config/switches` 的 RSS 开关关闭后：channel 无 `<item>`（**有消费方**，不同于 Comments 开关）。
- **A3** `?page=feeds` 展示的项数与 `AFS:posts/` 计数一致（**逐值**，不是"看起来对"）。
- **B1（负例）** 草稿/归档记录不得出现在 RSS 中。
- **C1** 快层：`arc dsl validate --json` → `issues: []`（`npm test` 快层亦须通过）；RSS 生成验证需 `npm run test:file -- scripts/arcblog-rss.test.mjs`（**live：写共享实例，先持 `docs/team/.gate-lock`**）——`arcblog-rss` **不在** `FAST_TESTS`，**不得**写成"`npm test` 快层通过（RSS 相关用例）"。
**§4 平台边界**：静态文件只在 `/p/` 下可达且为部署期快照（`R3 §1`）——**构建后必须重新生成 RSS**，顺序不能反；该条属约束列。
**§5 依赖**：`PRD-SET-*`（RSS 开关的写法）。**§6 写范围**：`scripts/arcblog-rss.mjs`、`.aup/pages/site/feeds.aup`、`.web-cache/`（生成物）。**§7 结果记录**：未开工。**§8 开放问题**：无。

### 3.6 PRD-SITE-06 · 主题面与站内导航（**O-SITE-1 = A 已裁，带硬约束**）

**§1 背景**：`03 §6（J6 访客）` J6-1、`R2 §1.3` V-p1——首页只有 Hero + 最新 10 篇；**分类名是纯文本不可点**；无标签页；平台 AFS **无 `search` 动作**（`R3 §1`）。
**§2 范围**：做——给访客"按主题继续逛"的最短路径；不做——不做推荐算法（`01 §7.3（明确不做）`）。
**§2.1 硬约束（O-SITE-1 点名，不得违反）**：
1. 分类/标签面**只能**基于 **`posts/` 目录边界** + **客户端在已加载集合上匹配**；
2. **禁止**写成"按字段服务端筛选"（索引陈旧 + **≤ ~1.8 KB 内联红线**，`R3 §2.1`）；
3. 页面必须给出**常驻说明**："当前实现为前端匹配，集合变大后会降级"——**不得**让读者以为这是全量服务端检索；
4. "自建索引"作为 **Stage 5 候选**登记（**不阻塞本阶段**）。
**§3 验收标准**
- **A1** 首页/阅读页的分类名渲染为**可点击链接**（DOM 可观察：`a[href]`），点击后到达该分类的内容集合。
- **A2** 该集合的列表满足分页契约（`total > pageSize` 有真入口；`total ≤ pageSize` 不渲染且不伪造）。
- **A3** 检索实现走"目录边界 + 客户端匹配"，其**代码路径可判**：不得出现把分类/标签当作服务端 `where` 字段的调用（静态可查）。
- **A4** 页面出现常驻降级说明（可观察文本），内容与 §2.1 第 3 条一致。
- **B1（负例）** 不得出现"点了没反应"的分类（`03 §11（体验红线）` 红线 1）。
- **B2（负例）** 不得因筛选而**静默漏文**：集合计数与 `AFS:posts/` 中该分类的实际条数逐值相等。
- **C1** `npm test` 快层通过。
**§4 平台边界**：站内搜索**平台无 AFS `search` 动作**（`R3 §1`）；下推 `filter` 只对已内联记录可靠（`R3 §2.1`）。降级路径指向 `05-开发文档/` 平台边界篇（Stage 5）。
**§5 依赖**：无。**§6 写范围**：`.aup/pages/index.aup`、新增主题集合页（Stage 3 定名）。**§7 结果记录**：未开工。
