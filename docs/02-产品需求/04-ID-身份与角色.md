## 4. 不做什么（本域）

| 项 | 理由 |
| --- | --- |
| 不做多角色的资格模型 | 现行只有 `studio` 单一角色（`04 §1` 能力档） |
| 不做按 capability 的运行期菜单/按钮显隐 | **【平台边界】**：平台无 capability 求值（[`docs/05-开发文档/02`](../05-开发文档/02-平台能力与边界.md) 能力矩阵 `C2`）⇒ 只分登录/管理员两档 |
| 不做平台侧订阅/记忆记录 | 违背 `01 §2 P1`（读者关系不被平台持有）⇒ 归读者或其 agent |
| 不做付费与访问控制 | 产品选择：不内置支付与访问控制（`01 §2 P3`） |
