## 1. 能力组

| # | 能力组 | 一句话 | 覆盖的 `PRD-` |
| :-: | --- | --- | --- |
| K1 | 巡检与健康可见性 | 一屏回答"节点是否健康、是否还能被读到" | `OPS-01` |

## 4. 不做什么（本域）

| 项 | 理由 |
| --- | --- |
| **不拥有链上节点生命周期**（购买/质押/撤销/清空/转让） | `00 §5` **S2-A 裁决**：生命周期归 [`04-ID`](04-ID-身份与角色.md)；`OPS` 只读它、只做可见性 |
| 不做支付与访问控制的运维面（订单/退款/凭据） | 产品选择：不内置支付与访问控制（`01 §2 P3`） |
| 不在页面里执行运维动作 | 平台约束：命令一律"复制后自行执行"（`.aup/pages/admin/diagnostics.aup:16` 原文"nothing on this page executes"） |
| 不定义"平台能不能" | 唯一出处 = [`docs/05-开发文档/02-平台能力与边界.md`](../05-开发文档/02-平台能力与边界.md) |
