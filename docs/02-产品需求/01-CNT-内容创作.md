## 4. 不做什么（本域）

| 项 | 理由 |
| --- | --- |
| 不做页面内直接发布（应用内） | 【平台边界】：应用无运行时依赖 ⇒ 只能写意图，发布在运营侧（`01 §7`） |
| 不做内容质量/排名的自算指标 | 违背 `01 §6`（"谁被看见"不由平台决定）；计数只取平台给出的分页器 |
| 不做付费/访问控制相关的创作门 | 产品选择：不内置支付与访问控制（`01 §2 P3`） |
