## 1. 这是什么（30 秒）

ArcBlog 是**用 Arc/AUP 写的 DID 原生、Markdown 优先的发布 Blocklet**：

- **没有打包器、没有 dev server、应用本身没有运行时依赖**。应用用 AUP DSL 写（`.aup/app.aup`、`.aup/pages/**/*.aup`、`.aup/man/*.yaml`），加一小撮 Node 运维脚本（`scripts/`）。
- **产品只有两条主线**：① 网络里只有 studio 节点，**聚合由 agent 承担**；② **发现靠链**——所有节点把 studio NFT 质押到同一个 factory 地址，查该地址的质押列表即全部节点。经济体系（付费/打赏/分成/结算/账本）**已整体删除**，不要重新引入。
- **内容存在实例的 AFS 空间**里，通过 `arc` CLI 与页面里的 `/.actions/write` 操作；代码里**没有数据库**。

## 2. 怎么跑起来（5 分钟）

```bash
npm install                 # 只为链脚本（@ocap/*）；应用本身不需要
arc dsl validate --json     # 主门：issues 必须是 []
npm test                    # 快层门：~2 s，32 个套件，不写实例
npm run gate:docs           # 交付门：六个文档卷门合一条命令

npm run build               # 改了 .aup / blocklet.yaml / world/** 才需要（= build + 剔密钥）
node scripts/arcblog-deploy.mjs        # 部署到本机实例（构建 → 校验 → 部署 → RSS → 存活检查）
arc service restart -i default && arc blocklet run . -i default   # ⚠️ 部署后必须复挂，否则浏览器还是旧版
```

- **看站点**：`http://arcblog.localhost:4939`（**不要**用 80 端口，本机没有监听）。控制台会有 2 条 `Refused to execute … (MIME text/html)`——平台侧噪音，不是缺陷。
- **只改一个文件时**：`npm run test:file -- scripts/<name>.test.mjs`（live 套件会写共享实例；先建 `docs/team/.gate-lock`，跑完删掉）。
- **内容操作**：`node scripts/arcblog-lifecycle.mjs publish --title "…" --author-did did:key:z… --body-file post.md --sign-key node.key`（CLI 是唯一会写真实署名的路径）。

## 3. 代码与数据在哪（一张表）

| 位置 | 是什么 | 你需要知道的 |
| --- | --- | --- |
| `.aup/pages/**/*.aup` | **全部页面**（25 个页面 = 17 个控制台 + 8 个公开页） | 页面不在 `app.aup` 里；每个目录一个 glob；每文件**恰好一个根节点** |
| `.aup/wrapper.aup` + `.aup/locales/*.json` | 应用外壳与两语文案 | locale 是**生成物**（`arc dsl generate --write`），但 `wrapper.*` 键**手工维护** |
| `world/*.yaml` | AFS 记录 schema（12 个） | 权威清单见 [`05/01`](05-开发文档/01-数据模型与存储.md) §1 |
| `pages/` + `.web/` + `.route/` | SSR 面与 daemon 路由（`/` → AUP，`/p` → Web） | `.web/components/hero-carousel/script.js` 是**生成物** |
| `scripts/` | 运维 CLI + 测试（32 个快层套件） | 快层白名单只认 `scripts/run-tests.mjs` 的 `FAST_TESTS` |
| 实例 AFS | `posts/`（已发布）· `drafts/`（草稿/归档/软删）· `config/`（设置，admin-only）· `node/`（节点与投影） | 草稿边界靠**目录**，不靠 `visible`（`status` 无法在 DSL 里比较） |
| `seed/settings/arcblog/` | 外观设置默认值 | 主题桥用它驱动整页主题 |

## 7. 改东西之前的三条硬规矩

1. **不臆造 ARC API**：先 `arc <cmd> --help` / `explain` 核验；平台做不到的写进 [`05/02`](05-开发文档/02-平台能力与边界.md) 并给降级路径。
2. **不提交红门**：`validate` + 快层必须绿；改了 `.aup` 还要 `npm run build`，并且**部署后复挂**再核验。
3. **只提交人是你**：唯一提交人 = Lead，检查点提交、精确 `add`；`push`、链上真实写、删数据都要**人类批准**（清单见 [`team/human-checkpoints.md`](team/human-checkpoints.md)）。
