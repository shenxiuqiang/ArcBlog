## 1. 四条设计原则（**承接概念 `01 §2` 的三条承诺，给可判据**）

| # | 原则 | 概念依据 | **可判据** |
| :-: | --- | --- | --- |
| **P1** | **诚实** | `01 §2 P1`（内容与读者关系归用户） | 每个数字/状态都能指到 AFS 记录或链上事实；**做不到就明说**（破折号 + 常驻说明），**禁止假 0/假绿灯/假按钮** |
| **P2** | **可验证** | `01 §6`（发现源在链上、聚合权归用户） | 凡"发现/收录"类界面，**必须给出核对面**（链上浏览器或通用 SDK 指引），**不得**只给自己的口径 |
| **P3** | **克制** | `01 §2 P3`（越简单越好） | 每页**恰 1 个主操作**；新增页面**必须**指到一条 `PRD-`（入口口径 §2 判据） |
| **P4** | **一致** | `04`（术语唯一出处） | 同一事实**只有一个拥有者页**；措辞与 `04` 的术语逐字一致 |

| 组 | 行（`?page=`） | 说明 |
| --- | --- | --- |
| **写作** | `dashboard` `compose` `posts` `media` | 分组不变（`media` 仍在 ops 目录，其处置见 `01 §3`） |

## 4. 事实归属入门（**跨页契约的引子**；细则在 `04-流程与跨页契约`）

| 事实 | **唯一拥有者** | 其它页如何引用 |
| --- | --- | --- |
| "有哪些节点在运行"（注册表） | **`?page=registry`** | 其它页只显示**引用 + 跳转** |
| "我的节点是否在注册表里" | **`?page=registry`**（巡检视角） | `?page=operations` 只给只读摘要 |
| 节点可达信息（`endpoint`/`region`） | **`?page=factory`**（写） + `registry`（读） | `registry` 不提供编辑 |
| agent 的发现/汇总/对话/生成 | **`?page=agents`** | 其它页不复制该工作面 |
| 文章的写作与生命周期 | **`?page=compose` / `?page=posts`** | 公开面只读投影 |

## 5. 命名与引用纪律

| 纪律 | 内容 |
| --- | --- |
| 引用原始证据 | 引 `docs/05-开发文档/附件/`、`docs/08-其他/附件/` 的**原始证据**（逐字转录、**不是**现行结论）必写**全路径** |
| 不写预期数 | 凡数字**要么实测、要么标时点与来源** |
| `?page=` 名 | **零改动**（改名会牵动生成器、测试与外部链接） |
| 事实标签 | 五类，门槛 = 总纲 §3.1；**【未验证】必须给验证步骤与判定式** |
