## 1. 交互模式（M01–M08）

| ID | 模式 | 一句话 | 判据（可判者写命令，否则写人工观察） |
| :-: | --- | --- | --- |
| **M01** | 门禁卡 | 未登录门（两档：访客 / 登录） | 受保护页在未登录时只渲染门禁卡；无内容泄漏（人工 + guest 权限矩阵） |
| **M02** | 意图队列卡 | 页面写入的**唯一反馈范式**：`pending｜running｜applied｜rejected｜noop` | 有页面写接线的页必须出现队列卡；状态词取自 `scripts/lib/intents.mjs` |
| **M03** | 诚实降级 | 平台破折号 `—` + **常驻说明** + 可复制命令 | 不可实现能力出现处必须有常驻说明且含命令（人工） |
| **M04** | 空态 | **引导**（含"下一步"），不断言"没有数据" | 空态为页级常驻元素；**不得**用 `emptyText` 承载指引 |
| **M05** | 错误与恢复 | 原因 + 影响 + **恢复路径** | 每个写动作有失败分支（人工 + grep `onErrorToast` 计数） |
| **M06** | 确认与二次确认 | 不可逆/高风险操作必须确认并说明后果 | 每个 `variant=destructive` 的动作带 `confirm=`（`grep` 可判） |
| **M07** | 复制命令卡 | 平台做不到的"诚实出路"：**可直接粘贴**的命令 | 命令卡文本可复跑（人工抽跑 1 条） |
| **M08** | 列表与分页 | 分页口径唯一：平台原生分页器；`total ≤ pageSize` 不渲染 | `grep` 出 `pagination=manual`；**不得**补假入口/"共 N 条" |

## 2. 三态（**空 / 错 / 降级**）—— 每页必给

| 态 | 写法（唯一出处） | 禁止 |
| --- | --- | --- |
| **空** | 页级**常驻说明** + 平台破折号；文案含"下一步" | `emptyText`；断言"没有数据/队列为空" |
| **错** | **原因 + 影响 + 恢复路径**；fail-closed 的拒绝**零写入** | 只弹成功、无失败分支；用 toast 当成功证据 |
| **降级** | 破折号 + 常驻说明 + **可复制命令（M07）** | 假按钮 / 假 0 / 假绿灯 / 把"已入队"写成"已生效" |

**载态（补充）**：异步取数页给"**未加载完 ≠ 不存在**"两段式说明（唯一出处同此）。

## 3. **【平台边界】项的"界面怎么说"**（B1–B8，逐条给界面文案口径）

| # | 平台事实 | 界面**必须**怎么说 | 界面**不得**怎么说 |
| :-: | --- | --- | --- |
| **B1** | **发布只能在应用之外** | 页面给**可复制的运营侧命令**（`node scripts/arcblog-lifecycle.mjs publish …`）；说明"页面只写意图，发布在运营侧完成" | 不给"发布"按钮；不说"已在应用内发布成功" |
| **B2** | **RSS 由部署管线产出**（步骤 3b；裸 build 会抹掉） | "feed 由部署管线生成并校验：部署后 `/p/rss.xml` 存活；**别用裸 `arc blocklet build`**，用 `node scripts/arcblog-deploy.mjs`" | 不说"由运行时自动产出"；不把裸 build 后的 404 说成正常（2026-10-12 同步，依据 `DEF-28`） |
| **B3** | **根级自定义端点不可用** | 只给 `/p/` 路径的出口（`/p/llms.txt`、`/p/rss.xml`） | 不出现"自定义域名下的 feed / API"、不写 `/.well-known/…`、`/api/…` 可用 |
| **B4** | **注册表枚举已接线**（两适配器均有 `listStakes`；真链只读 `P-2` 已通过，beta，`code: OK`、游标可续） | `?page=registry` **三样同现**：① CLI 预计算的 `stateNote`/`ownNote`（今天的**实际态**，常驻打印） ② 探针 `P-1`/`P-2` 状态 ③ **链上浏览器/通用 SDK 核对入口** | **禁止**用空列表冒充"链上没有节点"；禁止把机制【已实现】写成"本项目已完成"（2026-10-12 同步，依据 `ENG-02`/`ENG-03`/`P-2`） |

| **B5** | **索引陈旧**（`afs-list` 过滤走索引，编辑过的记录会从过滤列表消失） | 列表页给**目录边界口径**（"按目录/时间读，不靠过滤"）+ 缺项时给**可复现命令** | 不得把过滤列表当"就是全部"；不得给"共 N 条"式自算数字 |
| **B6** | **页内上传不可用**（2026-10-14：`?page=media` **已删除** —— 平台设置/浏览器接管媒体面，见 [`S11-02`](../../_research/S11-02-控制台功能 vs 平台设置-删除候选审计.md)） | 媒体面只提供 **CLI**（`arcblog-media …`，索引/refs/orphans/remove）与平台 AFS 浏览器 | **不得把页内上传写成可用路径**；页面可渲染 dropzone，但**必须同时**给**可复制 CLI 命令** + "**本实例实测失败**"的说明（依据 `docs/05-开发文档/02` `B12` 与 `arc-contracts §52`） |
| **B7** | **构建/密钥门告知面** | `?page=diagnostics` 给**只读告知条**："裸 `arc blocklet build` 会把 `node.key`/`.env.local` 复制进 `dist/`（BUG-067）；**只用 `npm run build`**" | 不提供"一键构建"按钮；不静默省略该风险 |
| **B8** | **平台无跨页片段**（`include` 不可用）⇒ 外壳在**每页各一份** | 说明"外壳是**生成物**：改导航须重跑 `node scripts/arcblog-console-nav.mjs`" | 不得说"改一处即全站生效"；不得承诺"组件化外壳" |

**判据（可判者）**：B1 的文案必须与命令同现（正则：含"发布"的句子里出现 `arcblog-lifecycle`）；B2 同 `02 §2` 的判据；B3 负例：页面不得出现 `/.well-known`、`/api/`、`/rss.xml` 作为**可用**出口；B4 **正例**（三样同现，可 `grep`；2026-10-12 同步）：`registry` 文案必须同时出现 ① **CLI 预计算的 `stateNote`/`ownNote`** ② **`P-1`/`P-2`** ③ **链上浏览器/SDK 核对入口**；B4 **负例**：**不得**显示"0 个节点"这类**确定性**空态。B5–B8 的"必须/不得"见上表各行。
