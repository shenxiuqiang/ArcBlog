## 2. 本阶段三件事

1. **页面族定型**：把控制台侧栏与公开面页收敛到**现行产品范围**内的页面集；
2. **流程重画**：概念 `03 §J1`–`§J6` 的**每一步都要有落点**（页面 / URL / CLI）；
3. **跨页契约**：定义"**哪个页面拥有哪个事实**"，同一事实**只有一个拥有者**。

## 5. 流程覆盖（设计必须给出落点；细则在 `04-流程与跨页契约`）

| 概念旅程 | 设计落点 |
| --- | --- |
| `J1` 创作者发布 | `?page=compose` → `?page=posts` → `/posts/{slug}` → **RSS 由部署管线产出**的告知（2026-10-12 同步，依据 `DEF-28`） |
| `J2` 读者读到并订阅 | `/posts`、`/posts/{slug}`、`/p/llms.txt`、`/p/rss.xml`（**管线产出**）；**订阅三义**的界面表达 |
| `J3` 节点加入网络 | `?page=factory`（买/质押/写 `endpoint`）→ **`?page=registry`**（等被 agent 发现）；`PRD-NET-01` **已接线**（`P-2` 通过）的**实际态说明** |
| `J4` **主干** | `?page=agents`：**发现 → 汇总 → chat → 生成草稿 → 发布**（发布只给"复制运营侧命令"） |
| `J5` 退出与转让 | `?page=factory`：撤销 → **清空质押字段** → 转让（【已实现】`ENG-06` mock 已验；**真链待批准**的如实表述）（2026-10-12 同步） |
| `J5b` 巡检排障 | `?page=diagnostics` + **`?page=registry`**（"我是否在注册表里"） |
| `J6` 平台方治理 | `?page=registry` 的**只读核对面**（链上浏览器/通用 SDK 指引） |
