### 2.1 分页契约（C1）
- **唯一口径**：`afs-list` 必须写 `pagination=manual pageSize=N`、`autoSelect=false`、`clickMode=none`、显式稳定 id。
- **真入口 vs 平台不渲染**：`total > pageSize` ⇒ 有真入口（下一页/上一页动作）；`total ≤ pageSize` ⇒ 平台**不渲染**分页器，**不得补假入口**。
- **恢复说明**：可能分页的列表必须紧邻**常驻说明**（`scale=caption intent=muted`），说明当前口径（例："每页 N 条，用下方分页器翻页"）。
- **判据**：每个 `afs-list` 命中上述四属性；可能分页者命中常驻说明；**无**"共 N 页"式自算文案。

### 2.2 意图终态词表（C2）
- **5 态**：`pending｜running｜applied｜rejected｜noop`，**逐字**取自 `scripts/lib/intents.mjs:33`。
- **页面图例**：队列卡必须带 `queue-legend`，图例词集 ⊆ `INTENT_STATUS`；**不得自造状态词**（`03-模式 §4 G1/R1`）。
- **漂移守卫**（Stage 6 立项）：`i18n` 文案 == `INTENT_STATUS` 的比对测试；本阶段只写"唯一真源"与人工审查条款（Lead 裁决 **Q5**）。

### 2.3 三处同名（C3）
- `gate-title`（门禁卡标题）== 该页 `title`（页头）== 侧栏短式；**改名必须同批触及三处**。
- **当前违例 2 处**（`S4-02` 复测）：`admin/general.aup`（**General** ≠ Settings 语义）、`economy/policy.aup`（**Economy** ≠ Split policy）——引用门禁证据时**以这两处为当前成立样本**（**R4**：不再引用已过期的 `media.aup:8`）。
- **判据**：改名批次内三处一致；机器门 **G2**（`03-模式 §4`）。

### 2.4 四态写法（C4）
唯一出处 = **`03-模式 §3`**（空/错/载/降级四条 + `emptyText` 四种写法全无效的平台事实）。本篇只登记"流程中出现四态时，写法回指 `03-模式 §3`"。

### 3.1 矩阵机检（逐条不留空）

```bash
python3 - <<'ZZ'
import re,glob
built=set()
for f in glob.glob('docs/02-产品需求/0[1-8]-*.md'):
    built|=set(re.findall(r'^\| \*{0,2}(PRD-[A-Z]+-\d{2})\*{0,2} \|',open(f,encoding='utf-8').read(),re.M))
rows=[]; seen=set()
for l in open('docs/03-产品设计/04-流程与跨页契约.md',encoding='utf-8'):
    m=re.match(r'^\| `(PRD-[A-Z]+-\d{2})` \| (.+) \|$',l)
    if not m: continue
    rows.append(m.group(1)); cell=m.group(2)
    for a,b in re.findall(r'(PRD-[A-Z]+)-(\d{2})',cell): seen.add(f'{a}-{b}')          # 裸 id
    for a,b,rest in re.findall(r'(PRD-[A-Z]+)-(\d{2})((?:/\d{2})+)',cell):              # 缩写：只认紧邻 PRD 前缀的 /NN
        for n in re.findall(r'\d{2}',rest): seen.add(f'{a}-{n}')
missing=sorted(built-set(rows)); orphan=sorted(seen-built)
print(f'matrix rows = {len(rows)}, missing = {len(missing)}, orphan = {len(orphan)}')
ZZ
```

**判据（本轮基线）**：`matrix rows = 50, missing = 0, orphan = 0`（编号核对**容忍缩写**，与 `00a §5.3` 口径一致）。
