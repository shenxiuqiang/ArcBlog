## 2. 跨页契约（**同一事实只有一个拥有者**）

| 事实 | **唯一拥有者页** | 其它页只做（引用 / 跳转 / 只读摘要） |
| --- | --- | --- |
| 链上注册表（有哪些节点在运行） | **`?page=registry`** | `operations` 只读摘要；`agents` 只**引用** |
| "我的节点是否在注册表里" | **`?page=registry`** | `diagnostics`/`dashboard` 不复制该判定 |
| 节点可达信息（`endpoint`/`region`）**写** | **`?page=factory`** | `registry` 只**读**并展示 |
| 节点可达信息**读** | **`?page=registry`** | `author` 可只读展示自己的 `endpoint` |
| agent 工作面（发现/汇总/chat/生成） | **`?page=agents`** | 其它页不复制 |
| 文章写作与生命周期 | **`?page=compose` / `?page=posts`** | 公开面只读投影 |
| 意图队列状态 | **写入页自身的队列卡（`03-M02`）** | 不在多处重复"队列总览" |
| 只读出口**可用性口径**（通道 vs 产物） | **`02 §2`**（唯一定义点；界面文案口径 = `03 §3-B2`）；`?page=feeds` 是**告知面** | 其它页**只引用**，不得复述"通道/产物"判据 |
| 订阅三义措辞 | **概念 `02 §4`**（本目录不重定义） | `02 §3` 只给落点 |

**判据（G4，修正版）**：**除 `00 §4` 的事实归属入门与本节（`04 §2`）契约表之外**，同一事实**不得有第三处"拥有"表述**（引用/跳转/只读摘要**不算**拥有）；措辞与概念 `04` 术语**逐字一致**。
