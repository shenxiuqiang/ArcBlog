## 1. 骨架与两条公开面专属约束

```text
app-header(site-header，48px；≤768 时 56px)      ← wrapper 提供
└─ 页面自己的内容卡（自然流式滚动）
   └─ app-footer（页脚：关于 / 作者 / 私有清单入口）
```

| # | 约束 | 依据 |
| :-: | --- | --- |
| **A** | **不设根 `view` 高度**（8 页实测均无 `height`）——公开面是**自然流式**，不受 R1 的 `calc(100vh - 48px)` 影响 | `01-骨架 §1`（R1）、`S3-01 §1.2` |
| **B** | **共用 `03-模式` 的"状态与内容模式"**（空态/降级/门禁/队列语义），**不共用控制台骨架**（侧栏/页头不属于公开面） | Lead 裁决 **Q6** |

**响应式（Q7 更新后的公开面结论）**：`/` 四视口 **全绿**（`scrollWidth == clientWidth`、无裁切）；`site-header` 48→56px（≤768）；`--aup-content-max` = 1200px。⇒ 公开面**不需要** `nav-sidebar` 折叠方案（那是控制台侧栏的事，见 `01-骨架 §8`）。**唯一仍属【未验证】的公开面项**：文章级 OG 能否被爬虫/分享器读到（见 §4）。

## 3. 路由绑定与权限边界（**5 个公开绑定 + 2 个控制台绑定**）

**公开绑定 5 个**（`blocklet.yaml:47-78`，实测；之前只列 4 个、漏了 `/store` ⇒ 已修）：
| 绑定 | 页面 | 权限要求 |
| --- | --- | --- |
| `/posts`（列表） | `index` | guest 可读 |
| `/posts/{slug}` | `reader` | guest 可读**公开副本**；付费正文**不在公开记录里**（`previewOnly`） |
| `/pages/{slug}` | `page-view` | guest 可读 |
| `/preview/{slug}` | `preview` | **admin only**（`drafts/` 绑定），guest not-found |
| `/store` | `store` | guest 可读（目录） |
| 页脚入口 | `author` / `saved` / `about` | 无绑定，走 `?page=`；`saved` 需登录（`/user` 私域） |

**另有 2 个控制台绑定**（**不计入公开 URL 集合**）：`/edit/{slug}`（`compose-edit`）、`/manage/seo`（`seo` 的深链入口）。

**判据**：**公开 URL 集合 == 5 个公开绑定 ∪ 页脚 `?page=author|saved|about`**；控制台绑定单独核对（2 个）。
**写接线**：公开面**只有 `saved`、`preview` 两页**有写接线（`S3-01 §1.2` 实测），其余 6 页 `grep -c '/.actions/write'` = **0**。

## 6. 公开面复用与不画清单

**复用的模式**：**清单与定义唯一出处 = [`03-模式 §1`](03-交互模式与状态.md)**（本篇不复述；每页实际用到哪些见 §2 各页的"模式"字段）

## 7. 机检（承接 `00-原则 §8` 五条 + **第 6 条公开面版**）

```bash
python3 - <<'ZZ'
import re,glob
pages=set('index reader store saved preview page-view about author'.split())
bad=0; seen=set()
for f in glob.glob('docs/03-产品设计/02-公开面.md'):
    for b in re.split(r'^### ',open(f,encoding='utf-8').read(),flags=re.M)[1:]:
        n=re.sub(r'[^a-z-]','',b.split(' ')[0])
        if n not in pages: continue
        seen.add(n)
        has=lambda k: re.search(r'\*\*'+re.escape(k)+r'\*\*',b) is not None
        for k in ['PRD','信息分级','四态','模式','预算']:
            if not has(k): bad+=1; print('MISS-KEY',n,k)
        m=re.search(r'-\s*\*\*四态\*\*[：:]([^|]*)',b)
        if not m: bad+=1; print('MISS-4态行',n)
        else:
            for st in ['空','错','载','降级']:
                if st not in m.group(1): bad+=1; print('MISS-STATE',n,st)
miss=sorted(pages-seen)
if miss: bad+=len(miss); print('MISS-PAGES',miss)
print(f"6') pages = {len(seen)}/8, failures = {bad}")
ZZ
```

**判据**：`pages seen = 8 of 8`、`failures = 0`；页名集合 == 8 个公开页枚举。
**其余五条**（① PRD 引用存在性、② 路径、③ 行长按**字符**、④ 链接**跳过围栏代码块**、⑤ 上游 § 引用 `A == B`）见 [`00-原则 §8`](00-设计原则与导航.md)。
