| --- | --- | --- |

## 2. 只读出口：**通道 vs 产物**（界面必须分开说）

| 出口 | 通道 | 产物 | 界面怎么说 |
| --- | --- | --- | --- |
| `/p/llms.txt` | 【已实现】 | 【已实现】 | "可被外部 agent 读取"（**可以**说已就绪） |
| `/p/rss.xml` | 【已实现】 | **【已实现】**：部署管线步骤 3b 生成（`build → deploy → rss → verify`），部署后存活校验含它 | **可以**说已就绪（管线保证）；⚠️ **裸 `arc blocklet build` 会重建 `.web-cache/` 把它抹掉** ⇒ 用 `node scripts/arcblog-deploy.mjs`（2026-10-12 同步，依据 `DEF-28`） |
| 根级 `/.well-known/*`、`/api/*`、`/rss.xml`、`/sitemap.xml` | 【平台边界】 | 无 | **不得**出现"自定义域名下的 feed / API"这类文案；一律指向 `/p/` 路径 |

**判据（可机检）**：公开页与 `?page=feeds` 的文案中，`rss` 相关句**不得**把产物说成"运行时自动产出"；必须能指到**部署管线**（正则：含 `rss` 的句子里出现 `部署`/`deploy`/`管线`/`O8` 之一）（2026-10-12 同步，依据 `DEF-28`）。
**前置（占位符唯一定义）**：`$BASE` = 节点公开基址（`?page=general` 的站点地址）；**全目录只用 `$BASE` 这一种写法**（不再用 `<canonical>` 等）。

## 3. **订阅三义**的界面表达（概念 `02 §4`；唯一出处 = 概念）

| # | 含义 | 界面落点 | 状态 |
| :-: | --- | --- | --- |
| 1 | 浏览器书签 / 本地列表 | `/posts/{slug}` 的"复制链接" | 【已实现】 |
| 2 | RSS 订阅 | `/p/rss.xml` + `?page=feeds` 的告知 | **【已实现】**（部署管线步骤 3b 产出；⚠️ 裸 build 会抹掉 ⇒ 用 `node scripts/arcblog-deploy.mjs`）（2026-10-12 同步，依据 `DEF-28`） |
| 3 | **交给自己的 agent** | `?page=agents` 的"交给 agent 盯"入口：**可复制的运营侧命令**（`arcblog-agent.mjs authorize/run --tool list_studios|get_studio`、`arcblog-summarize.mjs build/show/ask`） | **【已实现】**（CLI 命令面；`/mcp`、`/api/afs/rpc` 由运行时提供、本仓只声明与审计——见 `ENG-12`） |

**一致性判据**：三义的**措辞**与概念 `02 §4` 表格逐字一致；**不得**新增第四义（如平台侧"我的订阅"——违背 `01 §2 P1`）。

## 4. 三态（公开面每页必须给）

| 页 | 空态 | 错态 | 降级态 |
| --- | --- | --- | --- |
| `index` | Hero 无数据 ⇒ **默认卡**（不空白）；列表空 ⇒ 常驻说明 + "去写第一篇" | — | 上传/图片缺失 ⇒ CSS 占位 |
| `reader` | —（详情页） | 失败原因 + 返回入口 | **文章级 OG = `U20` 判定 B（平台边界）**：无 JS 时无文章级 meta（平台无 SSR meta 注入面）⇒ 降级 = 站点级 meta + 分享卡指引（已实现）（2026-10-12 同步） |
| `page-view` | — | 未绑定 ⇒ **"未绑定 ≠ 不存在"**两段式说明 | — |
| `preview` | — | 不存在 ⇒ 明确说明（访客 not-found） | — |
| `author` | 列表空 ⇒ 常驻说明 | — | 角色未知 ⇒ **如实显示 `unknown`**，不猜 |
| `saved` | 门禁/清单说明 | 写失败 ⇒ 原因 + 恢复 | **登出不可见**（不缓存、不泄漏） |
| `about` | — | — | 根级端点不可用 ⇒ 只给 `/p/` 出口 |

## 5. 不做什么（本域）

| 项 | 理由 |
| --- | --- |
| 不做平台侧"我的订阅" | 概念 `01 §2 P1`：读者关系不被平台持有 |
| 不做根级自定义端点 | 【平台边界】（应用壳吞掉） |
| 不做商品与付费类公开页 | 产品选择：不内置支付与访问控制（`01 §2 P3`） |
