## 1. 统一骨架（**唯一配方**）

```text
app-header（壳，来自 wrapper；控制台页不自带）
└─ 侧栏（生成物：scripts/console-nav.mjs → 每页复制一份）
└─ 内容区 = 唯一滚动容器
   └─ 页头卡：标题（短式）+ 一句话用途 + 唯一主操作
```

**三条硬约束**：① 每页**恰 1 个**主操作；② 每页**恰 1 行** `active=true`（当前页）；③ **门禁标题 = 页头标题 = 侧栏短式**（三处同名）。

## 2. 页面族（5 族）

| 族 | 页（`?page=`） | 共性 |
| --- | --- | --- |
| **F1 写作** | `dashboard` `compose` `posts` `media` | 产出内容；都需"来源与署名"可见 |
| **F2 站点** | `pages` `heroes` `categories` `tags` `appearance` `seo` `feeds` | 影响公开面；`feeds` 是**只读出口的告知面** |
| **F3 节点与网络** | `operations` `factory` **`registry`（新增）** `agents` | 链上事实的**读**（`registry`/`operations`）与**写**（`factory`/`agents`） |

| （无侧栏） | `compose-edit` | `/edit/{slug}` 子页 |

> **现行控制台不含"支付与访问控制"族**（`orders`/`policy`/`access`/`ledger` 的处置见 §3）。

## 4. 三处"升级/收窄"的落地要点

| 面 | 要点 |
| --- | --- |
| **`agents` 升主入口** | 五段工作面（2026-10-12 同步）：**发现**【已实现】（`list_studios`/`get_studio`，工具表 12 个）→ **汇总**【已实现】（`summarize build/show/ask`，`node/summaries/` 投影）→ **chat** = 确定性问答【已实现】（`ask` 返回 `cited[]`）+ 对话面【平台边界】（平台无 LLM 原语，`--llm` 未接）→ **生成草稿**【已实现】（`create_draft`）→ **发布**（**只给可复制的运营侧命令**；【平台边界】应用内不可发，属设计如此）；记忆【已实现】（本地 `<repo>/.arcblog/memory`，不落 AFS），DID Space 备份【规划中】 |
| **`factory` 只留 studio** | 四类动作 = 购买 / 质押 / 撤销+清空（**清质押字段、留 mint 字段**）/ 转让【已实现】（`ENG-06`：两适配器 `transfer()`，**mock 端到端已验**（owner=买家）；**⚠️ 真链执行待人类批准**，探针 `P-3`/`U8`）⇒ **不得**写成"已能买卖"（2026-10-12 同步） |
| **`operations` 收窄为只读** | 只给健康与自描述摘要 + 跳 `registry` |
| **`agents` 是否挪目录** | **不挪**（仍在 `ops/`）：`?page=` 名与目录无关；挪目录会牵动 `app.aup` 的每目录 glob、生成器与 `arcblog-console-nav.test.mjs` ⇒ **属 Stage 5/6 实现改动**，如要挪须三处同步（`00 §6 Q3`） |

## 6. 四态与降级总则（每个新页必须给）

| 态 | 要求 |
| --- | --- |
| **空** | 页级**常驻说明**（含"下一步"），**不得**用 `emptyText` 承载指引，**不得**断言"没有数据" |
| **错** | 原因 + 影响 + 恢复路径（可复制命令或目标页） |
| **载** | 异步取数给"未加载完 ≠ 不存在"的两段式说明 |
| **降级** | 【平台边界】项 → **常驻说明 + 可复制命令**；**禁止**假按钮/假 0/假绿灯 |
