## 4. 三类前置与排期

### 4.1 前置分类（`S6-01 §4` + `07 §3`）

| 前置 | 条目 | 为什么是前置 |
| --- | --- | --- |
| **需人类批准**（4 条） | `U8`（真实资金）、`U10`（受信证书/`--token`）、`ENG-16`（Pages 159 个部署存废）、`ENG-18`（回填 Stage 2 矩阵的跨阶段写） | 涉及**资金 / 外部凭据 / 用户数据 / 跨阶段写**，不得由 agent 自行决定 |
