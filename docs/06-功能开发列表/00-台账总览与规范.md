## 2. 状态判据（**G3**）——本阶段最重要的诚实性约束

| 判据 | 内容 |
| --- | --- |
| **自证上限** | 自己读代码 / 读 AFS 得出的结论**只能写 `已实现待验`** |
| **`已验证` 的判据** | **直接引** [`00 §4.2`](../02-产品需求/00-需求地图与规范.md) 的**七要素要求**（**逐字见该节；本篇不另立、不放宽**）；该节同时写明**退出码仅作辅助** |
| **"独立验证者"在本阶段的判定** | 验证者 ≠ 该行的主笔，且**留下了独立复跑记录**（`docs/team/reviews/**` 的实现级 QA）。**文档审查不算实现级 QA** |
| **为什么 `已验证` 今天必然是 0** | `docs/team/reviews/` 只有 S1–S5 的**文档/事实审查**，**没有一条针对实现的独立 QA 记录**，也没有实现级基线 commit（`S6-01 §0` 实测）⇒ 本阶段**不追求翻绿** |
| **P1 裁决（Lead，2026-09-30）** | **接受 `已验证` = 0 为当前基线**；**不得为"好看"把 `S6-01` 的 28 条 `已实现待验` 升格** |

> **一句话**：`已实现待验` 是"我看到它在那儿"，`已验证` 是"**别人**复跑过并留了原始输出"。两者之间没有中间态。

## 4. 证据四件套（填写规则）

字段唯一定义点 = [`00a §1`](../02-产品需求/00a-需求模板与验收规范.md) 第 12 字段。本台账每行**四格**：

| 格 | 填什么 | 允许的省略 |
| :--: | --- | --- |
| ① **证据（文件:行）** | 源码 / `.aup` / `world/*.yaml` 的**精确位置**；或"无证据" | 只读命令输出可代替 `文件:行`（须给命令） |
| ② **命令** | **可原样复跑**的只读命令（禁"我在 /tmp 跑过"） | 无法复跑 ⇒ 写"**无命令**"+ 原因 |
| ③ **输出** | 原样输出摘要（含**解析出的 `success`/错误码**，不是退出码） | 无输出 ⇒ 写"**无输出**" |
| ④ **验证者 · 日期** | **独立**验证者 + ISO 日期；自证只能写"主笔自证"⇒ 状态上限 `已实现待验` | 无验证者 ⇒ 写"**无**"（`已验证` 一律不成立） |

**证据不足时的强制写法**（**严禁空挂**，G2）：状态格写**"无证据"**，并在证据列给出**最小取证命令**（形如 `S6-01 §3` 的 12 条薄弱清单）。
**统计口径**：`已验证` 计数 = "④ 列非'主笔自证'且七要素齐全"的行数 ⇒ 本阶段应恒为 **0**；若不为 0，G8 必红。

## 6. 机检（**G1 / G4 / G8**）——代码 + 命令 + 真实输出同处一篇

> **"跑过 ≠ 写回"**（Stage 5 G8）：本节三个脚本都在**本轮实跑**，输出原样粘贴；下游 `01`–`04` 落盘后**必须复跑**并把新输出贴回本表。

### 6.1 G1 · 50/50 覆盖 + 矩阵对账

```bash
$ python3 - <<'PY'
import io, os, re
m = io.open('docs/03-产品设计/04-流程与跨页契约.md', encoding='utf-8').read()
m = m.split('## 3. 50 条落点矩阵')[1].split('### 3.1')[0]
matrix = set(re.findall(r'PRD-[A-Z]+-\d{2}', m))
path = 'docs/06-功能开发列表/01-功能台账.md'
rows, fp, prd = [], set(), set()
if os.path.exists(path):
    t = io.open(path, encoding='utf-8').read()
    rows = re.findall(r'^\|\s*(FP-[A-Z]+-\d{2})\s*\|\s*(PRD-[A-Z]+-\d{2})\s*\|', t, re.M)
    fp = {a for a, _ in rows}; prd = {b for _, b in rows}
print("matrix", len(matrix), "rows", len(rows), "fp", len(fp))
print("missing", len(matrix - prd), sorted(matrix - prd)[:3])
print("orphan", len(prd - matrix), sorted(prd - matrix)[:3])
print("VERDICT", "PASS" if len(rows) == 50 and fp == matrix == prd else "FAIL")
PY
```

**本轮真实输出**（2026-09-30；`01` 尚未落盘 ⇒ 预期 FAIL）：

```text
matrix 50 rows 0 fp 0
missing 50 ['PRD-AGT-01', 'PRD-AGT-02', 'PRD-AGT-03']
orphan 0 []
VERDICT FAIL
```

**判定式**：`rows == 50` **且** `missing == []` **且** `orphan == []`；任一不满足 ⇒ **G1 红**。`01` 落盘后本行必须变为 `VERDICT PASS`（届时把新输出贴回本节）。

### 6.2 G8 · 状态 ↔ 证据对账

```bash
$ python3 - <<'PY'
import io, os, re
path = 'docs/06-功能开发列表/01-功能台账.md'
bad, verified = [], 0
if os.path.exists(path):
    for line in io.open(path, encoding='utf-8'):
        if not re.match(r'^\|\s*FP-[A-Z]+-\d{2}\s*\|', line): continue
        cells = [c.strip() for c in line.strip().strip('|').split('|')]
        st = next((c for c in cells if c in ('未开工','开发中','已实现待验','已验证','平台边界','已废弃')), '')
        if st == '已验证': verified += 1
        if st in ('已实现待验','已验证') and any(c in ('无证据','无命令','无') for c in cells):
            bad.append((cells[0], st, '证据不全'))
        if st == '已验证' and '主笔自证' in line: bad.append((cells[0], st, '验证者非独立'))
print("violations", len(bad), bad[:5])
print("verified_count", verified)
print("VERDICT", "PASS" if not bad else "FAIL")
PY
```

**本轮真实输出**（`01` 尚未落盘 ⇒ 0 行可检；`verified_count` 已为 0）：

```text
violations 0 []
verified_count 0
VERDICT PASS
```

**判定式**：`violations == 0`；**并检查 `verified_count`**——本阶段必须为 **0**，否则与 §2 的 P1 裁决冲突（G8 红）。
