## 4. 证据四件套（填写规则）

字段唯一定义点 = [`00a §1`](../02-产品需求/00a-需求模板与验收规范.md) 第 12 字段。本台账每行**四格**：

| 格 | 填什么 | 允许的省略 |
| :--: | --- | --- |
| ① **证据（文件:行）** | 源码 / `.aup` / `world/*.yaml` 的**精确位置**；或"无证据" | 只读命令输出可代替 `文件:行`（须给命令） |
| ② **命令** | **可原样复跑**的只读命令（禁"我在 /tmp 跑过"） | **仅 `未开工`/`开发中`** 可写"**无命令**"+**非空原因**；`已实现待验`/`已验证` **不得**用（P2-3 对齐） |
| ③ **输出** | 原样输出摘要（含**解析出的 `success`/错误码**，不是退出码） | 同上：`未开工`/`开发中` 可写"**无输出**"+原因；`已实现待验`/`已验证` **不得**用 |
| ④ **验证者 · 日期** | **独立**验证者 + ISO 日期；自证只能写"主笔自证"⇒ 状态上限 `已实现待验` | 无验证者 ⇒ 写"**无**"（`已验证` 一律不成立） |

**证据不足时的强制写法**（**严禁空挂**，G2；**P1-2 已修正**）：**状态格仍写六态之一**（如 `未开工`/`开发中`），**`无证据` 写在证据格**——形如 `无证据（未开工）` + **最小取证命令**。
**不得**把 `无证据` 写进状态格：G8 取状态会得到空值 ⇒ **整行被跳过 ⇒ 假 PASS**（这是 qa 用对抗变异证出来的路径，新 G8 对"状态格非六态"**直接红**）。
**按态期望（新 G8，全 6 态覆盖）**：

| 状态 | 证据格的强制要求 |
| --- | --- |
| `已实现待验` / `已验证` | 必须含 **`文件:行`（或只读命令输出）** + **命令/输出**；**不得**出现 `无证据/无命令/无输出` |
| `未开工` / `开发中` | 必须有**最小取证命令**；`文件:行` 可用 `无证据（<态>）` 替代 |
| `平台边界` | **必须引 [`05-开发文档 02`](../05-开发文档/02-平台能力与边界.md)**（平台边界唯一定义点） |
| `已废弃` | 必须给**废弃依据**（`DEC-*`） |

**统计口径**：`已验证` 计数 = "④ 列非'主笔自证'且七要素齐全"的行数 ⇒ 本阶段应恒为 **0**；若不为 0，G8 必红。

## 6. 机检（**G1 / G4 / G8**）——代码 + 命令 + 真实输出同处一篇

> **"跑过 ≠ 写回"**（Stage 5 G8）：本节三个脚本都在**本轮实跑**，输出原样粘贴；下游 `01`–`04` 落盘后**必须复跑**并把新输出贴回本表。

> **判据能力边界（声明，不是偶然）**：① **G4** = **逐行可定位**（每个 id 必须出现在**某表格行的首列/来源列**；**出现于区间句不算落点**）；② **G8** = **覆盖全 6 态**（按态设期望，见 §4），**不再只查 2 态**；③ 三条判据都有**敏感性用例**（对抗变异 ⇒ 必红），见 §6.2/§6.3 的"变异"小节。
> **这些判据能抓什么、不能抓什么**：能抓"落点被删/被改""状态格空挂""平台边界不引 `02`""证据不足"；**不能**验证证据内容为真——那属于**独立审查者的工作**（`已验证` 因此必须由独立验证者给出）。

> **留给未来的人（Stage 6 实跑经验）**：本节三条脚本在首版里**有两条真错**——G1 把 `FP-` 集合与 `PRD-` 集合相比（**永不可能相等**），G8 把阻塞列的合法值 `无` 误判成"证据不全"；而 `01 §10.2` 还一度贴了**没跑过的"预期输出"（假 PASS）**。
> 三个问题**都不是**靠仔细读代码发现的，而是靠**把脚本真跑一遍、把输出原样贴回**发现的。⇒ 规矩：**凡写进文档的判据，必须本轮真跑；输出的每一行都必须来自终端，不得凭预期填写**。绿灯本身没有价值，"**能复现的绿灯**"才有。

### 6.1 G1 · 50/50 覆盖 + 矩阵对账

> **⚠️ 修订记录（v0.1 修订 1）**：本脚本首版有一处**真错**——判据写成 `fp == matrix`（把 `FP-` 集合与 `PRD-` 集合相比较），**任何情况下都不可能相等** ⇒ 台账落盘后仍恒 `FAIL`。已改为 `prd == matrix` 且加 `len(fp) == 50` 与 `dup_fp` 检查。**"跑过 ≠ 写回"抓到的正是这种错**。

```bash
$ python3 - <<'PY'
import io, os, re, sys
root = sys.argv[1] if len(sys.argv) > 1 else '.'
m = io.open(os.path.join(root, 'docs/03-产品设计/04-流程与跨页契约.md'), encoding='utf-8').read()
m = m.split('## 3. 50 条落点矩阵')[1].split('### 3.1')[0]
matrix = set(re.findall(r'PRD-[A-Z]+-\d{2}', m))
path = os.path.join(root, 'docs/06-功能开发列表/01-功能台账.md')
rows, fp, prd = [], set(), set()
if os.path.exists(path):
    t = io.open(path, encoding='utf-8').read()
    rows = re.findall(r'^\|\s*(FP-[A-Z]+-\d{2})\s*\|\s*(PRD-[A-Z]+-\d{2})\s*\|', t, re.M)
    fp = {a for a, _ in rows}; prd = {b for _, b in rows}
print("matrix", len(matrix), "rows", len(rows), "fp", len(fp), "prd", len(prd))
print("missing", len(matrix - prd), sorted(matrix - prd)[:3])
print("orphan", len(prd - matrix), sorted(prd - matrix)[:3])
print("dup_fp", len(rows) - len(fp))
print("VERDICT", "PASS" if len(rows) == 50 and len(fp) == 50 and prd == matrix else "FAIL")
PY
```

**正本真实输出**（2026-09-30；`01` 已落盘）：

```text

missing 0 []
orphan 0 []
dup_fp 0
VERDICT PASS
```

### 6.2 G8 · 状态 ↔ 证据对账（**全 6 态**）

> **⚠️ 修订记录（v0.1 修订 4）**：首版有**两条缺陷**，均被 qa 的对抗变异证出：① 只查 `已实现待验/已验证` **2 态** ⇒ 另 4 态（22 行）**无判据**；② 与 §4 自相矛盾——`§4` 要求"证据不足时状态格写 `无证据`"，而 `无证据` 不在六态内 ⇒ G8 取状态得空值 ⇒ **整行被跳过 ⇒ 假 PASS**。现已：**覆盖全 6 态**、**状态格非六态或含 `无证据` ⇒ 直接红**。

### 6.3 G4 · `S6-02` 65 行**逐行可定位**

> **⚠️ 修订记录（v0.1 修订 4）**：首版是**字符串命中**——文档用**区间写法**（`GATE-01…07`、`UNV-01…20`）一句话就"覆盖"整族，qa 用变异证明：**删掉 `02 §2` 的 `ENG-01` 行（`GATE-01` 的唯一落点）后仍报 `covered 65 missing 0 PASS`**。现已改为**逐行可定位**：id 必须出现在**某表格行的首列/来源列**（单元格与 id **完全相等**，允许 `S6-02 ` 前缀）。**出现于区间句不算落点。**

```bash
$ python3 - <<'PY'

loc = set()
for f in glob.glob(os.path.join(root, 'docs/06-功能开发列表/*.md')):
    for line in io.open(f, encoding='utf-8'):

        for cell in re.split(r'(?<!\\)\|', line):
```
