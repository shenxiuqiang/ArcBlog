## 4. 证据四件套（填写规则）

字段唯一定义点 = [`00a §1`](../02-产品需求/00a-需求模板与验收规范.md) 第 12 字段。本台账每行**四格**：

| 格 | 填什么 | 允许的省略 |
| :--: | --- | --- |
| ① **证据（文件:行）** | 源码 / `.aup` / `world/*.yaml` 的**精确位置**；或"无证据" | 只读命令输出可代替 `文件:行`（须给命令） |
| ② **命令** | **可原样复跑**的只读命令（禁"我在 /tmp 跑过"） | 无法复跑 ⇒ 写"**无命令**"+ 原因 |
| ③ **输出** | 原样输出摘要（含**解析出的 `success`/错误码**，不是退出码） | 无输出 ⇒ 写"**无输出**" |
| ④ **验证者 · 日期** | **独立**验证者 + ISO 日期；自证只能写"主笔自证"⇒ 状态上限 `已实现待验` | 无验证者 ⇒ 写"**无**"（`已验证` 一律不成立） |

**证据不足时的强制写法**（**严禁空挂**，G2）：状态格写**"无证据"**，并在证据列给出**最小取证命令**（形如 `S6-01 §3` 的 12 条薄弱清单）。
**统计口径**：`已验证` 计数 = "④ 列非'主笔自证'且七要素齐全"的行数 ⇒ 本阶段应恒为 **0**；若不为 0，G8 必红。

## 6. 机检（**G1 / G4 / G8**）——代码 + 命令 + 真实输出同处一篇

> **"跑过 ≠ 写回"**（Stage 5 G8）：本节三个脚本都在**本轮实跑**，输出原样粘贴；下游 `01`–`04` 落盘后**必须复跑**并把新输出贴回本表。

> **留给未来的人（Stage 6 实跑经验）**：本节三条脚本在首版里**有两条真错**——G1 把 `FP-` 集合与 `PRD-` 集合相比（**永不可能相等**），G8 把阻塞列的合法值 `无` 误判成"证据不全"；而 `01 §10.2` 还一度贴了**没跑过的"预期输出"（假 PASS）**。
> 三个问题**都不是**靠仔细读代码发现的，而是靠**把脚本真跑一遍、把输出原样贴回**发现的。⇒ 规矩：**凡写进文档的判据，必须本轮真跑；输出的每一行都必须来自终端，不得凭预期填写**。绿灯本身没有价值，"**能复现的绿灯**"才有。

### 6.1 G1 · 50/50 覆盖 + 矩阵对账

> **⚠️ 修订记录（v0.1 修订 1）**：本脚本首版有一处**真错**——判据写成 `fp == matrix`（把 `FP-` 集合与 `PRD-` 集合相比较），**任何情况下都不可能相等** ⇒ 台账落盘后仍恒 `FAIL`。已改为 `prd == matrix` 且加 `len(fp) == 50` 与 `dup_fp` 检查。**"跑过 ≠ 写回"抓到的正是这种错**。

```bash
$ python3 - <<'PY'
import io, os, re
m = io.open('docs/03-产品设计/04-流程与跨页契约.md', encoding='utf-8').read()
m = m.split('## 3. 50 条落点矩阵')[1].split('### 3.1')[0]
matrix = set(re.findall(r'PRD-[A-Z]+-\d{2}', m))
path = 'docs/06-功能开发列表/01-功能台账.md'
rows, fp, prd = [], set(), set()
if os.path.exists(path):
    t = io.open(path, encoding='utf-8').read()
    rows = re.findall(r'^\|\s*(FP-[A-Z]+-\d{2})\s*\|\s*(PRD-[A-Z]+-\d{2})\s*\|', t, re.M)
    fp = {a for a, _ in rows}; prd = {b for _, b in rows}
print("matrix", len(matrix), "rows", len(rows), "fp", len(fp), "prd", len(prd))
print("missing", len(matrix - prd), sorted(matrix - prd)[:3])
print("orphan", len(prd - matrix), sorted(prd - matrix)[:3])
print("dup_fp", len(rows) - len(fp))
print("VERDICT", "PASS" if len(rows) == 50 and len(fp) == 50 and prd == matrix else "FAIL")
PY
```

**本轮真实输出**（2026-09-30；`01` 已落盘）：

```text
matrix 50 rows 50 fp 50 prd 50
missing 0 []
orphan 0 []
dup_fp 0
VERDICT PASS
```

**判定式**：`rows == 50` **且** `len(fp) == 50`（无重复 FP）**且** `prd == matrix`；任一不满足 ⇒ **G1 红**。

### 6.2 G8 · 状态 ↔ 证据对账

> **⚠️ 修订记录（v0.1 修订 1）**：首版把"证据不全"的判定写成"**任意单元格**等于 `无证据`/`无命令`/`无`"——而**阻塞列本身合法取值就是 `无`**，导致 24 条误报。已改为：① 只按**未转义竖线**切格（本表的单元格里有 `\|` 转义）；② 只看**证据格**（含 `验证者` 的那格）；③ 新增"状态格 = `无证据`"的空挂判定。

```bash
$ python3 - <<'PY'
import io, os, re
STATES = ('未开工', '开发中', '已实现待验', '已验证', '平台边界', '已废弃')
path = 'docs/06-功能开发列表/01-功能台账.md'
bad, verified = [], 0
if os.path.exists(path):
    for line in io.open(path, encoding='utf-8'):
        if not re.match(r'^\|\s*FP-[A-Z]+-\d{2}\s*\|', line): continue
        cells = [c.strip() for c in re.split(r'(?<!\\)\|', line.strip().strip('|'))]
        fp = next((c for c in cells if re.match(r'^FP-[A-Z]+-\d{2}$', c)), '?')
        st = next((c for c in cells if c in STATES), '')
        ev = next((c for c in cells if '验证者' in c), '')
        if st == '已验证': verified += 1
        if st in ('已实现待验', '已验证'):
            if not ev or any(k in ev for k in ('无证据', '无命令', '无输出')):
                bad.append((fp, st, '证据不全'))
        if st == '已验证' and '主笔自证' in line:
            bad.append((fp, st, '验证者非独立'))
print("violations", len(bad), bad[:5])
print("verified_count", verified)
print("VERDICT", "PASS" if not bad else "FAIL")
PY
```

**本轮真实输出**（2026-09-30）：

```text
violations 0 []
verified_count 0
VERDICT PASS
```

**判定式**：`violations == 0`；**并检查 `verified_count`**——本阶段必须为 **0**，否则与 §2 的 P1 裁决冲突（G8 红）。
