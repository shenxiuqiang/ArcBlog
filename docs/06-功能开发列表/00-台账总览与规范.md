## 2. **六态与正交阻塞（本体系唯一定义点）**

### 2.1 六态

| 状态 | 含义 | **判据（缺一不可）** |
| --- | --- | --- |
| **`未开工`** | 尚未动手 | 仓库里**指不到**任何调用点/产物；**须给探针号或前置** |
| **`开发中`** | 有部分落点、未成形 | 能指到**部分**文件:行，但流程不通或未覆盖验收 |
| **`已实现待验`** | 代码/产物齐、**未经验收** | 能指到**完整**调用点/产物 + 有可跑命令；**未经独立方复核** |
| **`已验证`** | 经**独立方**复核通过 | **独立验证者署名**（≠ 实现人）+ 命令 + `success`/错误码 + **原样输出摘要** + **基线 commit** |
| **`平台边界`** | 平台做不到 / 已降级 | **证据与 `待平台能力` 同门槛**：**指到 `docs/05/02` 的 `B*`**，或指到**具体的实测证据节号/命令 + 结果**（平台实测证据库 = `docs/05-开发文档/附件/arc-contracts.md` §NN + `grep` 命令），**不接受"实测过"这类无出处的说法**；并给**降级路径** |
| **`已废弃`** | **曾存在**、现已下线 / 被取代 | 写明**处置去向**（谁替代，或"**不设替代**"） |

### 2.2 正交阻塞（可与任一状态共存）

| 阻塞 | 含义 | 判据 |
| --- | --- | --- |
| **`无`** | 既无**外部世界**限制、也无**前置依赖** | 能开工 = 真 |
| **`待决策`** | 等产品/口径裁决（人） | 有明确的待裁问题 |
| **`待批准`** | 需**人类批准**的动作（真链写、真资金、删数据、对外发布…） | 有"人类检查点"条目 |
| **`待平台能力`** | 平台给不了（对象是**平台**） | 有 `B*` 证据 |
| **`待前置`**（**Lead 裁决新增**） | 本需求**不能在其它需求落地前开工** | **必须写出前置的 `PRD-` 编号**；**判据 = 能从台账里指到前置那行的 `PRD-` 号**；**指不到 ⇒ 不是 `待前置`** |

**补充说明（pm R6）**：**六态为 `平台边界` 时，阻塞通常就是 `无`** —— "**降级路径**"本身就是答案，平台限制写在**状态**里，而不是写在**阻塞**里（阻塞表达的是"能不能开工"，不是"平台行不行"）。

### 2.2.1 `结果=` 的有限取值集（**唯一出处**）

| 取值 | 含义 |
| --- | --- |
| **`通过`** | 命令/产物按预期产出（本轮实测格式正确） |
| **`未通过`** | 命令跑得出结果，但**结果不符合预期**（缺陷/缺失/产物未生成/条数为 0） |
| **`未测`** | **尚未测量**（无输出可依） |
| **`不适用`** | 该行属平台边界，**没有本项目侧的测量对象**（只有降级路径） |

**归一判据**（**只扫表行**，避免变更记录/表头文本假命中）：

```bash
python3 - <<'ZZ'
import re
from collections import Counter
rows=[l for l in open('docs/06-功能开发列表/01-功能台账.md',encoding='utf-8').read().splitlines()
      if re.match(r'^\| `PRD-[A-Z]+-[0-9]{2}` \|', l)]
vals=Counter(m.strip() for l in rows for m in re.findall(r'结果=([^·|\n]+)', l))
print(dict(vals))
assert set(vals) <= {'通过','未通过','未测','不适用'}, f'越界: {sorted(set(vals)-{"通过","未通过","未测","不适用"})}'
print('结果= 取值集: PASS')
ZZ
```
**基线常量说明（pm R9）**：**基线 commit `4597ba2` 是表头级常量**，`01` 逐行重复只为**便于单行摘录**（不逐行变化）。

**三档判据（Lead 裁决；**可判**，不许只写词义形容）**

| 档 | 判据（必须满足，否则不得使用） |
| --- | --- |
| **`待平台能力`** | **必须能指到 `docs/05/02` 的 `B*` 条目**（有"平台给不了"的**事实证据**，如 `B1`/`B7`/`B8`/`B9`/`B11`/`B12`）。**指不到 `B*` ⇒ 不得用**（"本项目未接""未测"都不是平台限制） |
| **`待前置`** | 前置项**在本行工作之外**，且**必须写编号**（`PRD-` **或** `P-`/`U-`/`ENG-`/`FP-`），**且该编号在文档里有定义**；**本行自己就是那件工作 ⇒ 不是 `待前置`**（否则成环） |
| **`无`** | 本行的工作**今天就能开工**——**包括"只是还没做"**（未接/未测 ⇒ 写 `无`，把事实留在**证据列**） |

> **`待前置` vs `待平台能力` 的分界**：前者是"**别的需求先做**"（本体系内可指到 `PRD-`），后者是"**平台给不了**"（对象是平台，证据是 `B*`）。
> **禁止**：用 `待前置` 表达"我不知道为什么做不了"——指不到前置行就**不许**用这个词。

## 3. **回填纪律（四条，写死）**

| # | 纪律 | 判据 |
| :-: | --- | --- |
| **D1** | **"机制在平台上存在" ≠ "本项目已接"** | **判据 = 仓库里能指到调用点/产物**。例：`listStakes` SDK 有、本项目适配器 **0 命中** ⇒ **不得**写 `已实现待验`（写 `未开工`/`开发中`） |
| **D2** | **"跑过 ≠ 写回"** | `已验证` 必须能指到**原样输出**；只在临时脚本里跑通不算 |
| **D3** | **`已验证` 只由独立方给出** | 署名 + 命令 + `success`/错误码 + 原样输出摘要 + **基线 commit**；自证最高 `已实现待验` |
| **D4** | **已下线 / 被取代的能力记 `已废弃`，不记 `未开工`** | 判据 = 写明**处置去向**（谁替代，或"**不设替代**"） |
