## 4. G1 的机检草案（`rows=50 / missing=0 / orphan=0`）

```bash
# ① 台账行数 = 50，且与设计层矩阵双向一致（不重定义，只对账）
python3 - <<'PY'
import io,re
m=io.open('docs/03-产品设计/04-流程与跨页契约.md',encoding='utf-8').read()
m=m.split('## 3. 50 条落点矩阵')[1].split('### 3.1')[0]
matrix=set(re.findall(r'PRD-[A-Z]+-\d{2}',m))
t=io.open('docs/06-功能开发列表/01-功能台账.md',encoding='utf-8').read()
rows=re.findall(r'^\|\s*(FP-[A-Z]+-\d{2})\s*\|\s*(PRD-[A-Z]+-\d{2})\s*\|',t,re.M)
fp={a for a,_ in rows}; prd={b for _,b in rows}
print("matrix",len(matrix),"rows",len(rows),"fp",len(fp))
print("missing(需求无落点)",sorted(matrix-prd))
print("orphan(台账多出)",sorted(prd-matrix))
print("VERDICT", "PASS" if len(rows)==50 and fp==matrix==prd else "FAIL")
PY
```

**判定式**：`rows == 50` **且** `missing == []` **且** `orphan == []`；任一不满足 ⇒ G1 红。
**G8 对账（状态 ↔ 证据）**：每行若状态 ∈ {`已实现待验`,`已验证`} 而证据四件套不全 ⇒ 红；若状态 = `已验证` 而**验证者**列不是独立方（非主笔）⇒ 红（**今天这一列必然为空** ⇒ `已验证` 计数应恒为 **0**）。
