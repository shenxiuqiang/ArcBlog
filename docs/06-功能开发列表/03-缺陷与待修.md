## 0. 缺陷优先级口径（**本阶段定义，可判**；置于 §1 之前，避免与既有节号冲突）

> pm R4：原文有 `P0/P1/P2/P3` 却**没有一处写明"什么算哪一档"** ⇒ 读者无法判断分级是否一致，**新增缺陷也无法照判**。本节补口径，并**回扫现有 13 条**。

| 档 | 判据（**满足其一即入该档**；取**最高**档） | 谁受影响 |
| :-: | --- | --- |
| **P0** | **制造错误事实**：把"未就绪 / 未接 / 不存在"呈现为"可用 / 已就绪"（**假绿灯**）⇒ 用户会据此做出错误动作 | 终端用户 |
| **P1** | ① **阻断其它条目**（前置门 / 基线缺失 ⇒ 别人做不了）；**或** ② 用户**可见**且**正确性受损**（显示错的标签、错的文案） | 用户 + 下游条目 |
| **P2** | 用户**可见但局部**（单页 / 单字段 / 纯视觉细节），**不改变事实判断** | 终端用户（局部） |
| **P3** | **不可见 且 登记即可（无需动手）**（历史物证 / 按设计的覆盖边界）；⚠️ **"不可见但要动手"不算 P3**（那是待清残留，落 P2） | 无 |

**两条附加规则**：① **平台限制不评档**（它们不是缺陷，见 §6 E5）；② **"未接"不评档**（属实现工作，见 §6 E6）——**只有"该对而错"才评档**。
