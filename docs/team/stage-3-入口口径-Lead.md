## 1. 本阶段只做三件事

1. **页面族收缩**：把**今天的 21 个控制台页面**按概念**增删到位**；
2. **流程重画**：概念 `03 §J1`–`§J6` 的每一步都要有**落点页面/URL/CLI**；
3. **跨页契约**：定义"哪个页面拥有哪个事实"，避免同一事实两个落点。

## 2. 页面清单（**预裁：收缩已定，新增项待定**）

**控制台页面：21 → 约 15**（精确数以 Stage 3 撰写为准）；**下线页面的名单由本阶段按概念口径定**，本预裁不点名。

**留并升级**：`?page=agents`（**升为主入口**：从"只读审计视图"扩为 agent 的**发现/汇总/chat/生成/发布**工作面）；`?page=factory`（只留 studio）。

**可能新增（待 Stage 3 定）**：
- **注册表/网络视图**（"有哪些节点在运行"——`PRD-NET-01`/`OPS-07` 的落点）；
- **节点自描述编辑**（`endpoint`/`region` 写进 NFT data——`PRD-NET-02`）；
- **撤销/清空/转让**的操作面（`PRD-ID-04`/`ID-05`）。

**判据**：每个新增页面必须能指到**至少一条 `PRD-`**；每条"有页面落点"的 `PRD-` 必须指到页面。

## 3. 必须覆盖的流程（概念 → 设计）

| 概念旅程 | 设计必须给出 |
| --- | --- |
| `J1` 创作者发布 | 写作 → 发布 → 公开页 → 只读出口（**含 RSS 需先生成**的告知） |
| `J2` 读者读到并订阅 | 公开面 + **订阅三义**的界面表达（书签/RSS/交给 agent） |
| `J3` 节点加入网络 | 买 NFT → 质押 → **写 `endpoint`** → **等被 agent 发现**（`PRD-NET-01` 未落盘前的**降级说明**） |
| `J4` **主干** | agent 工作面：**发现 → 汇总 → chat → 生成草稿 → 发布**（发布【平台边界】：页面只给"复制运营侧命令"） |
| `J5` 退出与转让 | 撤销 → **清空质押时字段** → **转让**（【规划中】+ beta/TBA 验证路径的如实表述） |
| `J5b` 巡检排障 | "我是否在注册表里"（`PRD-OPS-07`） |
| `J6` 平台方治理者 | 只读核对面（`PRD-NET-07`：用链上浏览器/通用 SDK） |

## 4. Stage 3 定稿门（预告）

| # | 门 |
| :-: | --- |
| G1 | **需求有落点**：每条"需要界面"的 `PRD-`（55 条中筛出）指到页面/URL/CLI；无落点的写明"非界面项（CLI/AFS/链）" |
| G2 | **无残留**：页面集合里不得出现**没有任何 `PRD-` 支撑的门面**（`docs/02` 为唯一出处） |

| G4 | **跨页契约唯一**：同一事实只有一个拥有者（引 `docs/01-产品概念/04` 的术语） |
| G5 | 形态：≤400 行/篇、单行 ≤800 **字符**、`wc -l` 计数、链接 0 MISS |
| G6 | `arc dsl validate --json` `issues: []` + `npm test` 快层不红 |
| G7 | 两路独立审查 + Lead 核验 |
