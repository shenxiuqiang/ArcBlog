## 4. 流程资产（本阶段新增，Stage 3–8 复用）

1. **独立审查用持久 teammate**（`pm` / `qa`），不用一次性子智能体——本阶段子智能体出现"静默消失 / 超时未交付"。
2. **机检必须逐条目**（按 `### 3.x PRD-…` 切块核 8 节齐全与顺序），禁止"出现即通过"——Stage 2 因此漏抓过 `01-CNT` 的节标签错位。
3. **判据必须自己先跑通再写进文档**：本阶段有两条文档自带命令实测失效（计数命令输出 `合计 0`；Sponsored 判据应为 0 实为 3）。
4. **行长口径 = 字符数，非字节**（中文 3 字节/字；`awk length` 在 BSD awk 下按字节，曾造成假报）。
5. **识别性判据要容忍缩写形态**：`PRD-SITE-07` 的残留以 `PRD-SITE-03/07` 形式逃过 `grep 'PRD-SITE-07'`，必须用 `PRD-XXX-[0-9]{2}(/[0-9]{2})+` 展开核对。
6. **脚本只做机械变换，且必须给可复核判据**（残留计数 + 逐文件 grep）；语义改动一律用 `edit`。
