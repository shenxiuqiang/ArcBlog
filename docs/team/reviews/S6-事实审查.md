## 1. 三条机检：逐字复跑 + **判定式审判**

### 1.1 输出逐字复现（快照 2 上重跑）

```text
G1: matrix 50 rows 50 fp 50 prd 50
    missing 0 []      orphan 0 []      dup_fp 0      VERDICT PASS
G8: violations 0 []   verified_count 0               VERDICT PASS
G4: s6-02 ids 65 covered 65  missing 0 []            VERDICT PASS
```

✅ **与 `00 §6` 所贴的"本轮真实输出"逐字一致**（含 G1 的 `prd == matrix` 修正：已不再比较 `fp == matrix`）。

### 1.2 G1 —— **判定式成立** ✅

`rows==50 且 len(fp)==50 且 prd==matrix`：FP 重复由 `dup_fp` 兜住；PRD 重复（两个 FP 指向同一 PRD）由 `prd==matrix` 兜住；缺号即 `missing>0`。我另验其**失效方向**：任一 FP 行被加粗/错格 ⇒ `rows<50` ⇒ **FAIL（fail-closed）**，不会静默通过。**无同类残余**。

### 1.3 G8 —— ❌ **两条未对齐路径（一真一假），经变异证实**

**(α) 假 PASS：`00 §4` 强制指定的写法让整行对 G8 隐形。** `00 §4` 末段原文：

> **证据不足时的强制写法**（**严禁空挂**，G2）：**状态格写"无证据"**，并在证据列给出最小取证命令

而 G8 用 `st = next((c for c in cells if c in STATES), '')` 找状态 ⇒ `无证据` **不在六态词表**里 ⇒ `st==''` ⇒ **该行跳过全部检查**。变异实测（/tmp 副本，把一个 `已实现待验` 行的状态格改成 `无证据`、证据格清空）：

```text
  变异行: | FP-CNT-03 | … | 无证据 | 无 |  | A2/A3 需 HTTP 断言… |
  变异后 G8: violations 0 verified_count 0 VERDICT PASS      ← 空证据未被报
```

**(β) 假红：`00 §4` 允许的省略被 G8 判违规。** `§4` 的②③格明写「无法复跑 ⇒ 写"**无命令**"+原因」「无输出 ⇒ 写"**无输出**"」；但 G8 对 `已实现待验/已验证` 行把含 `无命令/无输出` 的证据格一律判 `证据不全`。变异实测（证据格写 `无命令（页面无此原语，见 07 §1）`）：

```text
  变异后 G8: violations 1 [('FP-CNT-03', '已实现待验')]   ← §4 允许的省略被判红
```

**(γ) 覆盖面：G8 只看 2/6 态。** 40 行里 **22 行**（`未开工`6 + `开发中`13 + `平台边界`3）**不受任何证据检查**，而 `§4` 要求每行四格齐全（**严禁空挂**）。当前这 22 行恰好都填了（实测"证据格缺失 = **0**"），故是**潜在**缺口而非现存错。

> **性质**：`violations 0` 今天为真，但**判定式不满足它要守的不变量**（"已实现待验/已验证 不得空挂证据"）。修法二选一：① 改 `§4`（删除"状态格写无证据"，改为"状态仍写六态之一，证据格写 `无证据+最小取证命令`"）**并**让 G8 把 `无证据` 也纳入判据；② 或让 G8 的 `st` 解析先做六态校验，**任何非六态取值直接判红**。另把 `无命令/无输出` 与 `§4` 对齐（要么 `§4` 禁止在 `已实现待验` 行使用，要么 G8 放行但要求带原因）。

### 1.4 G4 —— ❌ **判定式是"字符串命中"，不是"逐行归属"（变异已证）**

脚本本质 = `missing = [i for i in ids if i not in body]` ⇒ 只要该 id 在**任意一篇任意位置出现过**就算覆盖。文档自己的要求却是（`_提纲:88`、`00 §6.3` 判定式）：

> `S6-02` 的 **65 行必须逐行有归属**（吸收进 `FP` / 立 `ENG` / 落 `DEF` / 登记为探针 / 显式排除并写理由）⇒ **静默漏项即 G4 不通过**

**对抗变异（/tmp 副本）**：删掉 `02 §2` 里 `ENG-01` 那一行（= `GATE-01` 的唯一落点），保留覆盖面句（`02:36` 的「本表覆盖的 25 个 `S6-02` ID：`GATE-01…07`…」）：

```text
  删除行数 = 1
  变异后 G4: s6-02 ids 65 covered 65 missing 0
  VERDICT PASS      ← GATE-01 已无任何落点行，仍判 PASS
```

**机制**：文档大量使用**区间写法**（`GATE-01…07`、`UNV-01…20`、`DEF-01…15` + `FIX-01…05`、`TOOL-02/03/07`），一句"覆盖面"就能让整族 id 同时"命中"。⇒ **`missing==0` 不能推出"逐行有归属"**。

**现状严重度校准**（我做了两次测量，第一次过严）：把"可逐行定位"定义为"该 id 是某表格行的首列 **或** 独立行内标注（`02 §2` 的 ENG 行第 5 列 `GATE-0x`、`03 §2` 的 DEF 行"来源"列 `S6-02 FIX-0x`、`04 §3` 的 `UNV` 行首列）"：

```text
首次（只认首列，未处理反引号/非首列）→ 可定位 15 / 仅字符串 50   ← 过严，作废
修正后（允许 反引号 + 非首列的独立行内标注）→ 可定位 63 / 仅字符串 2 类
  细分：UNV-01…20 → 04 §3 逐行首列 ✅ ｜ GATE-01…07 → 02 §2 逐行第5列 ✅
        FIX-01…05 → 03 §2 逐行"来源"列 ✅ ｜ TOOL/DOC/DEF → 各自行 ✅
```

⇒ **实质覆盖今天是齐的**（63/65 有独立行/独立句子，剩余 2 类由 `03 §2` 的 `FIX-0x→DEF-(0x+15)` 对应表显式承接）。**问题不在"今天漏了"，而在"判据抓不到明天会漏"**——这正是主笔本轮自纠 G1 时的同一类风险，故计 P1（判据不足），但**不**主张台账本身有错。
