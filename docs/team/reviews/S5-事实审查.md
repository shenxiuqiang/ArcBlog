## 2. A1 的**反向分支**不能红（P2，机制已定位）

**A1 的代码**（`_gate.sh:47-70`）分两支：
- **正向**（三者计数全为 0）：要求 `02` 含 `三处代码缺口|本项目未接|未接` 且三个标识符都被提及 ⇒ **能红**（M3 已证 ✅）。
- **反向**（有计数 > 0）：只做
  ```python
  if v > 0 and re.search(rf'{k}[^\n]{{0,40}}未接', body(b02)):
      problems.append(f'`{k}` 在代码里已有 {v} 处调用，但 `02` 仍写"未接" ⇒ 文档过期')
  ```
  ⇒ 要求「**标识符在前、`未接`在后且 40 字符内**」。而 `02:60` 的实际写法是：

  ```text
  | **G1** | **链上枚举未接**：`listStakes` **两个适配器都没有**（ocap + mock） | `grep -c listStakes …` → **0** | …
  ```

  `未接` **在标识符之前** ⇒ 该正则**永不命中** ⇒ 代码真接上时，本判据**只打印一句人工提示、仍 `VERDICT PASS`**（我的 M6 实测）。

**影响**：Stage 6/实现轮把 `listStakes`/`updateAsset`/`signTransferTx` 任何一个接上后，若忘了同步 `02`，门不会拦（只留一句 note）。**修法（一行级）**：把顺序无关化，例如
`re.search(rf'{k}[^\n]{{0,40}}未接|未接[^\n]{{0,40}}{k}', body(b02))`，或直接改成"按行取含该标识符的行，看该行是否仍带 `未接`"。
