## 0. 判"可以删"的三条判据（本篇一致使用）

1. **平台有等价面**（实测存在，不是"看起来像"）；
2. **我们那份不是平台缺口的承载体**（不是平台做不到的降级/替代，见 [`docs/05/02`](../docs/05-开发文档/02-平台能力与边界.md) 的 `B*`）；
3. **删除不破坏门/绑定/AUP 面**（没有 `blocklet.yaml` binding、没有守卫、没有 AUP 冷启动依赖）。

三条全满足 = **删**；只有 1 满足 = **缩**（保留 CLI/公开面，删页）；只有 2 满足 = **留**。

## 1. 平台侧可替代面（实测清单）

| 平台面 | 覆盖的事实 | 证据 |
| --- | --- | --- |

## 3. 删除候选的详细方案

### 3.1 候选①：`?page=seo`（最强）

**依据**：描述与分享图两件事，平台都已提供，且平台的分享卡**会跟随 branding 的 `passportColor`**（我们那张是烘死的 PNG；`arcblog-og-image.mjs` 只是"用平台生成器生成后存成本地文件"，多了一道僵硬的手工步骤）。

**连带清单**（删/改）：

| 项 | 动作 |
| --- | --- |
| `.aup/pages/site/seo.aup` + `scripts/console-nav.mjs` 的 `nav-seo` 行（侧栏 16 → 15） | 删（重跑 `arcblog-console-nav.mjs`） |
| `.aup/locales/*` 的 `seo.*` keys、`.aup/man/seo.yaml` | 删 |
| `blocklet.yaml` 的 `sites[].bindings` 里 `seo-admin`（`/manage/seo` → page seo） | 删该 binding（否则绑定指向不存在的页） |
| `config/seo/{meta-description,share-image}.json`（实例记录） | 弃用（清理属人类批准） |
| `arcblog-rss.mjs` 的 `general.metaDescription` 分支 | 改为 **branding.description → 清单描述**（`S11-01 §4.3 #8` 已做一半） |
| `.web/seo/og-image` + `.web/site.yaml` 的 `seo.og-image` | **改为平台端点**（两者必须一致——`arcblog-artifact-drift` 钉住了这一点） |
| `content/media/arcblog-og.png`（153 KB 烘死资产）+ `scripts/arcblog-og-image.mjs` | 删（`arc blocklet check` 在指向平台端点后 **ok:true**，已实测） |
| `scripts/arcblog-run-tests.test.mjs` / `arcblog-page-grants` / `arcblog-routes` / `ui-budget` / `ui-copy` 基线 | 随页数变化同步（16 → 15） |
| 文档 | `PRD-SITE-03`/`PRD-SITE-04`/`PRD-SET-02`（`E9` = A 的"seo 记录 vs node profile"拆分）、`docs/05/01` 的 `config/seo/*` 行、`docs/06` 台账、`V09` 无关 | 口径改动 ⇒ **人类检查点（新 `E17`）** |

**验证判据**：删后 `arc blocklet check . --profile basic --json` = ok；SSR 页 `og:image` = 平台端点（**未验证**：需一次构建+curl，见 §5 P1）；RSS `<description>` = branding.description；`npm test` + `gate:docs` 全绿。

**风险**：⑴ AUP 面本来就没有 meta（`B19`），分享卡只在 web 面生效 ⇒ 删掉我们那张 PNG 不损失 AUP 面；⑵ 平台 og.png 是**动态端点**（每次被爬虫抓都要渲染）⇒ 分享器抓取变慢（可接受）；⑶ `?page=seo` 曾是"分发元数据"的**记录编辑器**，删掉后 operator 只能改控制台 branding 的 description。

### 3.2 候选②：`?page=general` 的 `language` 字段

**依据**：语言列表平台已维护（`app:languages`），而我们的字段**只喂 RSS `<language>`**。

**动作**：删 `GENERAL_FIELDS.language` + 页面 input + `general install` 计划里的那一写 + locales keys；`arcblog-rss.mjs` 的 `<language>` 改读平台（`platform.languages[0].code`，回落 `en`）。

**阻塞**：`app:languages` **是否按 blocklet 取值未验证**（登录页 `locales` 在 arcblog 与 my-app 上完全相同）⇒ 与 `U21` 同批探针；若证否，则保留该字段并登记为"平台做不到（按实例语言）"的降级。

### 3.3 候选③：`?page=media` 的**页面**（保留 CLI）

**依据**：浏览同一批文件，平台自己的 AFS 浏览器（`/.well-known/admin`）已能做；我们的页面另外提供 refs/orphans/remove 与上传入口。

**动作**：删页面（+ 侧栏行 15 → 14 + locales + man + `ui-*` 基线），保留 `scripts/arcblog-media.mjs`（`list`/`refs`/`orphans`/`remove --force`）与 `?page=diagnostics` 里的 CLI 指引。

**阻塞**：页面是唯一的 `afs-dropzone` **上传入口**（"页内上传不可用"的历史结论见 `docs/03` 的 media 行）—— 若 operator 需要上传，平台 AFS 浏览器是否等价**未验证**（§5 P2）。若不支持上传，则**只删"索引/清理"那段、保留上传**，或整体保留。

## 4. 明确**不删**（附理由，免得下一轮又被提出来）

| 项 | 理由 |
| --- | --- |
| `?page=dashboard` / `operations` / `registry` / `factory` / `diagnostics` / `agents` | 平台 **无**等价面（链、节点、agent 策略都是本仓的领域） |
| `?page=posts` / `pages` / `compose` / `compose-edit` / `categories` / `tags` / `heroes` | 平台 CMS 面向声明式站点（`/web/.actions/cms-*`），不认 AUP 记录模型与 `posts/drafts` 的双目录草稿边界 |
| `?page=feeds` | RSS 是本仓产的（平台只产 llms.txt/sitemap） |
| `?page=general` 的 **时区** 与**三个开关** | 平台无等价（时区影响 RSS `pubDate` 偏移；三个开关是仓库功能位） |
| `?page=saved`（阅读清单） | 数据在**用户自己的 DID 空间**，与平台 save 是两套 store；`save: false` 的取舍已写在 `blocklet.yaml` |
| 公开面 `about`/`author`/`reader`/`preview`/`page-view`/`index` | 内容与信任面，无平台等价 |

### 8.1 追加裁定（同日）：分享卡也彻底不维护

人类「彻底不维护那张 PNG」⇒ ① 的连带删除全部执行：`content/media/arcblog-og.png`（153 KB）与 `scripts/arcblog-og-image.mjs` **删除**、`cli-flags` 条目删除、`.web/seo/og-image` + `.web/site.yaml` 两处声明改为平台生成器 `/.well-known/service/blocklet/og.png?template=default&locale=en`。
**关键实测**：省略 `title=` 时生成器仍返回真 PNG（`200 image/png` 134 870 B，且自动用控制台品牌名渲染）⇒ 卡片标题也不再写死。
**守卫同步**：`arcblog-artifact-drift.test.mjs` 的 `assetPathFor()` 现在接受平台形态（要求显式 `template=`、**禁止** `title=`），本地形态（`/p/` + PNG magic + ≥10 KB）仅对另一种声明生效；`content/media/` 目录随 PNG 消失（`arc collections scan` 现打印无集合，`arc blocklet check` 仍 `ok:true`）。证据 = `arc-contracts §79`。
