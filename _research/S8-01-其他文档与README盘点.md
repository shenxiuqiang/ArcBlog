## 0. 一句话现状

归档期**有**一套完整的入口体系（v1 归档总索引 + 协作手册 + 角色卡 + 7 篇专题入口），新体系**只有一本宪法**：`docs/README.md` 183 行承担了目录、阶段门、文档规范、审查清单、术语登记、工作台说明六件事，但**它对 8 个类目一个超链接都没给**（`docs/README.md:27-39` 是 `text` 代码块）。
结果：`docs/01-产品概念/00-导读.md` 是**唯一**成型的类内阅读入口，`02`/`03`/`04`/`05` 只有写作提纲（`_提纲.md`，状态多为「已定稿/已执行」但形态是**写作计划**），`06-功能开发列表/` 与 `07-团队与开发规范/` 是**空目录**，`08-其他/` 无 README。Stage 8 的实质工作 = **给这 8 类装门**，并把归档期最贵的三类资产（术语、决策、迁移对照）从"散落 + 无索引"变成"一页可查"。
