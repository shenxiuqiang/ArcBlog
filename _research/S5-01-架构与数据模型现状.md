## 5. 构建与产物

- **入口唯二**：`npm run build` = `arc blocklet build && npm run scrub:dist-secrets`（`package.json:14`）。禁止裸 `arc blocklet build`——它把仓库根 `node.key`/`.env.local` 复制进 `dist/` 并写入 `dist/.afs/manifest.json`（BUG-067）；`arc blocklet build --help` **只有** `--output/--dry-run/--clean`，无 exclude/ignore 开关（本次实跑 `--help` 确认）。
- **擦除规则**：`SECRET_BASENAMES = {node.key, .env.local}` + 任何含 `-----BEGIN … PRIVATE KEY-----` 的文件（`scripts/arcblog-dist-secrets.mjs:30,33`）；`--check` 是只读门（`package.json:13` 的 `verify:artifacts` 另加 `--pages` 扫 Pages 通道）。实测 `dist/node.key`、`dist/.env.local` **absent**；`dist/.node-pk.pem` 与 manifest 条目仍在（它是 `BEGIN PUBLIC KEY`，非私钥——`dist/.afs/manifest.json:444`）。
- **`dist/` 与源码对应**：整树镜像仓库根（`.aup/ .route/ .web/ .web-cache/ agents/ docs/ logs/ pages/ scripts/ seed/ world/` + 根文件），**不含** 、`node_modules/`、`providers/`（空目录）；另加三件生成物 `.afs/manifest.json`（实测 1183 条 path）、`.afs/preflight.json`、`blocklet.dist.json`。`blocklet.dist.json:41-50` 声明两个挂载：`agents/arcblog-agent → /agents/arcblog-agent`、`pages → /pages`（`indexMount` 也是 `pages → /`），并含 4 条 `requirements.probes`。实测 `dist` 文件 1185 个、`dist/scripts/*.mjs` 64 个（32 CLI + 32 test）⇒ **脚本与测试随包发布**。
- **`arc dsl generate` 的三类产物**（help 原文："Generate app.json and page JSON artifacts from app.aup"）：① `.aup/app.json`（`pages.<name>.tree` 指向每个 `.aup` 源，30 条，`.aup/app.json:12-102`）+ `.aup/wrapper.json`（外壳编译树，含 `site-header`）；② `.aup/pages/<name>.json` 预编译页树——**实测只有 7 个**（about/author/index/page-view/preview/reader/store），其余 23 页运行期从 `.aup` 源编译；③ `.aup/locales/{en,zh}.json` 扁平点号 i18n（`wrapper.*` 只能手写，`generate` 不产出）。默认 **dry-run**，`--write` 落盘，`--check` 是漂移门（在 `npm test` 快层内）。

## 6. 依赖与选型现状

- **AUP 应用零运行时依赖**：`grep -rl "@ocap|@arcblock|bip39" .aup/ .web/ pages/` → **0 命中**；`.aup/**` 里没有任何 `import`/`require`。页面能力全部来自 DSL 原语 + 平台运行时。
- **`package.json` 5 个包只服务链脚本**：`@ocap/client`、`@ocap/wallet`、`@arcblock/did-ext`、`@arcblock/did-util`、`bip39`（`package.json:16-22`）；全仓只有 **2 个文件**引用它们，且都是**动态 import**（`scripts/lib/chain.mjs:628-653`、`scripts/arcblog-economy.mjs:998`）⇒ `--adapter mock`/纯 AFS 路径**不需要** `npm install`。
- **无 bundler、无 dev server**：`package.json:5-15` 只有 test / build / scrub / verify 六类脚本，**没有** `dev`/`start`/`serve`；无 devDependencies；无 webpack/vite/esbuild/rollup 配置。唯一"构建"是 `arc blocklet build`（复制 + manifest），唯一"编译"是 `arc dsl generate`。
- **意味着什么**：① 研发迭代不能靠 HMR——`.aup` 改动对运行中的 daemon **不生效**，验收必须 `generate → build → arc service restart → arc blocklet run`（`S1-03:168` C2）；② 依赖缺失只影响 `--adapter ocap`，且以 `CHAIN_UNAVAILABLE` 等**显式错误码** fail-closed，不会静默降级；③ 因为脚本随 `dist/` 发布，`dist/` 的体积与密钥面必须由 `scrub:dist-secrets` 单点兜住；④ 生成物（`app.json`/`wrapper.json`/`locales`）是**提交进仓**的派生物，靠 `arc dsl generate --check` + `arcblog-i18n`/`arcblog-console-nav`/`arcblog-runtime-ids` 守住漂移。

## 摘要（给主笔，10 条以内）

1. **六层结构**：L1 AUP 页面（30 页，14 页有写接线）/ L2 AFS 资源（`/instance/app/arcblog/**`，`world/*.yaml` 22 schema，20 个 `replicated` 集合 + 20 条 `networkRead` 前缀）/ L3 链与身份（DID + `node.key` + `.env.local` 助记词）/ L4 CLI 与 worker（32 CLI + 24 lib + **8 个 watch worker**）/ L5 Web Device 与 SSR（`.route/web` `/p`）/ L6 ARC daemon v2.0.0-beta.50（`default:4939` up）。
2. **两条数字更正**：写接线 **14 页**（非 22）；worker **8 个**（非 4）——`docs/03-产品设计/04-流程与跨页契约.md:161` 与本篇一致。
3. **权限真源 = `blocklet.yaml`**：`replicated.readRole/minRole` 是唯一授权门，未声明路径默认拒绝；`networkRead` 是**前缀增补、不能收权**，所以 `config/` 整树 admin（父 guest 会泄漏子目录清单）。
4. **可见性 = 目录边界**：`posts/` guest 只放已发布、`drafts/` admin 放草稿+归档+软删、`pages/` vs `page-drafts/`、`paid/` admin 存付费全文（页面永不读）。
5. **写入三条路**：① 页面直写 `replicated` 集合（14 页）；② 页面写 `config/*-intents/<id>.json` → 本机 worker drain（7 条队列，词表 `pending/running/applied/rejected/noop`，唯一例外 `chain-intents` 仍是 `done/failed`）；③ CLI/worker 独占（`paid/` 全文、`contentHash`、签名、审计、链上）。
6. **构建唯二命令**：`npm run build` = `arc blocklet build` + `scrub:dist-secrets`（擦 `node.key`/`.env.local` + 任何 PRIVATE KEY 块；平台无 exclude 开关）；`dist/` 是仓库根整树镜像（1185 文件，含 `scripts/` 64 个、不含 ），另加 `.afs/manifest.json`（1183 条）与 `blocklet.dist.json`（声明 `agents/arcblog-agent` 与 `pages` 两个挂载）。
7. **`arc dsl generate` 三类产物**：`.aup/app.json`（+`wrapper.json`）、`.aup/pages/<name>.json`（实测仅 7 页）、`.aup/locales/{en,zh}.json`；默认 dry-run，`--write` 落盘，`--check` 是快层漂移门。
8. **零运行时依赖**：AUP/SSR 代码 0 处 `import`；`package.json` 5 个包只被 `lib/chain.mjs` 与 `arcblog-economy.mjs` **动态**引用（仅 `--adapter ocap`/只读对账需要）⇒ 无 bundler、无 dev server、无 `dev`/`start` 脚本。
9. **最硬的四条不变量**：页面 `exec.content` 内 `$session.*` 不插值（署名必须 CLI/worker）；页面无时间/哈希/签名原语；链私钥永不进浏览器（意图队列 + worker 是唯一形态）；AFS 查询对 >~1.8 KB 记录静默漏 + 编辑后索引 stale（不能做下推筛选/精确计数）。
