## 证据等级约定（与 `docs/05` 的写法对齐）

- **【实测】** = 本机跑过命令/抓过 HTTP，命令与结果都写出来，可复现；
- **【代码】** = 在解包源码或运行时产物里读到的字面实现；
- **【推断】** = 由上面两者推出的结论，**未直接验证**；
- **【未验证】** = 需要一次探针才能定论，已写清探针步骤。

## 复现前提

```bash
# 平台版本与进程
arc --version                                   # 2.0.0-beta.66 (54a9b40e)
lsof -nP -iTCP:4939 -sTCP:LISTEN                # arc-darwi <pid>
# 两个 npm 包（本机分析用，不进仓库依赖）
mkdir -p /tmp/kb/pkgs && cd /tmp/kb/pkgs
npm pack @abtnode/blocklet-services@1.17.12 && npm pack @blocklet/ui-react@3.5.4
```
