## 2. 六条最有产品含义的边界

1. **AFS 查询层只对 ≤ ~1.8 KB 的内联记录可靠。**
   `where`/`select`/`groupBy` 对超过内联上限的记录**静默**漏掉或返回 `{}`，既不报错也不给标记（§15.1、§44.2①、§44.3）。
   ⇒ 产品**不能承诺**"按分类/标签/任意字段精确筛选全量文章"和"准确的计数"；列表只能靠**目录边界**，筛选必须由自建索引或 CLI 承担。
   （出处：§44.1 可依赖子集表、§44.4 P1-1 结论。）

2. **AUP 表达式没有比较/算术，`visible` 只在同步 `$session.*` 上可靠。**
   只有 `!` `&&` `||`；`$state.*`/`$entry.*` 上的闸门语义不可靠（`visible="$entry.content.count"` 恒真、取反恒隐藏）（`language.md` §7；§28.1、§56；§54）。
   ⇒ 产品**不能承诺**"按状态/角色/能力动态变化的界面"。状态差异要用**目录或页面**表达（草稿/已发布分目录），权限只分「登录/管理员」两档，其余一律退化为**常驻说明**。

3. **没有可用的跨页复用机制：`include` 运行时不可用，共享外壳无法自动高亮当前项。**
   `include`/`partial`/`import` 只到解析层，守护进程直接 `SESSION INIT FAILED`；`active` 只认字面 `true`（§25.2、§16、§23；`language.md` §3b）。
   ⇒ 产品必须接受"**一处改、重新生成 N 页**"的成本：菜单/外壳由生成器投影进每页，并用 `--check` 门禁守住漂移。任何"导航只需改一处"的承诺都不成立。

4. **页面里没有时间、哈希、签名原语；这些事实只能由本机进程写入后投影。**
   `${generate.*}` 在 prop 与文本节点一律原样输出（§31(2)），AUP DSL 没有哈希原语（`.aup/pages/ops/agents.aup:16`）。
   ⇒ 产品**不能承诺**页面上显示"当前时间/内容指纹/验签结果"；内容哈希、Ed25519 签名、NFT SVG、时间戳全部由 CLI/worker 写入 AFS，页面只读投影（`scripts/lib/content-hash.mjs`、`content-sign.mjs`、`arcblog-chain-worker.mjs`）。

5. **链上写入被锁在本机进程内（私钥永远不进浏览器）。**
   助记词在 `.env.local`（gitignored）；`--adapter ocap` 先用「network + chainHost + tokenId」三件套 fail-closed，再要助记词（链环境纪律见 §30.1，fail-closed 三态见 §32(7)；`scripts/arcblog-chain-worker.mjs` 文件头）。
   ⇒ 产品形态**必须是"意图队列 + 本机 worker"**：点击不即时生效，UI 要显示 `pending → running → applied`、终态原因和**真实耗时**（§33、§36(1)）。任何"一键上链、立即完成"的说法都是错的。
6. **公开面只能是 AUP 动态 SPA：root 级端点被吞、Web Device 没有 AFS、内容站点不可达。**
   `/.well-known/*` 与 `/api/*` 返回 4,462 字节 AUP 壳（§7）；Web Device 在服务端与客户端都拿不到 AFS（§3.2/§3.3）；`cms-write`/`cms-publish` 对 blocklet 运营者不可达（§8）。
   ⇒ 产品**不能承诺** `/.well-known/arcblog`、REST API、per-post 静态 HTML 或完整 SEO 元数据。网络层以 AFS 资源 + `/mcp` 形态发布（§7）；逐条静态 SEO 明确记为**平台受限**，不在 MVP 兑现。

## 3. 降级模式库

### P1 · 意图队列 + 本机 worker
- **适用**：需要写链、需要私钥/大计算、耗时超过一次交互（上链、索引重建、分类/媒体迁移、策略变更）。
- **实现要点**：页面只写 `<id>.json` 意图（`${args.*}` 走隐藏 input，不得直接写 `entry.*`/`$session.*`，§29.1/§34(2)）；队列目录全树 admin-only；worker 认领写 `running`，终态写非空 `message`；状态词表只有 `pending|running|applied|rejected|noop`（§33(1)、§34(3)）；`<id>.json` 之外的条目必须显式落诊断（§33(2)）；耗时写**真实** `elapsedMs`，页面与 AFS 记录逐字一致（§36(1)）。
- **验收判据**：AFS 记录本身变化（不是 toast，§29.4）；队列状态可被 `afs-list subscribe=true` 实时看到；终态带原因；只读对账四分类计数自洽（§36(2)）。
- **已知反例**：`config/chain-intents` 仍用旧词表 `pending|running|done|failed`，且改名会触发真实链写，故未随 D36 改名（§33(1) 范围外残留）。

### P2 · 诚实降级：平台破折号 + 常驻说明
- **适用**：首屏可能为空、动态值无法本地化、状态无法条件渲染、平台确实不提供该信息。
- **实现要点**：空值渲染 `—`，并在同一卡片内写一句**恒定成立**的说明（把「—」读作「尚未绑定/暂不可用/未上链」）；不给"有数据才显示"的空态卡（§37(3) 收口、§28.8 路径 B、§36(2)）。
- **验收判据**：说明与数据状态**不矛盾**；不同真实状态**不得**被同一句话断言成同一件事（§28.8）；四分类报告里不出现「链上已验证」除非真的 `verified`（§36(2)）。
- **已知反例**：BUG-001 曾用互斥 `visible` 做空态，27 条标签同时渲染空态卡；BUG-005 的动态 `$t()` 三次探针全败。

### P3 · CLI 折叠为高级 + 可复制命令
- **适用**：平台能力缺位（哈希、签名、迁移、媒体引用复核、内容运维）。
- **实现要点**：页面**不假装能点**，而是渲染一条可复制的完整命令；命令走中央 flag 注册表（`--k v` ≡ `--k=v`，未知 flag fail-closed，§37(1)）；危险操作要求显式确认与到期时间（`arcblog-agent.mjs authorize` 强制 TTL）。
- **验收判据**：命令原样可跑；`--help` 存在（已知缺口：`chain-worker` 无 help 面，`rss`/`query-posts`/`daily-report` 的 `--help` 不生效，§37(1)）。
- **已知反例**：`ops/agents.aup` 的授权签发即此模式（`.aup/pages/ops/agents.aup:16`）。

### P4 · 角色 / 能力 fail-closed
- **适用**：任何"未验证就绝不能生效"的授权（节点角色、Agent 能力、付费全文）。
- **实现要点**：角色未验证 ⇒ 不授予任何能力（`scripts/lib/roles.mjs`）；链适配器归属必须**逐节点**三态 `mock|ocap|unknown` + `simulated: true|false|null`，**禁止**把未归属写成 `simulated: false`（§33(3)）；链上查询只在"节点归属与 worker 适配器都为 `ocap`"时才发起，否则跳过并写显式诊断（§33(4)）。
- **验收判据**：拒绝路径有**显式原因**且零副作用；mock/manual **永远不得**声称「链上已验证」（§32(7)）。
- **已知反例**：`node/factories.json` 曾文件头 `adapter: 'ocap'` 而 `nodes.hub` 是 mock 残留——按文件头判定的消费者会把模拟事实当链上事实（§32(9)、§33(3)）。

### P5 · 生成器投影（取代 `include`）
- **适用**：跨页共享的导航、门禁卡、页头、空态。
- **实现要点**：单源模型（`scripts/console-nav.mjs`）+ 生成器（`arcblog-console-nav.mjs`）+ `--check` 门禁；当前项用平台自己的 `active=true`（写在 `-> page <name>` **之后**，§23）；生成器**不输出 id**，靠自身产出的稳定标记定位（§25.3）。
- **验收判据**：`--check` 在缺项/漂移/多个或零个 `active` 时点名失败（§23）；`arc dsl format` 与 `--check` 不互相打架（§23 语法位置坑）。
- **已知反例**：`arc dsl lint --fix` 会删掉运行时寻址的 id（`site-header`/`hero-carousel-frame`/`theme-bridge-frame`），必须靠 `arcblog-runtime-ids.test.mjs` 拦住（§25.4）。

### P6 · 用目录边界取代条件筛选
- **适用**：需要按"状态"隔离可见性，但表达式不支持比较。
- **实现要点**：把语义放进**路径**：`posts/`（guest，只放已发布）、`drafts/`（admin，草稿+归档+软删）、`pages/` vs `page-drafts/`；`replicated` 与 `networkRead` 同时声明，未声明 = 拒绝（§13、`blocklet.yaml`）。
- **验收判据**：`scripts/arcblog-permissions.test.mjs` 以**无 cookie 访客**身份断言矩阵；拒绝断言必须匹配 `below readRole`，避免"未声明路径"伪装成"已正确授权"（§13）。
- **已知反例**：分类 chips 因下推查询漏记录被**移除**——宁可没有筛选也不要静默少文章（§15.1）。

## 5. 不可逆约束（容器 / 实例操作纪律）

| # | 约束 | 依据 | 纪律 |

## 摘要（给主笔，10 条以内）

1. **一句话结论**：ArcBlog 的可承诺面 = 「AUP 动态页面 + AFS 记录 + 本机 CLI/worker」；凡涉及**逐条静态 HTML、HTTP 端点、页面内哈希/时间/签名、动态筛选、按能力显隐、跨节点同步**的产品承诺，今天都写不得。
2. **最大的一条边界**：AFS 查询层只对 **≤ ~1.8 KB 内联**记录可靠，超限记录 `where`/`select` **静默**漏掉（§15.1、§44.2①）。所以筛选/计数/搜索必须由自建索引或 CLI 承担，列表只能靠**目录边界**。
3. **产品形态被链上私钥边界钉死**：私钥永不进浏览器 ⇒ 上链类操作**必然**是"意图队列 + 本机 worker"，UI 必须显示 `pending→running→applied/rejected/noop` + 终态原因 + **真实耗时**（§33、§36）。
4. **界面动态性是稀缺能力**：表达式无比较、`visible` 只在同步 `$session.*` 可靠、无 capability 求值 ⇒ 权限只分「登录/管理员」两档，状态差异靠**目录或页面**表达，其余退化为**常驻说明**（§16、§28.1、§54、§56）。
5. **跨页复用只能靠生成器**：`include` 运行时不可用，共享侧栏无法自动高亮 ⇒ 菜单单源 + 生成进每页 + `--check` 门禁是**唯一**正解（§25.2、§23、§16）。
6. **公开面就是 AUP SPA**：`/.well-known`、`/api/*` 被 AUP 壳吞掉；Web Device 无 AFS；内容站点烘焙不可达 ⇒ 网络层以 AFS 资源 + `/mcp` 发布，逐条静态 SEO 记为**平台受限**（§7、§3.3、§8）。
7. **六条最有产品含义的边界**见 §2；**六条降级模式**（意图队列+worker / 诚实降级 / CLI 折叠 / fail-closed / 生成器投影 / 目录边界）见 §3，每条的验收判据可直接搬进需求的验收标准。
8. **禁止清单 20 条**见 §4；写需求时逐条自检，尤其是"已同步""链上已验证""首屏必然为空""平台不支持 data: URI"这四类**已被证伪的反向断言**。
9. **三条操作红线**：① restart 后必复挂 `arc blocklet run .`（§34(1)）；② 只用 `npm run build`，且发布前扫**两条**密钥通道 `dist/` + Pages 产物（§39、§43(3)）；③ 写实例的测试必须先持 `docs/team/.gate-lock`（§36(5)）。
10. **未知项只有 6 条（§6）**：其余断言均有 §N 出处或源码行号；引用本笔记时请一并引用原节号，不要二次转述。
